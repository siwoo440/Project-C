# 241일차 방패 카드 확장 · 전열 보호부터 방패 파동까지

카드 시트 80~87행에 등록된 여덟 카드를 카드 보상, 상점, 회차 저장과 연결한다.

| 카드 | 효과 |
| --- | --- |
| 집중 방어 | 1턴 동안 받는 피해를 50% 줄인다. |
| 전열 보호 | 생존 아군 전체에게 각각 방어도 7과 2턴간 출혈 저항 20%를 부여한다. |
| 억제 타격 | 적 하나에게 물리 피해 9를 주고 공격력을 2턴 동안 3 낮춘다. |
| 막아내고 밀기 | 적 하나에게 물리 피해 7을 주고 35% 확률로 다음 행동을 한 번 취소한다. |
| 성벽 자세 | 생존 아군 전체에게 각각 방어도 15를 부여한다. 행동력 1을 추가로 소모한다. |
| 불굴 | 2턴 동안 체력이 1 이하가 될 피해 한 번을 막아 체력 1로 버틴다. |
| 수호 맹세 | 2회 적 턴 동안 지정 아군의 직접 공격을 대신 맞고 자신의 물리 방어력을 4 높인다. |
| 방패 파동 | 현재 가진 방어도의 절반만큼 모든 적에게 물리 피해를 준다. 소수점은 버리며 보유 방어도는 유지한다. |

수호 맹세의 대신 맞기와 대상 표시는 적 행동 처리와 같은 우선순위를 쓴다. 집중 방어와 불굴은 직접 피해를 처리하는 공통 경로에서 판정한다. 출혈 저항은 적용 저항으로 표시한다.

## 검증 및 실제 화면

- Unity EditMode 통합 검사 68건 통과. 실패 0건, 건너뜀 0건. 수호 맹세의 대상과 지속 시간, 불굴의 임계 피해, 카드 소유자 저장 복원을 검사했다.
- Windows Direct3D 11 플레이어에서 성벽 자세의 실제 행동력 비용 4, 전열 보호의 아군별 방어도 7과 출혈 저항 20%를 확인했다.
- 방패 파동의 기본 물리 피해 3과 시전자의 방어도 7 보존을 확인했다.
