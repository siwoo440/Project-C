# 271일차 펜타클 카드 확장 · 힘의 분배부터 임시 보급까지

카드 시트 208~213행, 215~216행의 원화와 카드 효과를 실제 보물 획득, 소유자 선택과 탐사 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 힘의 분배 | 선택한 생존 아군의 공격력을 8 높이고 물리 방어력을 4 낮춘다. 각 효과는 전투가 끝날 때까지 지속되며 그 전에 해제될 수 있다. |
| 카드 복제 | 이번 턴에 실제로 사용한 카드 한 장을 고른다. 같은 소유자와 강화 상태의 새 카드를 이번 전투의 손패에 추가한다. |
| 룬의 힘 | 선택한 아군의 손패에서 기본 행동력 비용이 있는 일반 카드 한 장을 무작위로 골라, 사용할 때까지 기본 비용을 0으로 바꾼다. |
| 제의 | 시전자의 체력 5를 지불해 행동력 2를 회복한다. 시전자의 체력은 최소 1 남아야 한다. |
| 융합의 힘 | 공용 손패에 카드 두 장을 뽑고 생존 아군 전원의 체력을 10 회복하며 생존 적 전원에게 일반 피해 15를 준다. |
| 동전 줍기 | 행동력을 1 회복하고 이 카드를 이번 전투에서 제외한다. |
| 물자 확보 | 공용 손패에 카드 한 장을 뽑고 시전자에게 방어도 3을 부여한다. |
| 임시 보급 | 지정 생존 아군의 체력을 4 회복하고 별도로 30% 확률로 행동력 1을 회복한다. |

카드 복제 선택을 취소하면 손패와 행동력이 유지된다. 룬의 힘으로 바뀐 카드 비용은 해당 카드를 다시 뽑아도 첫 실제 사용 전까지 적용되며 추가 지불 비용은 원래 규칙을 따른다.

## 검증 결과

- Unity 검사 33건 통과. 상점 재고·구매 확인 2건을 모두 실행했다.
- ‘제의’는 체력 5를 지불하고 행동력 2를 회복한다. 체력 5에서는 사용을 거절하고, 체력 6에서 사용하면 체력 1과 방어도 9가 남는다.
