# 설비 강화 설계도

설비 강화 화면에 기술 설계도를 적용했다. 배경, 붉은 위치 프레임, 설비 10종의 정면 평면도는 각각 별도의 텍스처다. 도면의 붉은 칸과 하단 가로 목록이 같은 설비를 선택한다. 오른쪽 패널은 설비 설명, 현재·다음 강화 효과, 필요 자원과 강화 버튼을 표시한다.

강화는 기존 설비 관리자에서 처리한다. 자원이 부족하거나 최고 단계라면 강화 버튼이 비활성화되고, 실제 레벨과 자원 수량은 화면에서 즉시 갱신된다.

우측 상단에는 기존 탐사 화면의 네 칸짜리 자원 프레임을 사용한다. 왼쪽부터 골드, 나사, 철판, 전선의 아이콘과 현재 수량을 표시한다. 오른쪽 끝의 X는 기존 거점 버튼 이미지를 사용하며, 누르면 설비 화면이 즉시 닫힌다.

## 검증

- Unity 검사 5건 전부 통과. 실패와 건너뜀 각 0건. 상점 검사 2건 포함.
- Windows Direct3D 11 실행에서 서로 분리된 원화 레이어와 새 자원 배치를 확인했다. 방어 차폐 장치를 1단계로 강화했을 때 상단 수량은 나사 30→25, 철판 30→20으로 즉시 갱신됐다. 하단 목록으로 상세 설비를 바꾸고, 1280×800에서 실제 X 위치에 포인터 클릭을 보내 창이 곧바로 닫히는 것을 확인했다.
