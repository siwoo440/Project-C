# 212일차 윈터폴 탐사 이벤트 ‘불탄 수레의 잔해’

반쯤 탄 수레가 길을 막고 있다. 식량 상자처럼 보이는 짐과 금속 공구가 남아 있지만, 수레 아래에는 누군가 기다린 흔적이 있다. 세 가지 선택지에 기획서의 결말과 수레 삽화를 연결했다. [기획서 5.2.10](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.wi4rzj33f2lg)

---

## 세 가지 선택

| 선택 | 결과 |
| --- | --- |
| 상자를 연다 | 60% 확률로 철판과 나사를 각각 1개 얻는다. 40% 확률로 현재 층의 일반 조우에 잿풍의 사냥꾼 1마리가 추가된 매복 전투가 열린다. |
| 수레를 해체한다 | 선택한 생존자 한 명이 체력 3을 잃고 철판·나사·전선을 각각 1개씩 얻는다. 체력이 3 이하면 쓰러지며 마지막 생존자라면 탐사가 실패한다. |
| 표식을 남기고 간다 | 다음 상점에서 처음 구매에 성공한 상품 한 개를 10% 할인한다. 상품 목록과 카드 소유자 선택 화면에 실제 결제 가격을 표시한다. |

---

## 매복과 상점 표식

상자 결과는 방마다 고정한다. 매복이 결정되면 일반 편성 ID를 결말과 함께 저장하고, 확인하거나 불러오면 같은 편성으로 전투에 들어간다. 지도에 배치된 일반 적은 그대로 남고, 다음 일반 적 접촉용 지도 조각도 유지된다. 승리하면 원래 일반 조우 보상을 한 번 얻는다. 도주하거나 전멸하면 전투 보상은 없다.

상점에서 소유자 선택을 취소하거나 골드가 부족하면 같은 방에 재입장해 할인을 쓸 수 있다. 상품을 사지 않고 층을 넘기면 다음 층의 첫 상점으로 할인이 이어진다. 상품 가격에 기존 유물 할인을 먼저 적용하고, 표식 할인액의 소수점은 버린다. 카드 제거 비용과 보유 유물 판매가는 기존 값을 사용한다.

이벤트 목록 버전 6부터 수레를 배치한다. 이전 저장은 그 층의 이벤트 목록을 유지하고 다음 층에서 최신 목록을 사용한다.

## 검증

Unity 6000.3.21f1에서 수레 전용 7개와 관련 회귀 20개가 모두 통과했다. 저장 후 재개한 매복에서 재폭풍 추적자와 사냥꾼이 함께 등장했고, 두 파티원이 도주한 뒤 지도 조각과 도주 결과가 유지됐다.

Unity 테스트 필터는 `BurntCartEventTests`다. 실제 탐사 자동 저장을 사용하는 검사는 회사명과 제품명이 모두 `ProjectCVerification`인 분리된 복제본에서 실행한다. 상자 추첨값 59·60의 경계, 해체 취소와 마지막 생존자 사망, 실제 상점 재입장과 층 이동 후 첫 결제, 저장에서 재개한 매복의 도주·승리·전멸을 다룬다. 최대 편성 검사는 원본을 복제해 일반 적 4명을 넣고, 사냥꾼을 포함한 5명이 실제 전투에 출전하는지 확인한다.
