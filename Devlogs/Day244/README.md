# 244일차 유물 확장 · 회색 로프부터 잿빛 도장까지

원본 시트의 86~92행 및 94행에 해당하는 유물 8종을 원화, 획득, 판매와 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 회색 로프 | 재가 된 수레의 강제 매복 가능성을 40%에서 30%로 낮춘다. 이 효과로 매복을 피하면 물자를 받지 않는다. |
| 금속 서랍손잡이 | 보유한 상태에서 탐사 중 첫 유료 상품 구매에 5% 추가 할인한다. 실제 결제 후 사용 상태를 저장한다. |
| 파손된 방패문양 | 원본 방어력 감소가 2인 기간제 약화의 지속을 1턴 줄인다. 최소 1턴이다. |
| 투박한 표식핀 | 표식이 있는 적에게 명중한 직접 마법 카드 타격마다 피해가 1 증가한다. |
| 금속 핸드벨 | 첫 손패의 일반 카드 한 장을 무작위로 골라, 그 카드가 손에 남아 있으면 첫 자동 버림에서 한 번 유지한다. |
| 여행자의 부적 | 성공적으로 탐사를 끝내면 그 회차에서 벌고 남은 골드의 5%를 추가 획득한다. |
| 침식 방울귀걸이 | 퇴색 위험과 침식지대에서 시작한 전투에서 잃는 정신력을 1 줄인다. |
| 잿빛 도장 | 새 상점 방문 시 25% 확률로 특수 카드 하나를 추가 진열한다. 기본 판매가는 100골드이며 소유자를 선택한다. |

원본에 수치가 없는 로프의 확률 감소와 도장의 발동 확률은 각각 10%포인트와 25%로 적용했다. 특수 카드의 기본 판매가는 기존 100골드 카드 판매가를 기준으로 정했다. 잿빛 도장은 기존 ‘잿빛 인장’과 별도 유물이다.

## 검증 및 실제 촬영

- Unity EditMode 62건 통과, 실패 및 건너뜀 0건. 상점 검사 두 건에서 최초 방문 전 저장 복원과 기존 진열·구매·품절 복원을 확인했다.
- Windows 빌드 성공. Direct3D11에서 1600×900 화면 3장을 촬영했다. 첫 상점 방문 전 탐사 저장을 복원한 뒤 유물 8종과 획득 순서가 일치했다.

- [특수 카드 신성의 일격 95골드 진열](AshStampShop.png)

실제 상점에서 95골드를 차감하고 선택한 두 번째 파티원에게 신성의 일격을 지급했다. 상점 방문 전 저장을 불러올 때도 판매 목록을 준비하도록 복원 순서를 수정했다.
