# 85일차 개발일지

---
## 작업 내용

- 여황제 선택 시 임시 전용 카드 `든든한 식탁` 한 장을 시작 덱에 추가했다.
- 공용 행동력 2를 사용해 생존 아군 전체의 물리 방어력을 2턴간 3 올린다.
- 기획 초안의 방어도 효과는 별도 보호막 시스템 구현 전까지 물리 방어력으로 임시 대체했다.
- 카드에 기존 임시 공용 일러스트를 사용한다.

---
## 검증

- 카드 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 거점 편성, 탐사 조우, 전체 아군 방어 증가와 행동력 소비를 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 98개 통과.

---
## 남은 작업

- 방어도 시스템과 여황제의 분배 카드·패시브, 개별 카드 일러스트 구현이 남아 있다.
- 카드 수치는 임시값이며 다른 캐릭터의 전용 능력도 추가해야 한다.
