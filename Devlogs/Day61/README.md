# 61일차 개발일지

---
## 작업 내용

- 상점 카드 제거 후 회차 덱에 최소 10장이 남도록 제한했다.
- 카드가 11장일 때 1장 제거는 허용하고, 10장 이하에서는 추가 제거를 차단한다.
- 이 제거 제한은 전투 출전 인원 변경에 따른 카드 보충 기능을 추가하지 않는다.

---
## 검증

- 기존 동작에서 10장 미만 제거가 허용되는 테스트 실패를 확인했다.
- 수정 후 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 55개 통과.

---
## 남은 작업

- 실제 파티 편성 화면과 출발 버튼을 연결해야 한다.
- 캐릭터 전용 카드와 덱 편성 UI는 아직 구현되지 않았다.
