# 69일차 개발일지

---
## 작업 내용

- 거점에서 캐릭터를 선택하고 탐사·전투에 진입하는 자동 플레이 테스트를 추가했다.
- 부트와 메인 메뉴, 거점, 탐사 씬 전환과 선택 파티 전투 출전을 검사한다.

---
## 검증

- 별도 프로젝트 복사본에서 선택한 바보 캐릭터가 탐사와 전투에 전달되는 것을 확인했다.
- 전투 초기화 로그에서 시작 손패 8장과 공용 AP 6을 확인했다.
- 전체 Unity 테스트 64개 통과. 이 중 씬 전환 테스트는 플레이 모드에 진입해 실행했다.

---
## 검증 범위

- 탐사 중 조우를 통한 전투 전환은 아직 검사하지 않았다. 테스트는 탐사 씬에서 전투 씬으로 직접 이동한다.
- 카드 사용, 전투 결과, 거점 귀환과 저장·이어하기는 별도 검증이 필요하다.
