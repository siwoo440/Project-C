# 164일차 : 카드 원본 이미지와 효과 적용

- 기존 시험용 카드 강타, 검풍, 정화에 시트와 일치하는 원본 이미지를 연결했습니다.
- 강타는 비용 1과 물리 피해 8, 검풍은 비용 3과 전체 적 피해 10으로 수정했습니다.
- 정화는 먼저 적용된 디버프 하나만 제거하며, 절제 전용 카드의 전체 정화는 유지합니다. 제거 순서는 임시 규칙입니다.
- 일반 탐사 보상·상점에서의 획득 경로와 시트 희귀도 적용은 후속 작업입니다.
- `SheetCardsBattle.png`는 확인을 위해 세 카드만 손패에 남기도록 임시 배치한 실제 전투 화면입니다.
- Unity 편집 모드 검사 327개를 모두 통과했습니다.
