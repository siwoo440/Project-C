# 72일차 개발일지

---
## 작업 내용

- 내장 이미지 생성 도구로 마법사·여황제·교황·연인의 임시 초상화를 제작했다.
- 기획서의 캐릭터 이미지 초안을 참고해 각 캐릭터 데이터에 연결했다.

---
## 이미지 생성 기준

- 마법사: 은발과 보라색·금색 장식의 마법사.
- 여황제: 분홍색 머리와 녹색·장미 장식의 치유사.
- 교황: 회백색 머리와 상아색 성직복의 엄격한 사제.
- 연인: 붉은 머리와 붉은 의상, 하트 장식의 전사.
- 파일: `Assets/_ProjectC/Art/Portraits/ARC_01.png`, `ARC_03.png`, `ARC_05.png`, `ARC_06.png`.
