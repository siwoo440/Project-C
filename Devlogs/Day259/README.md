# 259일차 지팡이 카드 확장 · 냉기 손길부터 마력 흡수까지

카드 시트 161~168행의 원화, 보물 선택 소유자, 저장 및 전투 효과를 연결한다.

| 카드 | 효과 |
| --- | --- |
| 냉기 손길 | 지정 적에게 마법 피해 5를 주고, 명중하면 적 턴 두 번 동안 행동 속도를 1 낮춘다. |
| 작은 불꽃 | 지정 적에게 마법 피해 6을 준다. 명중한 생존 적에게 25% 확률로 화상 2를 두 턴 동안 부여한다. |
| 정전기 | 지정 적에게 마법 피해 5를 준다. 명중한 생존 적에게 25% 확률로 감전 1을 두 적 턴 동안 부여한다. |
| 마력 집중 | 다음으로 사용하는 지팡이 피해 카드의 각 직접 명중 피해를 4 높인다. 정상 사용에 소모된다. |
| 마법 장벽 | 지정 아군이 받는 마법 피해의 저항을 두 적 턴 동안 10% 높인다. |
| 서리 파편 | 서로 다른 두 생존 적을 지정해 각 대상에게 마법 피해 4를 준다. 생존 적이 하나면 한 번 타격한다. |
| 불씨 확산 | 활성 화상이 있는 생존 적을 지정해 마법 피해 8을 준다. |
| 마력 흡수 | 지정 적에게 마법 피해 4를 주고 실제 명중에 30% 확률로 현재 행동력을 1 돌려받는다. |

화상과 감전의 기본 수치는 기존 상태의 실제 방식에 각각 2와 1을 적용했다. 감전은 적 턴 시작에 한 번씩 정산한다. 서리 파편의 두 대상 검증에는 기존 2적 검사 조우를 사용한다.

Unity 검사 35건이 통과했다. 상점 검사 2건을 포함했고 실패와 건너뜀은 각각 0건이었다. Windows Direct3D 11에서 서리 파편으로 첫 적을 골랐을 때 행동력 6이 유지됐다. 두 번째 적을 고른 뒤 행동력이 5로 줄고, 서로 다른 두 적에게 방어 계산 전 마법 피해 4씩이 적용됐다. [두 번째 적 선택 화면](FrostShardChooseSecond.png) · [두 적에게 피해 적용 화면](FrostShardTwoHits.png)
