# 전투 머리 조준

카드로 선택 가능한 아군과 적의 머리에 투명한 입력 영역을 추가했다. 카드 화살표와 적 행동 예고는 같은 머리 중심으로 이어진다. 적 행동 곡선은 떨어진 거리에 따라 높이가 달라지고, 카드 드래그 미리보기는 화살촉과 조준 대상이 보이도록 옆으로 이동한다.

Unity 검사 31건이 통과했다. 상점 검사 2건을 포함하며 실패와 건너뜀은 0건이다. 실제 Windows 플레이어에서 1600×900과 1280×800의 조준 장면을 찍었다. 머리 상자의 가장자리에 치유 카드를 놓았을 때 체력이 64에서 72로, 행동력이 6에서 5로 바뀌었다.
