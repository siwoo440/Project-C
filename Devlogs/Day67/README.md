# 67일차 개발일지

---
## 작업 내용

- 공격·방어·지원·전략 역할을 위한 임시 시작 카드 4종을 추가했다.
- 거점 출발 버튼에서 선택 파티와 12장 임시 덱을 생성하도록 연결했다.
- 선택한 런타임 편성을 탐사와 전투 씬에서 사용하도록 연결했다.
- 새 탐사 시작 시 탐사 세션과 회차 덱을 초기화한다.

---
## 검증

- 역할별 카드 로딩, 선택 편성 저장, 탐사 편성 조회와 출발 버튼 상태를 테스트했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 63개 통과.

---
## 남은 작업

- 실제 씬 전환과 탐사·전투 전체 흐름의 Play Mode 검증이 남아 있다.
- 시작 카드는 임시 공용 데이터이며 캐릭터별 전용 카드와 패시브는 아직 없다.
- 세계의 첫 회차 클리어 후 해금은 아직 구현되지 않았다.
