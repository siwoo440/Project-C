# 275일차 펜타클 카드 확장 · 자원 순환부터 기계식 계산까지

카드 시트 226~233행의 원본 그림과 효과를 보물 획득, 소유자 선택 및 탐사 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 자원 순환 | 이번 전투에서 제외된 카드 중 무작위 한 장을 기존 소유자 및 강화 상태로 손패에 되돌린다. |
| 전략 보관 | 손패의 다른 카드 한 장을 골라 다음 아군 턴까지 보존하고 기본 행동력 비용을 1 낮춘다. |
| 약점 분석 | 생존 적 한 명이 받는 피해를 두 적 턴 동안 20% 높인다. |
| 계산된 투자 | 행동력이 2 이상일 때 현재 행동력을 모두 결제한다. 다음 아군 턴의 최대 행동력과 현재 행동력을 실제 지불량만큼 늘린다. |
| 룬 증폭 | 생존 아군 한 명에게 있는 시간제 강화의 지속을 각각 한 턴 연장한다. |
| 임시 계약서 | 시전자 체력을 6 지불하고 공용 손패에 카드 두 장을 뽑는다. 시전자의 체력은 최소 1 남아야 한다. |
| 도박수 | 50% 확률로 행동력을 2 회복한다. 실패하면 시전자의 정신력이 5 감소한다. |
| 기계식 계산 | 이번 아군 턴 동안 펜타클 카드의 일반 기본 행동력 비용을 1 낮춘다. |

계산된 투자에서 표시된 최소 행동력 2는 전액 결제에 포함된다. 전략 보관과 기계식 계산에서 바뀌는 비용은 기본 행동력 비용이다.
