# 221일차 최대 체력에서 회복 카드와 물약 사용

생존 아군은 현재 체력과 관계없이 단일·전체 체력 회복의 대상이 된다. 실제 회복량은 빈 체력만큼이다. 회복 카드의 행동력을 지불하고 사용 카드를 버리며, 사용한 회복 물약은 한 개 소비한다. 사망한 대상에게는 기존 부활 규칙이 적용된다.

| --- | --- |
| ![최대 체력인 아군과 사용 전 손패](BeforeHeal.png) | ![체력 상한에서 카드를 사용한 뒤의 전투 화면](AfterHeal.png) |

Windows 플레이어에서 체력 94/94인 아군에게 회복 카드를 사용해 행동력이 6에서 5로 줄고 카드가 버린 더미에 들어가는 것을 확인했다. 같은 아군에게 회복 물약을 사용하자 슬롯이 비고 체력은 94/94였다. 별도 검사에서는 파티 전원의 체력이 최대일 때 전체 회복을 사용한 경우와 체력이 1만 부족할 때 초과분이 잘리는 경우를 확인했다.
