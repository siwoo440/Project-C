# 220일차 첫 손패 순차 배치와 전투 버튼 아이콘

전투의 첫 드로우에서 실제 카드들이 왼쪽 뽑기 더미에서 0.105초 간격으로 출발한다. 각 카드는 0.45초 동안 중앙으로 이동하고 부채꼴 손패의 자기 자리에 도착하면 선택할 수 있다. 씬 로딩이 끝난 뒤 연출 시간을 계산하며, 첫 전투의 자동 도움말은 배분이 끝난 뒤 표시한다.

상단 버튼은 도움말 책, 화살표 표적, 강화 계급장, 유물 수정으로 표시한다. 화살표의 개별 표시 모드는 청색으로 강조하고, 현재 강화가 있으면 강화 아이콘에 개수를 표시한다.
