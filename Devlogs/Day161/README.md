# 161일차 : 확률형 디버프 유물 추가

- 검은 손수건은 전투 시작 시 임시 10% 확률로 무작위 생존 적 한 명의 물리 방어력을 1턴 동안 1 낮춥니다.
- 임시 확률과 디버프 수치를 유물 시트의 설명과 게임 데이터에 동일하게 기록했습니다.
- 중복 전투 시작 알림은 실패한 확률 판정을 다시 시도하지 않으며, 기존 유물은 이전처럼 확정 발동합니다.
- 유물의 상점 가격과 획득·저장 복원을 연결했습니다.
- `BlackHandkerchiefShop.png`는 유물이 실제 상점에 표시되는 화면입니다.
- 유물 그림은 기존 유물 이미지를 참고해 이미지 생성 도구로 제작했습니다. 요청 내용은 황동 테두리와 청록색 문양이 있는 검은 손수건입니다.
- Unity 편집 모드 검사 324개를 모두 통과했습니다.
