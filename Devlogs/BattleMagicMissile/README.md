# 마력탄 전투 이펙트

마력탄을 사용하면 시전자 앞에서 청백색 마법진이 점등되고, 탄환과 잔광이 선택한 적 쪽으로 이동한다. 기존 명중 판정이 성공한 순간 적에게 별 모양 섬광이 퍼진다. 빗나간 탄환은 비행 뒤 사라진다. 게임에서 선택한 전투 속도가 세 단계에 함께 적용된다.

ImageGen에서 투명 원화 한 장을 제작한 뒤 시전용 마법진, 비행용 청백색 탄환, 명중용 청백색 섬광 세 스프라이트로 나누었다. 게임에서는 전투 캔버스의 실제 캐릭터 원화 위치를 기준으로 표시한다.

## 실제 Windows 플레이 확인

Direct3D 11 실행판에서 1600×900으로 촬영했다. 시전과 비행 동안 적 체력은 50으로 유지됐고 명중 순간 한 번 피해를 받아 44가 됐다. 두 번째 시전에서 실제 실명으로 명중률을 0으로 만들었을 때 탄환 비행 후 피해와 명중 섬광이 발생하지 않았다. 마력탄 두 장이 행동력 1씩을 지불해 공용 행동력이 6에서 4가 됐다.
