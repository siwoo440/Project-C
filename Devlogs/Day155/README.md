# 155일차: 저장·튜토리얼·로비·편성 개선

- 거점·탐사·전투 튜토리얼에 반투명 회색 배경과 확인 오른쪽의 건너뛰기 버튼을 적용했다.
- 제작한 가로형 화살표 버튼과 `페이지 현재 / 전체` 표시를 안내 상단 중앙에 추가했다. 실제 이동·카드 사용·턴 종료 대기 조건을 지키며 이전 페이지에서 돌아와도 완료된 행동 기록을 유지한다.
- 골드·나사·철판·전선의 배경을 넓히고 수치를 아이콘 오른쪽에 정렬했다.
- 편성된 칸을 클릭하면 해당 칸을 강조하고 오른쪽에 캐릭터 이름과 능력치·설명을 표시한다. 빈 칸 클릭은 기존 선택을 유지한다.
- 실제 저장 슬롯의 탐사 이어하기 후 획득 골드 구분을 복원하고 전멸 시 기존 재화가 유지되는 흐름을 확인했다.
- 실제 화면: [튜토리얼](TutorialLobby.png), [로비 자원](LobbyResources.png), [편성 선택](FormationSelection.png). 로비 자원 수치는 표시 확인을 위한 임시 예시다.
- 검증: 실제 화면 촬영과 페이지 이동·행동 조건·편성 칸 선택·재화 배치·저장 이어하기를 포함한 Unity 전체 검사 315개 통과.
