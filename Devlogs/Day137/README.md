# 137일차: 매달린 자·죽음 임시 전용 카드 구현

- 매달린 자의 `기울어진 시선`은 다른 아군의 디버프 중 하나를 직접 선택해 자신에게 이전한다.
- 이전할 때 수치·지속 횟수·중첩을 유지하며, 면역이나 중첩 한도로 상태가 손실될 경우 이전을 막는다.
- 죽음의 `마침표`는 임시 기본 피해 10을 주고 디버프가 있는 적에게 피해를 50% 늘린다.
- 두 캐릭터의 패시브와 정상·각성·붕괴별 세부 효과는 기획 미정으로 남겨 둔다.
- `DebuffChoice.png`는 실제 탐사 조우 전투에서 디버프 이전 카드를 사용해 촬영한 화면이다.
- 실제 카드 사용·상태 선택·조건부 피해와 기존 캐릭터 능력을 포함한 관련 검사 14개가 통과했다.
- 두 캐릭터의 전용 카드 탐사 저장·복원과 상태 중첩을 포함한 추가 검사 5개가 통과했다.
- Unity 전체 EditMode 회귀 검사 232개가 통과했다.
