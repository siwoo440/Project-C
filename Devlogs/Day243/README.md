# 243일차 방패 카드 확장 · 철갑 돌진부터 거인의 방패까지

카드 시트 88~95행의 원화와 카드 효과를 구현하고, 보물 보상에서 카드 소유자를 선택하고 저장할 수 있게 등록한다.

| 카드 | 효과 |
| --- | --- |
| 철갑 돌진 | 적 하나에 물리 피해 16을 주고 사용자에게 방어도 10을 부여한다. 방어도는 별도 효과라 적이 회피해도 지급한다. |
| 절대 가드 | 지정한 아군의 다음 유효 피해를 한 번 무효로 한다. 체력과 방어도가 그대로 유지된다. |
| 요새화 | 아군 전체의 물리 방어력 3과 마법 피해 저항 10%를 3턴 동안 높인다. |
| 응징 방벽 | 다음 적 턴에 직접 피격이 정산되면 살아남은 아군을 공격한 적이 고정 물리 피해 5를 받는다. |
| 분산 방어 | 2회 적 턴 동안 적의 광역 공격 피해를 35% 줄인다. |
| 불굴의 전열 | 생존 아군 전체에게 방어도 10을 각각 부여하고 공포를 제거한다. |
| 난공불락 | 생존 아군 전체에게 방어도 12와 각자의 다음 피해를 한 번 무효화하는 효과를 부여한다. |
| 거인의 방패 | 사용자에게 방어도 40을 부여한다. 다음 아군 턴의 최대 및 현재 행동력이 1 감소한다. |

분산 방어는 명시적인 광역 적 행동의 예고와 실제 피해에 반영한다. 광역 공격을 등록한 검사 전투에서 생존자가 여럿일 때와 한 명일 때의 피해 경감을 대조한다.

## 검증 및 실제 촬영

- Unity EditMode 55건 통과, 실패 및 건너뜀 0건. 상점 진열·구매 확인 두 검사와 기존 유물 저장 검사를 포함한다.
- Windows 빌드 성공. Direct3D11에서 1600×900 전투 화면 2장을 촬영했다.
- [상급 방패 카드가 들어온 전투 손패](AdvancedShieldHand.png)
- [지정 아군의 절대 가드와 철갑 돌진 정산](AbsoluteGuardAndIroncladRush.png)

절대 가드 적용 직후 여사제의 피해 무효 툴팁을 펼쳤다. 철갑 돌진의 물리 피해 16은 적 방어력 1을 거쳐 체력 50에서 35로 정산됐고, 사용자에게 방어도 10이 적용됐다.
