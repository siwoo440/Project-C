# 140일차: 달·태양 임시 전용 카드

- 달: 카드를 최대 2장 뽑고 손패에서 1장을 선택해 버린다. 사용 카드가 차지하던 손패 공간을 드로우 전에 확보한다.
- 태양: 선택한 적에게 물리 피해 8을 주고, 다른 생존 적 하나에게 무작위로 물리 피해 6을 준다. 대상별 방어와 카드 약점을 적용한다.
- 카드 사용, 손패 선택, 최대 손패, 사용 카드의 즉시 재드로우 방지, 탐사 저장과 복원을 검증했다. 전체 Unity 테스트 243개가 통과했다.
- 패시브와 정신 상태별 세부 효과는 기획 확정 후 구현한다.
