# Project C - 35일차 개발일지

## 작업 주제

세룰리온 설비 영구 강화 시스템 및 임시 강화 UI 구축

## 개발 목표

- 세룰리온의 10종 설비를 Lv.0부터 Lv.5까지 강화할 수 있는 기반 구축
- Gold, 나사, 철판, 전선을 강화 비용으로 사용
- 강화 상태를 Scene 이동 중에도 유지
- 설비별 현재 효과와 다음 레벨 효과 확인
- 강화 가능 여부와 최대 레벨 처리
- 강화 테스트 UI를 `20_Lobby`에서만 사용
- `30_Exploration`에서는 강화 UI가 표시되지 않도록 제한

## 구현 내용

### 1. 설비 종류 정의

`FacilityType`을 추가하여 다음 10종 설비를 관리하도록 구성했다.

- 전력 공급기
- 방어 차폐 장치
- 마력 변환기
- 자율 회복 장치
- 데이터 분석기
- 물자 창고 확장
- 전투 훈련실
- 응급 수복장치
- 통신 기지국
- 환경 정화 장치

### 2. 설비 강화 데이터 구축

`FacilityDefinition`과 `FacilityLevelDefinition`을 추가했다.

각 설비는 다음 정보를 가진다.

- 현재 강화 레벨
- Lv.1 ~ Lv.5 강화 데이터
- Gold 비용
- 나사 비용
- 철판 비용
- 전선 비용
- 레벨별 효과 설명

설비 데이터는 `FacilityCatalog`에서 일괄 관리하도록 구성했다.

### 3. 설비 영구 강화 관리자 구현

`FacilityUpgradeManager`를 추가했다.

주요 기능은 다음과 같다.

- 설비별 현재 레벨 관리
- 최대 레벨 Lv.5 제한
- 다음 강화 단계 조회
- 현재 자원으로 강화 가능한지 확인
- 강화 성공 시 자원 차감
- 강화 레벨 증가
- 설비 변경 이벤트 전달
- Scene 이동 시 강화 상태 유지
- 전체 설비 초기화 기능 제공

게임 시작 시 자동 생성되며 `DontDestroyOnLoad`를 통해 Scene 전환 후에도 유지된다.

### 4. 설비 효과 조회 기반 구현

향후 전투·탐사 시스템에서 사용할 수 있도록 설비별 효과 값을 조회하는 기능을 추가했다.

현재 조회 가능한 값은 다음과 같다.

- 전력 공급기 시작 정신력 증가
- 전력 공급기 최대 레벨 첫 턴 AP 증가
- 방어 차폐 장치 피해 감소율
- 마력 변환기 마법 피해 증가율
- 자율 회복 장치 전투 종료 회복률
- 데이터 분석기 약점 피해 증가율
- 물자 창고 일반 자원 획득 증가율
- 전투 훈련실 공격력 증가율
- 응급 수복장치 부활 확률
- 통신 기지국 이벤트 발견 증가율
- 환경 정화 장치 환경 피해 감소율

아직 구현되지 않은 전투·탐사 기능과 직접 연결되는 효과는 이후 해당 시스템 구현 시 연결할 수 있도록 조회 기능을 우선 구축했다.

### 5. 물자 창고 효과 실제 연결

`PlayerResourceManager`의 전투 클리어 보상 처리에 물자 창고 강화 효과를 연결했다.

물자 창고 레벨에 따라 다음 자원 획득량이 증가한다.

- 나사
- 철판
- 전선

기존 Gold 관리 구조와 자원 변경 이벤트는 유지했다.

### 6. 자원 직접 지급 기능 추가

설비 강화 테스트를 위해 `PlayerResourceManager`에 보정 없는 자원 직접 지급 기능을 추가했다.

이를 통해 테스트 UI에서 다음 자원을 빠르게 지급할 수 있다.

- Gold
- 나사
- 철판
- 전선

### 7. 20_Lobby 전용 임시 강화 UI 구현

`FacilityUpgradeDebugView`를 추가했다.

`20_Lobby`에서 F7 키를 누르면 임시 설비 강화 화면을 열고 닫을 수 있다.

화면에서 다음 내용을 확인할 수 있다.

- 현재 보유 자원
- 전체 설비 목록
- 설비별 현재 레벨
- 현재 효과
- 다음 레벨 효과
- 다음 강화 비용
- 강화 버튼
- 최대 레벨 표시
- 현재 런타임 효과 값

자원이 부족할 경우 강화 버튼이 비활성화되고, Lv.5에 도달하면 추가 강화가 제한된다.

### 8. 30_Exploration 강화 UI 제거

설비 강화 UI의 Scene 조건을 `20_Lobby`로 제한했다.

따라서 `30_Exploration`에서는 다음 기능이 동작하지 않는다.

- F7 강화 입력
- 강화 UI 안내
- 설비 강화 패널

탐사 Scene은 기존 탐사 기능을 위해 그대로 유지한다.

## 완료 결과

35일차를 통해 기존에 획득만 가능했던 영구 강화 자원을 실제로 소비하는 메타 성장 기반을 구축했다.

세룰리온 설비 10종의 강화 데이터와 레벨 관리 구조가 마련되었으며, `20_Lobby`에서 임시 강화 UI를 통해 설비를 직접 강화할 수 있다.

향후 전투, 탐사, 이벤트, 환경 시스템이 확장될 때 `FacilityUpgradeManager`의 설비 효과 값을 각 시스템에 연결할 수 있는 기반도 함께 준비했다.
