# 110일차: 탐사 상태 저장 데이터

---
## 작업 내용

- 현재 층·시드·플레이어 위치와 파티, 시작 덱 및 강화된 회차 덱을 저장한다.
- 클리어 조우·처리 이벤트·유물·소모품 슬롯과 상점 판매 상태를 기록한다.
- 대기 환경 피해, 노출도, 탐사 보상 합계와 동일 시점의 거점 상태를 함께 기록한다.
- 임시 파일을 먼저 기록하고 기존 파일을 교체하며, 전투 진행 중이거나 위치가 잘못된 경우 저장하지 않는다.

---
## 검증과 남은 작업

- 격리된 Unity 복사본에서 탐사 저장 내용, 기존 파일 교체와 잘못된 저장 요청 차단을 검증했다.
- 전체 EditMode 테스트 152개 통과 후 기존 파일 교체 검사를 추가 실행해 통과했다.
- 탐사 저장의 실제 복원과 이어하기 연결은 111일차에 진행한다. 자동 저장 지점은 112일차 범위다.
- 실제 사용자 화면에서의 확인과 독립 실행 빌드는 수행하지 않았다.
