# 130일차: 여사제·여황제 방어도 기반

- 방어도는 방어력과 약점을 계산한 뒤 피해를 흡수하며 적 턴이 끝난 다음 라운드 전환 시 제거된다.
- 여사제의 기존 카드는 사용자 확인에 따라 선택 아군에게 임시 방어도 2를 부여한다.
- 여황제의 기존 카드는 사용자 확인에 따라 임시 방어도 총 3을 생존 아군에게 균등 배분한다. 나누고 남는 수치는 배치 순서대로 부여한다.
- 연속 공격 예고는 앞선 공격의 방어도 소모를 반영한다. 전투 화면에는 남은 방어도와 흡수 피드백을 표시한다.
- 여사제와 여황제의 추가 패시브, 추가 카드 및 정신 상태별 효과는 기획 수치가 미정이어서 미구현 상태다.
- `BlockView.png`는 격리된 검증 프로젝트의 실제 전투 화면에서 임시 방어도를 부여한 캡처다. 테스트 전투의 임시 배경과 적이 표시된다.
- 격리된 Unity 6000.3.21f1 프로젝트의 전체 EditMode 회귀 검사 208개가 통과했다. 플레이 모드에서 실제 카드 사용과 전투 화면도 확인했다.
