# 132일차: 연인·전차 및 손패 UI 보완

- 연인 전용 카드로 자신을 제외한 생존 아군을 파트너로 지정한다. 다른 파트너를 선택하면 기존 사용 기록이 초기화된다.
- 파트너의 카드 사용 여부를 화면에 표시하며, 턴 종료 시 사용 기록을 지우고 파트너 또는 연인의 사망 시 연결을 해제한다.
- 전차의 전용 공격은 표식 1개를 부여한다. 한 턴에 같은 적을 두 번째 공격하면 패시브로 표식 1개를 추가한다.
- 전차가 다른 적을 공격하면 이전 적의 표식을 제거하고, 플레이어 턴 종료 시 남은 표식을 정리한다.
- 손패 장수와 화면 너비에 따라 카드를 겹쳐 배치하고, 마우스를 올린 카드는 위쪽과 다른 카드 앞으로 표시한다.
- 겹친 카드마다 독립 입력 영역을 배치해 이웃 카드 선택과 기존 드래그 사용을 유지한다.
- 연인의 공격 카드와 추가 피해량, 전차의 표식 소모 카드와 표식당 추가 피해량, 정신 상태별 효과는 기획 미정으로 미구현 상태다.
- `PartnerAndMark.png`는 표시 확인을 위해 파트너와 표식 상태를 직접 설정한 격리 테스트 전투 화면이다. 임시 배경과 적이 함께 표시된다.
- `HandHover.png`는 실제 전투에서 열두 장의 손패와 마우스 강조를 캡처한 화면이다. 렌더링된 카드와 인접 카드의 포인터 적중을 확인했다.
- 격리된 Unity 6000.3.21f1 프로젝트에서 전체 EditMode 회귀 검사 213개가 통과했다.
