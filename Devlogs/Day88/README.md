# 88일차 개발일지

---
## 작업 내용

- 마법사 선택 시 전용 카드 `임시 개조` 한 장을 시작 덱에 추가했다.
- 공용 행동력 1을 사용해 버린 카드 중 선택한 한 장을 손패로 회수한다.
- 버린 카드가 없으면 사용을 차단하며, 현재 사용하는 카드는 회수 후보에서 제외한다.
- 후보가 많을 때 페이지를 넘겨 선택할 수 있으며 기존 임시 공용 일러스트를 사용한다.

---
## 검증

- 카드 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 빈 버린 더미 사용 차단, 세 번째 후보 선택, 카드 회수와 행동력 소비를 확인했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 102개 통과.

---
## 남은 작업

- 마법사의 턴당 첫 회수 카드 AP 감소 패시브와 나머지 전용 카드가 미구현이다.
- 개별 카드 일러스트와 다른 캐릭터 전용 능력 구현이 남아 있다.
