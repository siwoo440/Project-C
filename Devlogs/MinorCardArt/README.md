# 마이너 카드 전용 원화

전투의 열기, 갑옷 균열, 강철의 의지, 마력 장막, 마력 침식, 생명의 불씨에 개별 원화를 적용했습니다. 찌르기 카드처럼 흑백 속도선 위에 검은 인물 실루엣을 그리고, 각 효과에는 구분되는 색을 사용했습니다. 금속 프레임은 별도 리소스로 적용했으며 이름과 효과 수치는 게임에서 표시합니다.

---

## 검증

- Unity 검사 5건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- 전용 프레임과 개별 원화 6종을 확인하고, Windows 전투에서 1600×900과 1280×800 화면을 촬영했습니다.
- 실제 마우스로 전투의 열기를 선택해 남은 선택이 0회가 되고 생존 아군 네 명에 공격력 증가가 적용되는 것을 확인했습니다. 화면의 적은 효과 확인용 시험 편성입니다.
