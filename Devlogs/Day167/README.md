# 167일차 : 회복·마법 공용 카드 보상 추가

- 카드 시트의 작은 치유, 불덩이, 마력탄 세 장에 원본 이미지와 비용·대상·효과를 적용했습니다.
- 작은 치유는 AP 1, 아군 한 명의 체력 6 회복입니다.
- 불덩이는 AP 1, 적 한 명에게 마법 피해 9입니다.
- 마력탄은 AP 1, 적 한 명에게 마법 피해 7입니다.
- 카드 시트에 상점 가격이 없어 세 카드는 보물 보상에서만 얻으며 상점 표시와 구매를 제한합니다.
- 보상 획득 시 파티원 중 소유자를 직접 선택하고 카드와 소유자를 저장·복원합니다.
- `SheetCardsBattle.png`는 시연을 위해 세 카드만 손패에 남긴 실제 전투 화면입니다.
- 검증: Unity EditMode 전체 검사 332개 통과.
