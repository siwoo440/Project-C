# 277일차 펜타클 카드 확장 · 전장 지도부터 운명 조작까지

카드 시트 234~241행의 효과와 제공된 원화를 보물 획득, 소유자 선택 및 탐사 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 전장 지도 | 생존 적 전체에 한 적 턴 동안 표식을 부여하고, 생존 아군 전체의 명중률을 두 아군 턴 동안 10%p 높인다. |
| 비밀 금고 | 행동력 2를 얻고 다음 아군 턴에 기본 드로우를 한 장 줄인다. |
| 룬 봉인 | 지정 적의 제거 가능한 활성 강화 중 먼저 적용된 것 하나를 해제하고, 마법 저항력을 두 적 턴 동안 10 낮춘다. |
| 재분배 | 생존 아군의 현재 체력 총합을 유지하며 각 최대 체력 범위 내에서 고르게 나누고, 생존 아군 모두 방어도를 6 얻는다. |
| 대가 지불 | 시전자 체력을 12 지불하고 행동력 4를 얻는다. 시전자 체력은 최소 1 남아야 한다. |
| 연금술 | 다른 일반 손패 카드 한 장을 골라 이번 전투 동안 같은 계열의 무작위 희귀 카드로 바꾸며, 기존 소유자를 유지한다. |
| 복리 효과 | 이번 아군 턴에 행동력을 얻을 때마다 행동력이 1 더 오른다. 실제 획득량은 기존 최대 행동력 범위에 따른다. |
| 운명 조작 | 뽑을 카드 더미에서 실제 카드 한 장을 골라 현재 소유자와 강화 상태 그대로 손패로 옮긴다. |

재분배에서 같은 체력을 나눈 뒤 남는 정수 체력은 최대치에 여유가 있는 파티원을 편성 순서로 배정한다. 체력 이동은 피해와 회복 효과를 발동시키지 않는다. 비밀 금고를 한 턴에 여러 번 사용하면 다음 아군 턴의 기본 드로우 감소량이 합산된다.
