# 82일차 개발일지

---
## 작업 내용

- 바보 캐릭터의 선택 드로우에 사용할 덱 위 카드 후보 조회와 선택 기능을 추가했다.
- 후보가 부족하면 버린 카드를 섞어 기존 뽑을 카드 아래에 놓는다.
- 선택하지 않은 카드는 기존 순서대로 남으며 손패가 가득 차면 선택한 카드를 버린다.

---
## 검증

- 기능 구현 전 테스트 실패와 구현 후 성공을 확인했다.
- 카드 순서 보존, 후보 외 선택 차단, 초과 드로우 버림과 전체 카드 보존을 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 94개 통과.

---
## 남은 작업

- 선택 화면과 바보 전용 카드 연결 전이므로 게임에서 아직 직접 사용할 수 없다.
