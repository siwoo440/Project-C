# 284일차 유물 확장 · 중앙 전력 퓨즈부터 불량 AI의 판단식까지

유물 시트 253~260행에 개별 원화와 실제 게임 효과를 더한다. 상점, 도감과 탐사 회차 저장에서 같은 원본을 참조한다.

| 유물 | 효과 |
| --- | --- |
| 중앙 전력 퓨즈 | 아군이 활성 감전 상태의 적을 실제로 처치하면 기존 공용 상한 안에서 행동력 2를 얻는다. |
| 냉각수 밸브 | 아군에게 화상이 새로 적용될 때 50% 확률로 즉시 해제한다. 같은 활성 화상의 중첩에서는 다시 판정하지 않는다. |
| 데드락 백업칩 | 전투 시작에 생존 적 전체에 두 적 턴 동안 표식을 부여한다. 전투 중 모든 아군의 마법 저항력이 5 낮아진다. |
| 바실리스크 엔진 코어 | 전투 시작에 첫 생존 아군이 방어도 30을 얻는다. 같은 아군의 첫 아군 턴에 행동 속도가 1 감소한다. |
| 스크랩 마더의 재조립핵 | 기계형 적을 처치한 아군이 그 자리에서 방어도 5를 얻는다. 해당 아군의 누적량에 5를 더하며 이후 실제 아군 턴이 시작될 때 누적 방어도가 다시 지급된다. |
| 중앙 봉쇄 프로토콜 | 실제 아군 턴이 세 번 시작될 때마다 한 번 판정한다. 25% 확률로 생존 적 전체의 다음 예정 행동을 하나씩 취소한다. |
| 실험체 보존 캡슐 | 결과를 정산할 때 생존 아군마다 체력을 기본 10 회복하고 정신력을 3 낮춘다. |
| 불량 AI의 판단식 | 실제 아군 턴의 손패 지급이 끝나면 무작위 고정 비용 카드 한 장의 비용이 이번 턴에만 1 줄거나 1 늘어난다. |

캡슐은 기존 회복이 부여하는 정신력 상승과 별도로 정신력 3 감소를 적용한다. 퓨즈와 재조립핵은 출처가 실제 아군인 처치에 반응한다. AI의 판단식에서 전액 소비 X와 전투 중 생성된 무비용 복사본은 원래 비용 규칙을 사용한다.

## 검증 결과

Unity EditMode 35건 통과, 실패와 건너뜀 0건. 상점 검사 2건을 포함했다.

Windows 플레이어에서 유물 8종의 저장 복원, 시작 방어도 30과 행동 속도 1 감소, 한 카드의 비용 변경, 감전된 적 처치 시 AP 2 회복을 확인했다. 캡슐의 승리 후 회복은 체력 56→66, 기본 정산을 포함한 정신력은 50→48이었다.
