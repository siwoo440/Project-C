# 283일차 방패 카드 · 막기, 흘려내기, 밀어 막기

카드 시트 57~59행의 비용, 효과, 범위와 대상이 비어 있어 세 카드의 사양을 정했다. 제공된 원화를 그대로 카드와 도감에 연결한다.

| 카드 | 등급 | 행동력 | 대상과 효과 |
| --- | --- | ---: | --- |
| 막기 | 일반 | 0 | 자신이 방어도 4를 얻는다. |
| 흘려내기 | 희귀 | 2 | 자신이 방어도 6을 얻는다. 다음 적 턴이 끝날 때까지 자신의 회피율이 35%p 증가한다. |
| 밀어 막기 | 일반 | 1 | 지정 적 하나에게 물리 피해 3을 주고 자신은 방어도 4를 얻는다. |

막기는 행동력이 떨어진 상황에서 방어도를 남기는 선택이다. 흘려내기는 기존 회피 기간과 명중 계산을 사용한다. 밀어 막기는 방어 전진과 같은 단일 타격과 자기 방어 흐름을 쓰며 비용과 수치를 낮게 책정했다.

## 검증 결과

Unity EditMode 25건 통과, 실패와 건너뜀 0건. 상점 검사 2건을 포함했다.

Windows 실제 전투에서 막기·흘려내기·밀어 막기를 순서대로 사용했다. 방어도는 0→4→10→14, AP는 6→6→4→3이었다. 흘려내기의 회피율 35%p 증가와 밀어 막기의 적 체력 25→23을 확인했다.
