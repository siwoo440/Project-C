# 242일차 유물 확장 · 손상된 코어 조각부터 세공된 초크까지

원본 유물 시트 78~85행의 여덟 유물에 원화, 획득, 상점 가격과 회차 저장을 연결한다.

| 유물 | 발동 조건과 효과 |
| --- | --- |
| 손상된 코어 조각 | 침식핵 조우의 첫 승리에 해당 조우의 추가 유물 확률을 20%포인트 높인다. 방 식별자마다 동일한 결과를 판정한다. |
| 잔광 등불 | 재폭풍 눈의 파편과 유리밭의 깨진 유리 함정 피해를 2 줄인다. 선택 화면에 줄어든 수치를 표시한다. |
| 파열된 방울 | 실제 체력 피해를 받고 생존한 아군에게 방어도 3을 부여한다. 전투 전체에서 두 번 발동한다. |
| 퇴색한 왕관 | 첫 아군 턴의 시작 손패 중 비용이 있는 고정 비용 카드 한 장을 골라 해당 턴 비용을 1 낮춘다. |
| 검은 왕관 | 생존 적 하나에게 첫 아군 턴까지 취약을 부여한다. 방어도로 막을 수 있는 피해를 20% 높인 뒤 소수점을 버린다. |
| 오염 표본병 | 재먹는 구더기 조우에서 승리하면 다음 탐사 전투의 첫 아군 턴 드로우를 하나 예약한다. |
| 균열 표본병 | 같은 괴생체 조우에서 승리하면 다음 탐사 전투의 첫 아군 턴 행동력을 하나 예약한다. |
| 세공된 초크 | 상점의 회차 카드 제거 비용이 20% 줄어든다. 기존 무료 교환권은 우선 적용된다. |

침식핵 추가 보상 확률과 취약 증가율은 시트에 수치가 없어서 각각 20%포인트와 20%를 적용했다. 괴생체 판정에는 원본 적 설명에 괴생체가 명시된 재먹는 구더기 조우를 사용했다. 표본병은 승리 시 보상을 저장하고 다음 실제 탐사 전투에 지급한다.

## 도감 이미지 로딩과 메모리

목록에서는 메타데이터를 읽고 화면에 들어온 셀의 최대 128픽셀 독립 썸네일을 불러온다. 상세를 고르면 해당 항목의 원화 참조 한 개를 읽는다. 상태 아이콘도 목록의 썸네일과 전투 표시용 Sprite를 분리했다.

도감 로딩을 재현할 때는 개발용 Windows 플레이어에서 `-codex-memory-probe`에 카드 `7`, 유물 `3`, 적 `2` 또는 상태 `4`를 지정한다. Unity Profiler의 네이티브 텍스처 할당과 상세 원화 참조 수를 비교한다. 정리 전 표본과 `Resources.UnloadUnusedAssets` 이후 표본을 모두 기록한다. 전투 UI가 공용으로 참조하는 Sprite Atlas는 기존 씬의 영향도 받는다.

1280×720 Windows Direct3D 11에서 분류마다 새 프로세스로 계측했다. 카드, 유물, 적의 목록을 처음 열거나 끝까지 스크롤해도 원화 참조는 0개였다. 상세에서 선택한 원화 참조가 1개 생겼고, 상세를 닫고 미사용 에셋을 정리한 뒤 0개로 돌아갔다. 상태 분류는 전투용 아이콘을 사용하며 상세를 열어도 원화 참조 개수는 0개였다.

| 분류 | 목록 처음 열기 시 썸네일 | 끝까지 스크롤한 뒤 정리 전 썸네일 | 선택한 썸네일 → 상세 원화 |
| --- | ---: | ---: | --- |
| 카드 | 15개, 120,384바이트 | 34개, 381,312바이트 | 128×128, 8,640바이트 → 1024×1024, 524,736바이트 |
| 유물 | 24개, 403,968바이트 | 44개, 740,608바이트 | 128×128, 16,832바이트 → 256×256, 65,984바이트 |
| 적 | 8개, 154,624바이트 | 8개, 154,624바이트 | 120×128, 15,808바이트 → 961×1024, 3,936,704바이트 |
| 상태 | 13개, 218,816바이트 | 26개, 437,632바이트 | 128×128, 16,832바이트 → 256×256, 65,984바이트 |

표의 바이트 수는 Unity Profiler가 보고한 네이티브 텍스처 오브젝트 수치다. 스크롤 뒤 표본에는 정리 대기 중인 이전 행의 썸네일이 포함된다. 플레이어 로그에는 기존 탐사 타일맵 콜라이더의 스프라이트 윤곽 경고가 남는다.

## 검증

- Unity EditMode 45건 통과, 실패와 건너뜀 0건. 실제 상점 테스트 2건 포함.
- Windows Direct3D 11 플레이어에서 유물 8종의 획득, 중복 전환 및 저장 복원을 확인했다. 빛바랜 왕관은 첫 손패 카드의 행동력 비용을 1 낮췄다. 검은 왕관이 부여한 취약으로 찌르기의 방어 전 피해가 7에서 8로 증가했다.
- `CoreRelics.png`, `CrownOpeningHand.png`, `CrownVulnerableHit.png`는 1600×900 실제 Windows 플레이어 화면이다. 개발자 콘솔에는 기존 탐사 타일맵 경고가 표시된다.
