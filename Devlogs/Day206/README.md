# 206일차 탐사 이벤트 패널 확대

탐사 이벤트의 선택 화면과 결과 화면에 같은 패널을 사용한다. 참고 이미지의 하늘색 사각형을 기준으로 패널은 화면 가로의 95.4%, 세로의 84.8%를 차지한다. 위쪽 여백은 3.5%, 아래쪽 여백은 11.7%로 두어 파티 정보가 보인다.

삽화는 원래 비율을 유지하며 왼쪽 열 안에서 커진다. 오른쪽에는 본문을 배치했다. 선택 화면에서는 버튼 세 개의 높이를 확보하고, 결과 화면에서는 확인 버튼 한 개만큼만 공간을 남긴다.

두 장 모두 1600×900 Windows 플레이어 촬영본이다. 기존 고정 크기에서 실패한 배치 검사가 수정 후 통과했다. 하단 여백, 삽화와 본문 간격, 버튼 경계를 포함해 관련 Unity 검사 8개가 모두 통과했다.
