# 59일차 개발일지

---
## 작업 내용

- 아르카나 ARC_00~ARC_21의 기본 캐릭터 데이터와 역할별 임시 능력치를 추가했다.
- 전투 기본값을 AP 6, 시작 손패 8장, 이후 턴 드로우 4장, 최대 손패 20장으로 조정했다.
- 손패 한도를 초과해 뽑은 카드를 버린 카드 더미로 이동하도록 수정했다.
- 전투 결과 관리자의 전역 인스턴스 등록을 보완해 사망 상태 출전 검증을 수정했다.

---
## 검증

- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 52개 통과.
- 초과 드로우 및 22개 캐릭터 에셋 읽기 검증 추가.

---
## 남은 작업

- 캐릭터 데이터는 임시 능력치이며 초상화, 전용 카드, 패시브와 해금 조건은 연결되지 않았다.
- 실제 거점 캐릭터 선택, 파티 편성, 출전 검증과 덱 편성 화면을 구현해야 한다.
- Play Mode 전체 흐름은 아직 검증하지 않았다.
