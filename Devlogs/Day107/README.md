# 107일차: 거점 상태 저장과 복원

---
## 작업 내용

- 골드·재료, 설비 단계, 성장 레벨·경험치, 호감도를 저장한다.
- 캐릭터별 체력·정신력·사망 횟수와 남은 회복 횟수를 저장한다.
- 거점 진입과 거점 상태 변경 후 저장을 예약하고 프레임 종료 시 파일을 기록한다.
- 임시 파일에 먼저 기록한 후 기존 파일을 교체한다. 저장 데이터의 버전과 값을 검증한 후 복원한다.
- 세계 해금은 기존 `PlayerPrefs` 기록을 유지하며 거점 저장 파일에 포함하지 않는다.

---
## 검증과 남은 작업

- 임시 파일을 사용해 저장·복원, 파일 교체, 자동 저장, 유효하지 않은 파일 차단을 검증했다.
- 격리된 Unity 프로젝트 복사본에서 전체 EditMode 테스트 148개 통과.
- 사용자 설정 및 세계 해금 기록과 테스트용 저장 파일을 분리했다.
- 이어하기 버튼은 아직 비활성 상태이며 108일차에 연결한다.
- 탐사 중 상태 저장은 아직 구현하지 않았다. 실제 사용자 화면과 독립 실행 빌드는 확인하지 않았다.
