# Project C - 51일차 개발일지

## 1. 개발 목표

51일차는 전투와 탐사 사이에서 아군의 상태가 끊기지 않도록 파티 상태를 영속화하고, 탐사 화면에서 현재 파티원의 생존 상태를 직접 확인할 수 있는 구조를 구축하는 것을 목표로 진행했다.

주요 목표는 다음과 같다.

- 탐사 출전 파티 등록
- 아군 HP 및 정신력 상태 유지
- 전투 종료 후 사망 상태 유지
- 탐사 환경 피해와 파티 상태 직접 연동
- 파티 전멸 시 탐사 실패 처리
- 사망 아군 부활 기능 기반 구축
- 탐사 화면 파티 상태 HUD 추가
- 아군 사망 및 정신력 감소 테스트 카드 추가

---

## 2. 탐사 출전 파티 등록

`30_Exploration` Scene에 `ExplorationPartyLoadoutProvider`를 추가했다.

탐사 Scene에서도 전투 Scene과 동일한 `BattleLoadoutData`를 사용하도록 연결하여 현재 출전 중인 파티를 `BattleResultManager`에 등록한다.

이를 통해 전투에서 사용하는 파티와 탐사 화면에서 표시되는 파티 상태가 동일한 캐릭터 데이터를 기준으로 동작하도록 구성했다.

---

## 3. 파티 상태 영속화

`BattleResultManager`를 확장하여 전투와 탐사 사이에서 아군 상태를 계속 유지하도록 수정했다.

현재 저장하는 상태는 다음과 같다.

- 현재 HP
- 현재 정신력
- 사망 여부
- 탐사 중 사망 횟수
- 현재 출전 파티

전투 종료 시 각 아군의 HP와 정신력을 저장하고, 다음 전투가 시작되면 저장된 상태를 새 `BattleUnitRuntime`에 다시 적용한다.

따라서 한 전투에서 받은 피해나 정신력 감소가 다음 전투에서도 유지된다.

HP가 0이 된 캐릭터 역시 다음 전투에서 사망 상태로 시작하도록 구성했다.

---

## 4. 탐사 파티 상태 HUD

탐사 화면 좌측 하단에 현재 출전 파티의 상태를 표시하는 `ExplorationPartyStatusView`를 추가했다.

각 캐릭터마다 다음 정보를 표시한다.

- 캐릭터 초상화
- 캐릭터 이름
- 현재 HP / 최대 HP
- 현재 정신력
- 사망 상태

사망한 캐릭터는 초상화를 어둡게 표시하고 빨간색 `사망` 문구를 표시하도록 구성했다.

파티 상태가 변경되면 `PartyStateChanged` 이벤트를 통해 HUD가 즉시 갱신되며, 0.2초 간격의 보조 갱신도 함께 사용한다.

---

## 5. 탐사 환경 피해와 파티 상태 연동

기존 퇴색 환경 피해는 다음 전투에 적용할 피해를 누적하는 구조였지만, 51일차부터 실제 탐사 파티의 영구 상태에 즉시 반영하도록 변경했다.

퇴색 지역에서 환경 피해가 발생하면 현재 출전 중인 생존 캐릭터들의 HP와 정신력이 즉시 감소한다.

이미 사망한 캐릭터에게는 추가 환경 피해를 적용하지 않는다.

환경 피해로 마지막 생존 캐릭터까지 HP가 0이 되면 탐사 실패로 처리한다.

실패 원인은 다음과 같이 별도로 기록된다.

`퇴색 환경 피해로 출전 파티가 전멸했습니다.`

---

## 6. 탐사 실패 처리

`ExplorationSessionManager`에 탐사 실패 처리 기능을 추가했다.

파티가 전멸하면 다음 상태가 기록된다.

- 탐사 완료 상태
- 탐사 실패 상태
- 실패한 층
- 실패 시점의 클리어 조우 수
- 실패 원인

전투 결과에서도 생존 아군 수가 0명이면 탐사 실패가 발생한다.

따라서 전투 전멸과 탐사 환경 피해 전멸이 동일한 탐사 실패 흐름으로 연결된다.

---

## 7. 아군 부활 기능 기반 구축

`BattleResultManager`에 저장 상태 기준 부활 기능을 추가했다.

기본 부활 수치는 다음과 같다.

- HP : 최대 HP의 30%
- 정신력 : 10

개발 단계에서 기능을 빠르게 확인할 수 있도록 탐사 화면에서 `F7`을 누르면 첫 번째 사망 아군을 부활시키는 테스트 기능도 추가했다.

부활 시 저장된 HP와 정신력이 변경되고 파티 HUD도 즉시 갱신된다.

---

## 8. 아군 상태 테스트 카드 추가

사망 및 정신력 상태 연동을 직접 검증하기 위한 디버그 카드 2종을 추가했다.

### [DEBUG] 아군 즉사

- 대상 : 단일 아군
- AP : 0
- 효과 : 물리 피해 999,999
- 목적 : 아군 사망 및 전투 이후 사망 상태 유지 확인

### [DEBUG] 아군 정신 붕괴

- 대상 : 단일 아군
- AP : 0
- 효과 : 정신력 -50
- 목적 : 전투에서 변경된 정신력이 탐사 및 다음 전투까지 유지되는지 확인

테스트가 쉽도록 두 카드를 `Deck_Test`에 각각 3장씩 등록했다.

## 10. 테스트 확인 항목

1. `30_Exploration` 진입 시 출전 파티가 좌측 하단 HUD에 표시되는지 확인한다.
2. 각 캐릭터의 HP와 정신력이 정상적으로 표시되는지 확인한다.
3. 전투에서 `[DEBUG] 아군 정신 붕괴`를 사용한 뒤 탐사로 돌아와 감소된 정신력이 유지되는지 확인한다.
4. `[DEBUG] 아군 즉사`를 사용한 뒤 탐사로 돌아와 해당 캐릭터가 사망 상태로 표시되는지 확인한다.
5. 사망 캐릭터의 초상화가 흐려지고 `사망` 문구가 표시되는지 확인한다.
6. 다음 전투에서도 이전 HP·정신력·사망 상태가 유지되는지 확인한다.
7. 탐사에서 `F7` 입력 시 첫 번째 사망 아군이 HP 30%, 정신력 10으로 부활하는지 확인한다.
8. 퇴색 환경 피해가 탐사 파티 HP와 정신력에 즉시 반영되는지 확인한다.
9. 환경 피해 또는 전투로 파티가 전멸했을 때 탐사 실패 상태로 전환되는지 확인한다.
10. Unity Console에 컴파일 오류나 새로운 예외가 발생하지 않는지 확인한다.

---

## 11. 51일차 결과

51일차를 통해 전투마다 초기화되던 아군 상태를 탐사 런 전체에서 유지할 수 있는 기반을 구축했다.

이제 캐릭터의 체력, 정신력, 사망 상태가 탐사와 전투를 오가며 이어지며, 환경 위험 역시 실제 파티 상태에 직접 영향을 준다.

또한 사망 표시 HUD와 부활 기능 기반이 추가되어 이후 치료, 부상, 휴식, 시설 회복 시스템과 연결할 수 있는 파티 생존 관리 구조가 마련되었다.
