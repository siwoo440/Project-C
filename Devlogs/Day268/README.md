# 268일차 유물 확장 · 붕괴 왕좌의 나사부터 무도회의 마지막 박자까지

유물 시트 186~193행의 원화와 효과를 획득, 상점, 도감, 실제 전투와 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 붕괴 왕좌의 나사 | 보스전의 첫 실제 아군 턴에 현재 및 최대 행동력이 각각 2 증가한다. |
| 초상화 속 붉은 눈 | 전투 시작에 35% 확률로 생존 적 전체에게 한 적 턴 동안 공포를 부여한다. |
| 영주의 마지막 명령서 | 첫 두 아군 턴 동안 생존 아군 공격력이 3 증가한다. 이후 이어지는 적 턴 동안 생존 아군의 물리 방어력이 2 감소한다. |
| 거울 공작의 깨진 왕관 | 적이 생존 아군에게 제거 가능한 약화를 부여하면 50% 확률로 해당 적에게 같은 약화를 복제한다. |
| 만찬 심장의 잔뿌리 | 아군 턴 시작에 중독된 생존 적 한 명당 생존 아군 전원이 체력을 2 회복한다. |
| 검은 샹들리에 핵 | 세 번째 아군 턴마다 생존 적 전체에 일반 피해 10을 주고, 그 아군 턴 동안 생존 아군의 명중률이 5%p 감소한다. |
| 고해실의 숨은 이름 | 생존 아군마다 각자 받는 첫 치명 피해에 적용되는 보호를 하나 부여한다. 보호가 발동하면 체력 1로 버틴다. |
| 무도회의 마지막 박자 | 같은 적 턴에 두 번째 아군 회피가 실제로 발생하면 생존 적 전체에 일반 피해 12를 준다. |

숨은 이름은 전투마다 생존 아군별로 한 번의 보호를 부여한다. 두 번째 회피는 실제 회피율로 피한 타격만 집계한다.

---

## 검증

- Unity 검사 32건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건이다.
- Windows 플레이어에서 유물 8종의 회차 저장과 불러오기를 확인했다.
- 실제 보스전에서 첫 아군 행동력이 8/8로 표시됐으며, 첫 아군이 치명 피해 뒤 체력 1로 생존했다. 다른 아군의 보호는 유지됐다.
