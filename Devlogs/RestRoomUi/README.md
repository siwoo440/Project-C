# 탐사 휴식 방

휴식 창에 모닥불 원화와 황동 프레임을 적용했습니다. 왼쪽에 위험도에 따른 회복량과 파티의 HP·정신력을, 오른쪽에 강화할 카드 목록과 스크롤바를 표시합니다. 아래에서 선택 결과를 확인하고 휴식을 실행할 수 있습니다.

모닥불 원화는 내장 이미지 생성으로 제작했습니다. 어두운 지하 석조 쉼터를 넓게 그리고, 오른쪽에 따뜻한 모닥불과 여행 장비를 배치했습니다.

---

## 검증

- 상점 검사 2건을 포함한 Unity 검사 17건이 통과했습니다.
- 실제 탐사에서 F 키로 휴식 방을 열고 목록을 스크롤했습니다. 같은 카드가 두 장 있을 때 선택한 슬롯만 강화됐고, 파티 회복과 자동 저장을 확인했습니다.
- 1600×900과 1280×800에서 촬영했습니다. 완료된 휴식 방의 재사용 차단과 닫을 때 시간 배율 복원도 확인했습니다.
