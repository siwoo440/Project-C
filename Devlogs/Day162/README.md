# 162일차 : 유물 판매 기능 추가

- 상점에서 보유 유물의 판매 목록을 열고 시트의 판매 가격 범위로 정해진 금액에 판매할 수 있습니다.
- 같은 상점의 판매 가격은 저장 후에도 유지되며, 판매 대금은 탐사 중 획득한 골드로 기록됩니다.
- 보유하지 않은 유물, 판매 가격이 없는 유물과 골드 한도를 초과하는 거래는 차단합니다.
- 획득 즉시 영구 효과가 적용되는 유물은 효과 되돌리기가 아직 없어 판매를 막습니다.
- `RelicSalesShop.png`는 화면 확인을 위해 유물 두 종류를 임시로 보유한 실제 판매 목록입니다.
- Unity 편집 모드 검사 325개를 모두 통과했습니다.
