# 262일차 유물 확장 · 찢어진 초대장부터 은제 식탁종까지

유물 시트 162~169행의 원화와 실제 효과를 구매, 도감, 전투 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 찢어진 초대장 | 아군이 적에게 공포를 부여하거나 갱신하면 그 적의 회피율이 한 적 턴 동안 5%p 감소한다. |
| 녹슨 포크 장식 | 아군이 적에게 확률로 부여하는 출혈의 발동 확률을 5%p 높인다. |
| 흐린 거울못 | 아군이 적에게서 받는 첫 제거 가능 약화를 20% 확률로 해당 적에게 부여한다. 전투당 첫 기회에 한 번 판정한다. |
| 낡은 하인 장갑 | 아군이 실제로 체력을 회복할 때 그 아군에게 방어도 3을 추가한다. |
| 고해실의 못 | 실제 정신 피해를 받은 생존 적에게 표식을 부여한다. 그 적의 다음 유효 직접 카드 명중 피해를 3 늘린다. |
| 검은 예배포 | 성배 카드를 사용해 정산한 생존 아군에게 방어도 4를 부여한다. |
| 피 묻은 초상 못 | 청진기·공개·전차 표식이 있는 적에게 적용되는 출혈 피해를 2 높인다. |
| 은제 식탁종 | 전투 중 적 소환을 완료하면 생존 적 전체의 회피율이 두 적 턴 동안 5%p 감소한다. |

검은 예배포의 대상은 성배 카드를 사용한 아군으로 정했다. 거울못은 즉시 정화된 약화 이후에도 첫 기회를 보존한다. 공포와 출혈은 기존 면역 및 약화 수치 범위를 따른다.

최종 Unity 검사 38건이 통과했다. 상점 검사 2건을 포함했고 실패와 건너뜀은 각각 0건이었다. 출혈 검사는 아군 턴 종료에 해제되는 기존 표식과 실제 출혈 시점에 남아 있는 표식을 구분한다. 성배 검사는 플레이 모드 전환 뒤 필수 선택을 준비하고, 선택이 끝나야 사용자가 방어도 4를 얻는지 확인한다.

Windows Direct3D 11에서 유물 8종을 저장·복원했고, 은제 식탁종은 적 소환이 완료되자 두 생존 적의 회피율을 각각 5%p 낮췄다. 두 적 턴을 나타내는 상태도 화면에 표시됐다. [보유 유물 화면](ServantRelics.png) · [소환 후 전투 화면](DiningBellSummonEvasion.png)
