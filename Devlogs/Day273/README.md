# 273일차 펜타클 카드 확장 · 교환 제안부터 기회 포착까지

카드 시트 217~219행과 221~225행의 원화와 실제 효과를 보물 획득, 소유자 선택 및 회차 저장에 등록한다.

| 카드 | 효과 |
| --- | --- |
| 교환 제안 | 손패의 다른 카드 한 장을 골라 버린 뒤 공용 손패에 카드 두 장을 뽑는다. |
| 룬 기록 | 시전자가 다음 실제 사용에서 지불하는 일반 카드의 기본 행동력 비용을 1 낮춘다. 사용 전까지 다음 턴으로 이어진다. |
| 전술 표시 | 지정한 생존 적에게 두 적 턴 동안 기존 표식을 부여한다. |
| 임기응변 | 시전자가 소유한 무작위 일반 등급 카드 하나를 전투 손패에 생성한다. |
| 비상금 | 다음 실제 아군 턴 동안 최대 및 현재 행동력을 각각 1 높인다. |
| 도구 손질 | 지정 아군이 다음에 명중시키는 유효 직접 공격 피해를 4 높인다. |
| 패 정리 | 손패의 다른 카드 한 장 또는 두 장을 선택해 버린 뒤 같은 수만큼 뽑는다. |
| 기회 포착 | 이번 아군 턴 첫 사용 카드가 기회 포착이면 사용 직후 행동력을 1 회복한다. |

손패 선택을 확정하기 전에는 행동력을 지불하지 않는다. 패 정리는 카드 하나를 고른 뒤 한 장으로 확정하거나 다른 카드를 더 고를 수 있다.

## 검증 결과

- Unity 검사 38건 통과. 상점 재고·구매 확인 2건과 기존 카드 선택 UI 검사 3건을 모두 실행했다.
- ‘룬 기록’과 ‘비상금’은 사용자 체력을 유지하고 ‘기회 포착’은 방어도를 유지한다. 행동력과 턴 전환은 카드별 규칙을 확인했다.
- 1600×900 Windows 플레이어에서 ‘패 정리’는 한 장을 골라 한 장을 뽑았고, ‘교환 제안’은 한 장을 골라 두 장을 뽑았다. 두 효과 모두 선택을 확정하고 행동력 1을 지불했다. [한 장 선택](HandSortingOneSelected.png) · [패 정리 완료](HandSortingResolved.png) · [교환 제안 완료](ExchangeProposalResolved.png)
