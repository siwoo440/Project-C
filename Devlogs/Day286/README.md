# 286일차 유물 확장 · 낙석 경고패부터 검은 늪물병까지

유물 시트 269~276행의 효과, 투명 원화, 상점 가격 범위 및 회차 저장을 연결한다.

| 유물 | 효과 |
| --- | --- |
| 낙석 경고패 | 불타는 협곡에서 탐사 함정으로 받는 체력 피해를 15% 줄인다. |
| 흑요석 칼편 | 아군의 검 카드가 생존 적에게 직접 명중하면 적마다 15% 확률로 두 적 턴 동안 출혈 1을 부여한다. 같은 카드의 같은 대상은 한 번 판정한다. |
| 화염 광맥 부스러기 | 아군 카드가 적에게 화상을 실제로 부여하면 다음 적 턴 동안 그 적의 마법 피해 저항률이 5%p 낮아진다. |
| 재먼지 석상 눈 | 전투 중 모든 생존 적의 명중률을 5%p 낮춘다. |
| 돌가시 묶음 | 적의 직접 공격으로 아군의 방어도나 체력이 감소하면 20% 확률로 해당 공격자에게 피해 3을 준다. |
| 협곡 바람피리 | 전투 시작에 생존 아군 전체의 회피율을 실제 적 턴 두 번 동안 8%p 높인다. |
| 젖은 갈대매듭 | 아군이 받는 중독 피해를 최소 0까지 1 줄인다. |
| 검은 늪물병 | 아군 카드의 확률형 중독 부여 성공률을 10%p 높인다. |

탐사와 저장에서 불타는 협곡의 지역 값을 추가했다. 기존 탐사 지역과 조우의 지정은 유지했다. 출혈의 기본 피해량은 1로 정했고 실제 적 턴 종료까지 유지한다. 화염 광맥의 저항률 약화는 기존 침식 약화와 합산한다. 중독의 확정 부여는 기존 확정 동작을 유지한다.

## 검증 결과

Unity EditMode 52건 통과, 실패와 건너뜀 0건. 상점 검사 2건과 협곡 함정 지역 및 중독 적용 검사를 포함했다.

Windows 플레이어에서 유물 8종의 저장 복원과 생존 아군 전원의 회피율 8%p 증가를 확인했다. 적 명중률 87%에서 판정값 86은 적중했고 87은 빗나갔다. 화염 광맥과 협곡 바람은 각각의 독립 상태 아이콘을 사용한다.
