# 83일차 개발일지

---
## 작업 내용

- 바보 선택 시 임시 전용 카드 `바보의 선택` 한 장을 시작 덱에 추가했다.
- 덱 위 최대 두 장의 이름, 소유자, 비용, 설명과 임시 일러스트를 보여주고 한 장을 선택해 드로우한다.
- 후보가 한 장이면 한 장만 표시하며 선택하지 않은 카드는 덱에 남는다.
- 선택 중 다른 카드 사용, 턴 종료와 도주 입력을 잠그고 선택 후 복구한다.
- 카드 사용에 공용 행동력 1을 소비한다.

---
## 검증

- 카드 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 편성부터 전투 진입, 선택 화면, 입력 잠금, 지정 카드 드로우와 카드 보존을 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 95개 통과.

---
## 남은 작업

- 바보의 나머지 전용 카드와 패시브, 개별 카드 일러스트 제작이 남아 있다.
- 카드 이름과 수치는 임시값이며 다른 캐릭터의 전용 능력도 추가해야 한다.
