# 91일차 개발일지

---
## 작업 내용

- 기존 바보·마법사·여사제·여황제 초상화를 일본 애니메이션 서브컬처 스타일로 다시 제작했다.
- 각 캐릭터의 기존 머리색, 의상, 표정과 주요 소품을 참고해 이미지를 교체했다.
- 기존 에셋 식별자를 유지해 거점 편성과 전투 초상화에 적용했다.

---
## 이미지 생성 기준

- 기존 초상화를 참고한 정사각형 상반신 구도, 선명한 선화, 애니메이션식 명암과 판타지 게임 분위기.
- 파일: `Assets/_ProjectC/Art/Portraits/ARC_00.png`~`ARC_03.png`.

---
## 검증

- 초상화 스프라이트가 이미지 전체를 사용하는지 확인하는 검증을 추가했다.
- 별도 프로젝트 복사본에서 전체 캐릭터 에셋 테스트 23개 통과.

---
## 남은 작업

- 나머지 18명과 캐릭터가 등장하는 카드 일러스트의 스타일을 순차 변경한다.
