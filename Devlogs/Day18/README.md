# 18일차 개발일지 - 적 속도 및 행동 순서 시스템 구축

---
## 개발 목표

- 적마다 행동 속도 범위 설정
- 적 턴마다 행동 속도 결정
- 속도와 배치 순서를 기준으로 적 행동 정렬
- 적 행동 예고에 실행 순번과 속도 표시
- 행동 목록 변경 시 남은 순번 자동 갱신

---
## 개발 환경

- Unity 6000.3.21f1
- 테스트 적 최소 행동 속도: 1
- 테스트 적 최대 행동 속도: 10
- 속도 결정 시 최소값과 최대값 포함

---
## 주요 구현 내용

### 1. 적 행동 속도 데이터 추가

- `EnemyData`에 최소 행동 속도와 최대 행동 속도 추가
- 최소 행동 속도를 1 이상으로 보정
- 최대 행동 속도가 최소 행동 속도보다 작지 않도록 보정
- 새 적 데이터도 기본 범위 1~10으로 동작

### 2. 턴별 행동 속도 결정

- 적 행동을 준비할 때 설정 범위 안에서 속도 결정
- 다음 적 행동 준비 시 새로운 속도 산정
- 결정된 속도를 `BattleEnemyAction`에 저장

### 3. 행동 순서 정렬

- 행동 속도가 높은 적을 먼저 배치
- 동속도일 경우 전투의 적 배치 순서 적용
- 추가 난수를 사용하지 않아 동속도 결과 재현 가능
- 정렬 완료 후 1부터 시작하는 행동 순번 부여

### 4. 행동 목록 변경 대응

- 행동을 완료한 적을 예정 목록에서 제거
- 사망한 적의 예정 행동 자동 제거
- 행동할 대상이 없어진 행동 자동 제거
- 목록 변경 후 남은 행동 순번 재지정

### 5. 행동 예고 UI 개선

- 기존 피해 유형, 원본 피해, 예상 피해, 대상 표시 유지
- 행동 순번과 결정된 속도 추가 표시
- 세 줄 정보를 표시할 수 있도록 예고창 높이 확장
- 기존 한글 지원 글꼴과 자동 생성 방식 유지

### 6. 기존 행동 연출 연결 유지

- 정렬된 예정 행동 목록을 17일차 행동 실행기에 전달
- 속도가 높은 적부터 전진, 타격, 피격, 복귀 연출 실행
- 행동 중 사망 및 전투 종료 처리 유지

## 개발 결과

적 행동이 단순 등록 순서가 아니라 턴마다 결정된 속도를 기준으로 실행되도록 개선했다. 동속도 상황에서는 적 배치 순서를 사용해 결과를 예측하고 재현할 수 있으며, 행동 예고에서 실제 실행 순서와 속도를 미리 확인할 수 있다.
