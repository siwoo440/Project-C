# 265일차 지팡이 카드 확장 · 화염 폭우부터 비전 쇄도까지

카드 시트 185~192행의 원화와 실제 효과를 전투, 보물 획득, 도감과 회차 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 화염 폭우 | 매 타격마다 생존 적을 무작위로 골라 마법 피해 5를 최대 6회 준다. 명중한 생존 적에 25% 확률로 화상 2가 두 턴 동안 걸린다. |
| 천둥 감옥 | 생존 적 전체에게 마법 피해 10을 준다. 명중한 생존 적에 40% 확률로 감전 1이 두 적 턴 동안 걸린다. |
| 마력 폭주 | 이번 아군 턴 동안 자신의 지팡이 마법 공격 피해가 50% 증가하고, 사용 뒤 자신의 정신력이 5 감소한다. |
| 공허의 손 | 지정 적에게 마법 피해 16을 준다. 유효하게 명중한 생존 적의 가장 오래된 제거 가능 강화 하나를 제거한다. |
| 별빛 낙인 | 생존 적 전체가 받는 피해를 두 적 턴 동안 10% 늘린다. |
| 환영 분열 | 지정 아군의 회피율을 두 적 턴 동안 25%p 높인다. 다음 유효한 적 직접 피격 피해를 한 번 5 줄인다. |
| 마력 역류 | 생존 적 전체에게 마법 피해 12를 준다. 카드 정산 뒤 이번 아군 턴 동안 자신의 공격력이 2 감소한다. |
| 비전 쇄도 | 고정 행동력 3으로 지정 적에게 마법 피해 24를 준다. 현재 마법 저항력 중 20%를 무시한다. |

마력 역류의 원본에는 약화 수치가 없어 기존 공격 약화 수치인 2를 적용했다. 비전 쇄도는 현재 마법 저항력의 80%를 내림한 값을 피해 정산에 사용한다.

확대된 보물방 표식은 렌더러 없이 생성되는 방에서도 초기화되도록 보정했다. 새 지팡이 카드를 보물방에서 선택하고 원래 소유자로 복구하는 검사에서 확인했다.

## 검증

- Unity 검사 34건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건이다.
- Windows 검증 전투에서 마력 폭주로 정신도 5를 소모하고, 화염 폭우의 여섯 타격에 각각 적용 전 피해 7이 기록되는 것을 확인했다. 두 카드의 공용 행동력 합계는 6이다. 화면의 적은 타격 수와 저항을 재현하는 시험용 편성이다.
