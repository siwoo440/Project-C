# 98일차 개발일지

---
## 작업 내용

- 교황 선택 시 임시 전용 카드 `안전 절차` 한 장을 시작 덱에 추가했다.
- 공용 행동력 1을 사용해 아군 한 명에게 방어 준비를 부여한다.
- 준비는 다음 적의 물리·마법 공격 한 번에 임시 방어력 3을 적용하고, 사용하지 않으면 적 턴 종료 시 사라진다.
- 별도 방어도 시스템 구현 전이므로 기획 초안의 방어도를 임시 방어력으로 대체했다.
- 카드에 기존 임시 공용 일러스트를 사용한다.

---
## 검증

- 카드 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 아군 선택, 적 피해 예고 감소, 실제 피해 일치와 준비 소모를 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 109개 통과.

---
## 남은 작업

- 교황의 반복 훈련 패시브와 나머지 전용 카드, 별도 방어도 시스템이 미구현이다.
- 개별 카드 일러스트와 다른 캐릭터의 전용 능력 구현이 남아 있다.
