# 99일차 개발일지

---
## 작업 내용

- 바보의 선택 카드를 턴당 처음 사용해 두 장 중 한 장을 가져오면 남은 카드의 처리 방법을 고르게 했다.
- 남은 카드를 덱 맨 위에 유지하거나 버린 카드 더미로 보낼 수 있다.
- 모든 선택이 끝날 때까지 손패와 턴 종료 입력을 잠그고, 같은 턴에는 패시브가 다시 발동하지 않는다.

---
## 검증

- 패시브 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 남은 카드 유지·버리기, 맨 위 카드 검증, 턴당 한 번 제한과 카드 보존을 확인했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 111개 통과.

---
## 남은 작업

- 바보의 나머지 전용 카드와 개별 카드 일러스트, 다른 캐릭터 전용 능력 구현이 남아 있다.
