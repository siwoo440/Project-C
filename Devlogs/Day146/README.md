# 146일차: 이벤트·유물 점검과 유물 초기 구현

- 시제품 목표는 이벤트 6~8개와 유물 약 15종이다. 별도 기획에는 윈터폴 이벤트 8개와 유물 298종이 있으나, 기존 게임의 이벤트 3개와 유물 2개는 테스트용이므로 완성 수량에서 제외했다.
- 별도 유물 시트에서 현재 효과를 검증할 수 있는 유물 4종을 구현하고 상점·보물 후보 및 탐사 저장 복원 목록에 연결했다.
- `잿빛 인장`: 사용자가 확인한 대로 전투 시작 시 생존 아군에게 방어도 총 6을 순서대로 배분한다.
- `깨진 멜로디 박스`: 전투 시작 시 아군 전체 정신력 +1. `청동 향로`: 아군 전체 마법 저항력 +1을 1턴 적용. `부유석 조각`: 무작위 생존 아군 1명에게 방어도 8을 부여한다.
- 상품 가격은 기획 시트의 구매 범위 안에서 각각 220·320·300·270 골드로 임시 설정했다. 유물 아이콘 4개를 제작하고 실제 상품에 연결했다.
- 네 유물의 효과와 중복 구매 방지, 실제 상점 구매 및 탐사 저장 복원을 검증했다. [실제 유물 상점 화면](PrototypeRelicShop.png)과 [잿빛 인장 화면](PrototypeRelicShopUpper.png)에서 상품과 아이콘을 확인했다.
- Unity 전체 EditMode 테스트 270개가 통과했다. 저장 복원한 유물이 실제 다음 전투에서 발동하는 추가 검사도 통과했다.

## 남은 작업

- 시제품 목표 약 15종 중 실제 유물은 4종이다. 나머지 약 11종은 기획 시트에서 선정하고 효과·획득·저장 흐름을 구현해야 한다.
- 윈터폴 기획 이벤트 8개는 아직 연결되지 않았다. 현재 이벤트 선택지는 골드·나사·철판·전선 증감만 지원하므로 체력·정신력, 유물·카드 획득, 전투 분기와 같은 결과 처리가 필요하다.
- 유물별 보물 획득 확률과 상품 가격, 전투 효과의 밸런스는 실제 플레이를 통해 조정해야 한다.
