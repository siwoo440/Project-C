# 224일차 검 카드 확장 · 치명 일격부터 파멸의 검까지

| 카드 | 행동력 | 효과 |
| --- | ---: | --- |
| 치명 일격 | 2 | 선택한 적에게 물리 피해 15. 이 공격의 치명타 확률 +20%p. |
| 검의 춤 | 3 | 선택한 칸과 이웃 칸의 생존 적 중 하나를 타격마다 다시 뽑아 총 3회, 각 물리 피해 6. 같은 적이 다시 뽑힐 수 있다. |
| 돌진 | 1 | 선택한 적에게 물리 피해 7. 명중한 적은 다음 아군 턴에 물리 방어 −2. |
| 역공 | 2 | 직전 적 턴 시작부터 사용 시점까지 카드 소유자가 받은 실제 체력 피해의 절반을 선택한 적에게 준다. 소수점 이하는 버린다. |
| 최후의 일격 | X | 적의 체력이 최대치의 20% 이하일 때 남은 행동력 X를 사용해 X×5의 물리 피해를 준다. |
| 전의 고취 | 1 | 생존 아군 전체의 치명타 확률 +5%p, 2턴 지속. |
| 화염 참격 | 2 | 적 하나에게 물리 피해 10과 화상. |
| 파멸의 검 | 4 | 적 하나에게 물리 피해 25, 소유자 체력 10 소모. |

기본 치명타 확률은 0%이며 치명타 피해는 1.5배다. 검의 춤은 대상 칸과 오른쪽 칸을 범위로 삼고 오른쪽 끝에서는 왼쪽 칸을 사용한다. 범위 안의 적이 모두 쓰러지면 남은 타격은 종료한다. 모든 카드는 보물에서 보상을 받을 생존 파티원을 선택해 해당 덱에 추가한다.

Windows 플레이어에서 검의 춤을 사용해 잿빛 방랑자에게 기본 피해 6을 세 번 적용했다. 적 방어를 계산한 실제 피해는 5·5·5였고 체력은 50에서 35로 줄었다. 행동력은 6에서 3으로 한 번만 차감됐다. 전투 규칙·보물 소유자 선택·저장·아이콘을 포함한 관련 Unity 검사 36건이 통과했다.
