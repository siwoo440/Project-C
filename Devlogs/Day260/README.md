# 260일차 유물 확장 · 공허 순환장치부터 금 간 접시 장식까지

유물 시트 154~161행의 효과와 원화를 실제 획득, 구매, 도감과 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 공허 순환장치 | 전투 중 아군이 실제 체력을 잃으면 15% 확률로 현재 행동력 1을 회복한다. 행동력 최대치를 따른다. |
| 붉은 심연의 등잔 | 생존 적 전체의 공격력을 두 적 턴 동안 2 낮춘다. 생존 아군 전체의 정신력은 5 낮아진다. |
| 네크레이트 왕관못 | 보스에 직접 명중으로 주는 피해가 20% 늘어난다. 일반 전투에서 적에게 직접 받는 피해가 10% 늘어난다. |
| 어비스 성배 조각 | 전투마다 처음 쓰러진 아군이 최대 체력의 30%로 부활한다. 이어서 생존 아군 전체의 정신력이 10 낮아진다. |
| 무명자의 검은 서약 | 전투 동안 아군 공격력 5를 얻는다. 승리하거나 도주하면 각 생존 아군이 이미 잃은 체력의 20%를 추가로 잃고 최소 체력 1을 유지한다. |
| 침식핵의 작은 심장 | 정예나 보스를 처치할 때마다 이번 탐사에서 아군의 영구 공격력이 1 늘어난다. 기존 회차 저장에서 추가 필드가 비어 있으면 0부터 시작한다. |
| 먼지 먹은 손수건 | 첫 적 턴이 끝날 때까지 적이 거는 실명에 대한 아군 저항이 20%p 늘어난다. |
| 금 간 접시 장식 | 전투 시작에 무작위 생존 적 한 명의 공격력을 두 적 턴 동안 1 낮춘다. |

등잔의 원본 시트에 약화 수치가 없어 기존 탐사 유물의 공격력 감소 수치 2를 적용했다. 등잔과 접시 장식이 같은 적에게 적용되면 기존 동일 상태의 갱신 규칙을 따른다. 성배 부활 체력은 올림, 서약의 전투 종료 체력 손실은 내림으로 정산한다.

Unity 검사 29건이 통과했다. 상점 검사 2건을 포함했고 실패와 건너뜀은 각각 0건이었다. Windows Direct3D 11에서 유물 8종을 획득하고 순서 그대로 저장·복원했다. 등잔과 서약을 함께 보유한 전투에서는 생존 아군 전원의 정신력이 50에서 45로 내려갔고 공격력 5를 얻었다. 적의 공격력 감소 2는 두 적 턴 동안 적용됐다. [보유 유물 화면](AbyssOathRelics.png) · [전투 시작 화면](AbyssLampOpening.png)
