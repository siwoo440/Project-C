# 213일차 검게 탄 우물

윈터폴 탐사의 새 층에 ‘검게 탄 우물’을 추가했다. 세 선택 모두 살아 있는 출전 파티원 한 명을 지정한다. 불탄 수레까지 포함한 이전 층의 이벤트 배치는 저장 당시 구성을 유지한다. [기획서 5.2.11 검게 탄 우물](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.wi4rzj33f2lg)

| 행동 | 선택한 생존자와 탐사에 적용되는 결과 |
| --- | --- |
| 재를 파낸다 | 체력 5를 잃고 소모품 빈칸에 기존 체력 회복 포션 한 개를 넣는다. 빈칸이 없으면 체력과 사건을 보존한다. |
| 물을 뜨려 한다 | 정신력 6을 잃고 회복 효과 한 번을 보관한다. 해당 생존자가 실제 전투에서 체력 피해를 받고 살아남으면 즉시 자신의 체력 8을 회복한다. |
| 우물을 봉인한다 | 정신력 4를 회복한다. 다음 층에서 처음 뽑힌 ‘재폭풍의 눈’에 한해 15% 확률로 그 층의 다른 이벤트가 배치된다. |

방어도가 전부 흡수한 피해, 다른 파티원의 피해, 사망에 이른 피해로는 물 효과를 소모하지 않는다. 봉인은 교체 성공과 실패 모두 첫 판정에서 소모된다. 같은 시드로 지도를 복원하면 그 결과를 다시 보여 준다. 판정을 마친 뒤 F9로 다른 시드의 지도를 뽑아도 봉인이 돌아오지 않는다. 다음 층에 재폭풍의 눈이 나오지 않으면 그 층을 떠날 때 봉인이 끝난다.

사용 전인 물 효과는 생존자당 한 번, 다음 층 봉인은 파티당 한 번 보관한다. 이미 보관한 효과를 다시 고르면 비용을 지불하지 않고 다른 행동을 선택할 수 있다.

## 검증

Unity EditMode에서 우물 전용 검사 4개와 기존 회귀 검사 7개가 모두 통과했다. 파괴된 임시 이벤트 원본이 남은 카탈로그를 다시 열었을 때 같은 식별자의 원본을 복구하는 경우도 확인했다.

- 실제 행동자 선택 취소, 가득 찬 소모품 보관함, 포션 원본 지급·저장·복원, 마지막 생존자의 체력 비용을 검사한다.
- 물을 보관하기 전후의 캐릭터 정신력, 실제 피해·완전 흡수·치명타격, 한 번 회복한 뒤의 피해와 저장 상태를 대조한다.
- 봉인 방 시드 128개로 15% 판정의 두 결과와 두 번째 재폭풍 보존을 확인한다. 지도 생성기가 호출하는 판정 함수에 임시 배치, 최종 배치, 같은 시드 복원, 다른 시드 재생성을 입력한다. 별도 탐사 파일로 판정 전후의 복원 결과도 대조한다.
