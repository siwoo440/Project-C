# 290일차 카드·유물 통합 점검

카드 시트 251종과 유물 시트 298종을 정규 저장 카탈로그와 대조한다. 전체 카드와 유물을 실제 회차에 함께 획득한 뒤 저장하고, 다시 불러와 카드 순서·소유자·강화 단계와 유물 목록 및 탐사 시드가 그대로 복원되는지 확인한다. 유물마다 재획득 시 중복 보상으로 처리되는지도 점검한다.

다섯 카드 계열을 아우르는 실제 전투를 실행해 카드 비용과 환급, 상태 부여, 반격 및 처치 유물, 승패 정산을 확인한다. 구형 탐사 및 거점 저장을 로드하고 현재 형식으로 재저장한다. 도감의 전체 목록과 스크롤 시 셀 재사용, 썸네일 지연 로드, 첫 화면과 재진입 비용을 Windows 플레이어에서 측정한다.

---

## 검증 결과

Unity EditMode 39건 통과, 실패와 건너뜀 0건. 상점 검사 2건과 저장 슬롯·복구본·탐사 자동 저장을 포함했다. 카드 251종과 유물 298종을 실제 회차에 획득한 뒤 각각 복원했고 유물 298종에 대한 중복 획득 보상도 확인했다. 카드 순서, 소유자, 강화 값과 탐사 시드가 유지됐다.

110일차와 246일차 저장에서 구역 필드가 생략되어 Unity가 빈 구역 객체를 만들면 윈터폴 기본값으로 복원하도록 수정했다. 현재 파일로 재저장한 뒤 다시 복원했고, 손상된 카드 ID·강화 값·유물 중복 기록은 활동 중인 회차를 바꾸지 않고 거절됨을 확인했다. 다섯 계열의 카드가 함께 사용되는 실제 전투와 동시 전투불능 정산도 검사했다.

| Windows 도감 | 원본 이름 일치 | 화면 항목 수 | 첫 입력부터 프레임 표시까지 | 같은 목록 재진입 중앙값 | 물리 셀 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 카드 | 251/251 | 310 | 48.420 ms | 2.083 ms | 36 |
| 유물 | 298/298 | 300 | 27.653 ms | 2.795 ms | 36 |

Direct3D 11, 1600×900의 한 실행에서 카드와 유물 순으로 방문하고 각각 5번 재진입했다. 목록 시작·중간·끝에서 동일한 셀 36개를 재사용했다. 스크롤에 따라 보이는 썸네일이 바뀌었고, 원본 이미지는 상세 선택 후에 로드됐다. 목록에는 이전부터 있던 시트 외 항목도 포함된다.
