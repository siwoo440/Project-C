# 228일차 유물 확장 · 실험용 포션보관대부터 유리 지팡이 심까지

| 유물 | 발동 조건과 효과 |
| --- | --- |
| 실험용 포션보관대 | 포션 전용 슬롯을 하나 추가한다. 추가 칸이 차 있으면 판매 시 포션을 빈 기본 칸으로 옮긴다. 기본 칸에 자리가 없으면 판매할 수 없다. |
| 기름 묻은 렌치 | 체력 회복 포션이 원래 회복시킬 대상마다 회복량을 2 늘린다. |
| 청동 경보장치 | 적 턴 시작 시 무작위 생존 적 한 명의 직접 공격 피해를 이번 턴 동안 1 줄인다. |
| 푸른 봉합사 | 체력 회복 카드를 쓴 캐릭터가 방어도 3을 얻는다. 턴당 한 번이며 회복 대상의 체력이 가득 차도 발동한다. |
| 고장난 시계 | 아군의 3·6·9번째 턴처럼 세 번째 아군 턴마다 카드 1장을 추가로 뽑는다. |
| 희미한 성배 조각 | 성배 카드를 쓴 캐릭터의 체력을 1 회복한다. 턴당 두 번 발동한다. |
| 녹슨 검집 | 턴마다 첫 검 피해 카드에서 처음 적중한 직접 타격 한 번에 피해 2를 더한다. |
| 유리 지팡이 심 | 턴마다 첫 지팡이 마법 피해 카드에서 처음 적중한 직접 타격 한 번에 피해 2를 더한다. |

Windows 플레이어에서 보관대를 소유했을 때 기본 두 줄 아래에 추가 슬롯이 생기는 것을 확인했다. Unity 검사에서는 기존 열 칸 저장, 열한 번째 포션의 체크포인트 복원, 모든 칸을 채운 상태에서의 보관대 판매 차단, 빈 기본 칸을 만든 뒤 판매하면 포션이 옮겨지는 경로를 확인했다.

신규 유물과 기존 전투·상점 검사를 합쳐 42건이 통과했다. 검과 지팡이의 추가 피해가 각각 첫 적중 한 번에만 적용되는 것과 정신력 전용 포션에는 렌치가 발동하지 않는 것도 확인했다.
