# Project C - 37일차 개발일지

## 작업 주제

탐사 계단 및 층 진행 시스템 구축

## 개발 목표

- 36일차에 구현한 절차적 논리 맵에 실제 층 진행 기능 연결
- 현재 탐사 층 데이터 관리
- 계단 Trigger를 통한 다음 층 이동
- 층 이동 시 새로운 절차 맵 생성
- 새로운 층의 시작 지점으로 플레이어 재배치
- 연속 Trigger로 인한 다중 층 이동 방지
- 현재 층 정보를 디버그 맵에 표시

## 구현 내용

### 1. 현재 탐사 층 데이터 추가

`ExplorationSessionManager`에 현재 탐사 층을 관리하는 `currentFloor` 값을 추가했다.

탐사는 기본적으로 1층에서 시작하며 계단을 사용할 때마다 다음과 같이 증가한다.

- 1F → 2F
- 2F → 3F
- 3F → 4F

현재 층 데이터는 탐사 세션 관리자에서 유지되므로 향후 층별 난이도와 조우 구성에 활용할 수 있다.

### 2. 다음 층 진행 기능 구현

`ExplorationSessionManager`에 `AdvanceFloor()` 기능을 추가했다.

다음 층으로 진행할 때 다음 상태를 처리한다.

- 현재 층 +1
- 진행 중 조우 초기화
- 이전 층의 전투 복귀 위치 초기화
- 전투 복귀 위치 사용 여부 초기화
- 이전 전투 보상 표시 초기화

탐사를 완전히 초기화할 경우 현재 층도 다시 1층으로 돌아가도록 구성했다.

### 3. 임시 계단 오브젝트 구현

`ExplorationFloorStairs`를 새로 추가했다.

계단은 다음 구성으로 런타임에서 자동 생성된다.

- SpriteRenderer
- CircleCollider2D
- ExplorationFloorStairs

계단 Collider는 Trigger 방식으로 동작하며 `ExplorationPlayerController`를 가진 플레이어가 접촉했을 때만 층 이동을 요청한다.

### 4. 계단 위치와 논리 맵 연결

36일차에서 생성된 `StairsCoordinate`를 실제 월드 좌표로 변환하는 기능을 추가했다.

현재는 실제 Tilemap 전 단계이므로 논리 맵의 전체 크기를 플레이 가능한 임시 월드 범위에 맞춰 변환한다.

이를 통해 논리 맵에서 `▼`로 지정된 셀과 실제 노란색 계단 오브젝트가 대응하도록 구성했다.

### 5. 계단 시각화

계단은 현재 프로토타입 확인을 위해 노란색 사각형으로 표시한다.

계단 위치는 새 맵이 생성될 때마다 현재 맵의 `StairsCoordinate`에 맞춰 자동으로 갱신된다.

별도의 Prefab이나 Inspector 연결 없이 런타임에서 생성된다.

### 6. 플레이어 순간 이동 기능 추가

`ExplorationPlayerController`에 `Teleport()` 기능을 추가했다.

층 이동 시 다음을 처리한다.

- 기존 이동 입력 초기화
- Rigidbody2D 위치 변경
- 기존 물리 속도 초기화
- Transform 위치 동기화

이를 통해 새로운 층이 생성된 직후 플레이어를 새 맵의 시작 지점으로 즉시 이동시킬 수 있다.

### 7. 새 층 시작 위치 배치

새로운 층으로 이동하면 현재 맵의 `StartCoordinate`를 월드 좌표로 변환한 뒤 플레이어를 해당 위치로 이동시킨다.

최초 탐사 진입에서도 전투 복귀 상황이 아닌 경우 시작 셀 위치에 플레이어가 배치된다.

기존 전투 후 탐사 복귀 상태가 존재할 경우에는 기존 복귀 위치를 우선 유지한다.

### 8. 계단을 통한 층 이동 흐름 연결

플레이어가 계단에 접촉하면 다음 순서로 처리한다.

1. 계단 Trigger에서 플레이어 감지
2. `TryDescendFloor()` 호출
3. 현재 층 증가
4. 새로운 Seed 생성
5. 새로운 14셀 절차 맵 생성
6. 새로운 계단 위치 갱신
7. 플레이어를 새 시작 셀 위치로 이동

이를 통해 하나의 `30_Exploration` Scene 안에서 계속해서 다음 층을 생성하며 진행할 수 있도록 했다.

### 9. 연속 층 이동 방지

계단 Collider에 계속 접촉하면서 여러 층이 연속으로 증가하는 상황을 막기 위해 층 이동 쿨다운을 추가했다.

현재 한 번 층을 이동하면 짧은 시간 동안 추가 층 이동 요청을 무시한다.

### 10. 디버그 맵 현재 층 표시

`ExplorationMapDebugView`를 37일차 기준으로 수정했다.

디버그 패널에서 다음 정보를 확인할 수 있다.

- 현재 층
- 현재 Seed
- 시작 셀
- 계단 셀
- F9 맵 재생성 안내
- 실제 계단 오브젝트 안내

예시:

```text
37일차 절차 맵 | 2F | Seed ...
S 시작 / ▼ 계단 / F9 새 맵
노란 사각형 접촉 : 다음 층
```

### 11. F9 디버그 재생성 유지

기존 F9 기능은 그대로 유지했다.

F9를 누를 경우 현재 층 값은 증가하지 않고 현재 층의 논리 맵과 계단 위치만 새로 생성된다.

## 현재 단계의 제한 사항

37일차에서는 층 이동 구조만 구현한다.

아직 다음 기능은 포함하지 않는다.

- 층마다 조우를 절차적으로 다시 배치하는 기능
- 현재 층의 Seed와 셀 상태를 전투 전후로 완전히 보존하는 기능
- 실제 Tilemap 기반 탐사 맵
- 층별 난이도 상승
- 일반·엘리트·보스 층 구분

이 기능들은 이후 탐사 시스템 개발 단계에서 순차적으로 연결한다.

## 완료 결과

37일차를 통해 36일차의 단일 절차 맵 생성 기능을 여러 층을 연속해서 탐사할 수 있는 진행 구조로 확장했다.

플레이어는 현재 층의 계단에 접촉하여 다음 층으로 이동할 수 있으며, 층이 변경될 때 새로운 절차 맵과 계단이 생성되고 플레이어는 새 시작 위치에 배치된다.

이를 통해 이후 절차적 조우 배치, 층 상태 보존, Tilemap 생성, 층별 난이도 시스템을 연결할 수 있는 기본 탐사 층 진행 구조가 마련되었다.
