# 84일차 개발일지

---
## 작업 내용

- 전차 선택 시 임시 전용 카드 `전차의 돌파` 한 장을 시작 덱에 추가했다.
- 적 하나에게 물리 피해 6을 주고 이번 턴에 유지되는 표식을 남긴다.
- 표식 대상에게 전차가 후속 공격을 하면 방어와 약점 계산 전 원본 피해가 3 증가한다.
- 새 대상에게 표식을 주면 이전 표식이 사라지며, 적의 상태 면역은 표식을 막는다.
- 카드에 기존 임시 공용 일러스트를 사용한다.

---
## 검증

- 카드 연결 전 테스트 실패와 연결 후 성공을 확인했다.
- 실제 전투에서 표식 적용과 같은 적에 대한 후속 추가 피해를 확인했다.
- 표식의 적 턴 시작 만료와 상태 면역 차단을 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 97개 통과.

---
## 남은 작업

- 전차의 나머지 전용 카드와 패시브, 개별 카드 일러스트 제작이 남아 있다.
- 카드 이름과 수치는 임시값이며 다른 캐릭터의 전용 능력도 추가해야 한다.
