# 249일차 성배 카드 확장 · 진정부터 상처 봉합까지

카드 시트 116·117·118·119·120·121·122·124행의 원본 그림과 전투 효과를 연결하고 보물 보상과 회차 저장에 등록한다.

| 카드 | 효과 |
| --- | --- |
| 진정 | 지정 아군의 공포를 해제하고 정신력을 4 회복한다. |
| 성수 뿌리기 | 적 하나에게 마법 피해 5를 준다. 명중한 적이 불사형이면 피해 5를 추가한다. |
| 회복 기도 | 현재 체력 수치가 가장 낮은 생존 아군을 자동 선택해 체력 8을 회복한다. |
| 정화의 손길 | 선택한 아군의 제거 가능한 디버프 하나를 해제하고 다음 적 턴의 마법 피해 저항을 5% 높인다. |
| 잔잔한 축복 | 선택한 아군이 받는 체력 회복량을 2턴 동안 20% 높인다. |
| 빛의 조각 | 지정 적에게 마법 피해 6을 주고 지정 아군을 체력 3만큼 회복한다. |
| 재생 | 지정 아군은 이번 아군 턴부터 아군 턴 종료마다 체력 5를 총 세 번 회복한다. |
| 상처 봉합 | 지정 아군의 모든 출혈을 해제하고 체력을 14 회복한다. |

회복 기도는 현재 체력 수치를 비교하며 같은 수치는 배치 순서로 처리한다. 성수 뿌리기는 적 데이터의 불사형 속성을 확인한다. 알려진 기존 적 원본은 작성된 분류를 사용한다. 빛의 조각의 체력 회복은 공격 결과와 독립적으로 처리되며 마지막 적 처치 시에도 적용된다. 정화의 손길의 일시적 마법 저항은 다음 적 턴의 종료 시점까지 적용한다.

## 검증과 실제 화면

Unity EditMode 검사 32건이 통과했다. 실패와 건너뜀은 각각 0건이며 상점 진열 및 구매 확인 검사 2건이 포함됐다. Windows 독립 실행 플레이어에서 다음 화면을 1600×900으로 촬영했다.

- `LightFragmentChooseAlly.png`에서 적을 선택한 뒤 회복할 아군을 고르는 두 번째 대상 선택을 확인했다.
- `LightFragmentResolved.png`에서 기본 마법 피해 6이 방어 적용 뒤 5로 정산됐고, 마법사의 체력이 71에서 74로 올랐다. 행동력은 6에서 5로 줄었다.
- `HealingPrayerLowestAlly.png`에서 회복 기도가 현재 체력이 가장 낮은 마법사를 자동으로 선택해 체력을 74에서 82로 회복했다.
