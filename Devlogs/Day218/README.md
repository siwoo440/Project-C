# 218일차 탐사 이벤트 선택지 스크롤과 본문 배경

이벤트에서 선택지는 한 번에 세 줄까지 보인다. 네 번째 줄부터는 마우스 휠, 목록 드래그 또는 오른쪽 금색 손잡이로 이동한다. 결과 화면을 열면 목록이 첫 줄로 돌아가고, 한 화면에 들어오는 목록에서는 손잡이를 숨긴다.
