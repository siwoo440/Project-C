# 270일차 유물 확장 · 잠들지 않는 저택의 심지부터 사막왕의 부서진 팔찌까지

유물 시트 194~199행 및 201~202행의 원화, 효과, 구매와 저장을 연결한다.

| 유물 | 효과 |
| --- | --- |
| 잠들지 않는 저택의 심지 | 성채 조우 시작에 생존 아군 전원에게 방어도 15를 부여한다. |
| 사막 유리조각 팔찌 | 사막 조우에서 적이 거는 실명에 대한 아군 저항이 15%p 증가한다. |
| 마른 물주머니 끈 | 전투가 승리 또는 도주로 끝날 때 생존 아군 전원이 체력 2를 회복한다. |
| 모래 묻은 뼛조각 | 전투에서 출혈 중인 적에게 처음으로 명중한 유효 직접 카드 타격 피해가 2 증가한다. |
| 풍화된 발자국석 | 사막 이벤트에서 실제로 고른 선택지의 체력 피해를 20% 줄인다. |
| 검은 모래병 | 아군이 적에게 확률로 거는 실명의 발동 확률을 5%p 높인다. |
| 카라반의 낡은 저울 | 보유 중 상점에서 유물 구매가 성공할 때마다 다음 전투의 첫 실제 아군 턴에 드로우 한 장을 예약한다. |
| 사막왕의 부서진 팔찌 | 전투 시작에 무작위 생존 적 한 명의 공격력을 두 적 턴 동안 2 낮춘다. |

상점 드로우 보상은 사용하기 전까지 회차 저장에 남는다. 사막·성채 발동은 조우와 이벤트에 명시된 구역 설정으로 구분한다.

---

## 검증

- 상점 검사 2건을 포함한 Unity 검사 35건 통과. 실패와 건너뜀은 0건이다.
- Windows 플레이어에서 신규 유물 8종을 저장하고 불러왔다. 실제 상점에서 유물 구매 뒤 드로우 1장이 예약됐고, 불러온 회차의 첫 아군 손패에 카드 9장이 표시됐다.
