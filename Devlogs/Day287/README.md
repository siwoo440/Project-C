# 287일차 유물 확장 · 거머리 이빨목걸이부터 재의 봉인문양까지

유물 시트 277~284행의 원화, 전투 효과, 상점 가격 및 회차 저장을 연결한다.

| 유물 | 효과 |
| --- | --- |
| 거머리 이빨목걸이 | 단일 대상 공격 카드로 실제 감소시킨 적 체력의 5%를 사용자에게 회복한다. 소수점은 버린다. |
| 진흙 부적 | 명시 효과로 행동력이 실제로 줄어든 생존 아군이 방어도 5를 얻는다. |
| 안개 꽃가루 | 전투 시작에 30% 확률로 무작위 생존 적 한 명에게 다음 적 턴 동안 실명을 부여해 명중률을 25%p 낮춘다. |
| 화산암 거한의 손가락 | 전투 중 체력이 최대 체력의 절반 이하인 생존 아군의 물리 방어력을 4 높인다. |
| 흑요석 참수면 | 아군이 출혈 중인 적을 처치하면 나머지 생존 적에게 각각 일반 피해 6을 준다. 한 차례의 파편 피해로 같은 효과가 다시 발동하지 않는다. |
| 용암맥 수호핵 파편 | 실제 아군 턴이 시작되면 25% 확률로 화상 중인 생존 적마다 그 턴에 쓸 행동력 1을 얻는다. |
| 붉은 협곡 방벽석 | 생존 아군 전체가 전투 시작에 방어도 10을 얻는다. 첫 아군 턴의 기본 드로우는 한 장 줄어든다. |
| 재의 봉인문양 | 전투 중 아군의 마법 피해 경감률을 10%p 높이고 받는 체력 회복량을 5% 낮춘다. |

실명의 강도는 명중률 25%p 감소로 정했다. 용암맥 수호핵 파편은 턴마다 한 번 판정하고, 성공한 턴에만 가용 행동력과 상한을 함께 높인다.

---

## 검증 결과

Unity EditMode 36건 통과, 실패와 건너뜀 0건. 상점 검사 2건과 실제 체력 흡수, 출혈 처치 파편의 재발동 방지를 검증했다.

Windows 플레이어에서 유물 8종을 저장하고 복원했다. 붉은 협곡 방벽석이 첫 턴에 생존 아군 네 명에게 방어도 10씩을 부여하고 기본 손패가 7장으로 줄어드는 장면을 확인했다.
