# 63일차 개발일지

---
## 작업 내용

- 아르카나 22명의 기본 캐릭터 데이터를 참조하는 공용 목록을 추가했다.
- 거점 화면에서 공용 목록을 불러올 수 있도록 Resources 에셋으로 연결했다.
- 외부에서 목록을 직접 수정하지 못하도록 읽기 전용으로 제공한다.

---
## 검증

- 공용 목록 리소스의 부재를 테스트로 확인한 뒤 에셋을 추가했다.
- Unity에서 22명 참조와 ARC_00~ARC_21 순서가 읽히는지 확인했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 57개 통과.

---
## 남은 작업

- 거점 편성 화면과 공용 목록을 연결해야 한다.
- 세계의 해금 조건과 캐릭터별 전용 카드·패시브는 아직 구현되지 않았다.
