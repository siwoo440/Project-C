## 작업 내용

- 기존 황제·교황·연인·전차 초상화를 일본 애니메이션 서브컬처 스타일로 다시 제작했다.
- 각 캐릭터의 머리색, 나이 인상, 의상과 상징 소품을 기존 초상화에 맞췄다.
- 기존 에셋 식별자를 유지해 거점 편성과 전투 초상화에 적용했다.

- 파일: `Assets/_ProjectC/Art/Portraits/ARC_04.png`~`ARC_07.png`.
