# 134일차: 파티 프로필 드래그와 순서 표시

- 파티 프로필을 화면 너비에 맞는 세 열로 확대하고 스크롤할 수 있도록 조정했다.
- 왼쪽부터 4·3·2·1번인 편성 칸과 각 선택 프로필의 번호를 표시했다.
- 드래그로 빈 칸에 배치하고 편성된 캐릭터끼리 자리를 바꾸거나 새 캐릭터로 교체할 수 있다.
- 빈 칸과 배치 위치를 저장하며, 이전 저장은 기존 출전 순서를 유지해 번호별 위치로 복원한다.
- `PartyFormation.png`는 격리된 검증 프로젝트의 실제 로비에서 맵 선택 후 촬영한 화면이다.
- 파티 편성과 저장 호환성 관련 Unity 검사 13개가 통과했다.
- Unity 전체 EditMode 회귀 검사 218개가 통과했다.
