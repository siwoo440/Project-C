# 월드맵과 지역별 탐사

기획서 ‘4.1 콘텐츠’의 순서에 따라 윈터폴 잿빛 벌판, 금 간 대지, 부식된 산업 지구, 퇴색의 사막, 불타는 협곡, 지하 벙커 Δ-12, 붕괴된 성채, 공백지대를 월드맵에 배치했다. 지도에서 지역을 선택하면 현재 진행률, 보스 예약, 해금 조건과 출발 난이도를 확인할 수 있다. 잠긴 지역의 상세 정보도 열 수 있으며, 출전 가능 여부를 편성 화면에서 재확인한다. 이전 저장의 탐사 지역은 윈터폴로 복원된다.

지역마다 바닥과 벽 무늬를 각각 네 종으로 제작했다. 기존 연결 벽 모양과 충돌 규칙을 재사용한다. 같은 지도의 시드는 지형 구조를 유지하며, 해당 지역의 재질과 조우를 선택한다. 새 지역 일곱 곳에 일반·정예·보스 적을 각각 연결했다. 전투에서 사용할 몬스터 원화 21종을 왼쪽으로 그렸고, 기존 윈터폴 적도 이미 연결된 좌향 원화를 사용한다. 실제 전투 크기에서 외곽과 잔무늬가 부드러워지도록 가져오기 설정을 조정했다.

구역별 진행률과 보스 기록을 저장한다. 협곡 보스 처치 보상에 구역 식별 코드를 연결했고, 성채 공략 뒤의 원정 기록 보고를 공백지대 해금에 사용했다. 세부 환경 기믹과 전용 보상표는 기획서에 남아 있다. 이번 구현은 기존 전투 행동을 사용하며 선택 구역 레벨에 맞춰 적 체력과 공격력을 조절한다.

## 검증

- Unity 검사 25건 전부 통과. 실패와 건너뜀 각 0건. 상점 검사 2건 포함.
- Windows Direct3D 11에서 월드맵 두 해상도, 새 지역 일곱 곳의 바닥·벽 표시와 충돌, 금 간 대지의 저장 복원, 불타는 협곡의 실제 전투 진입과 몬스터 원화를 확인했다.
