# 89일차 개발일지

---
## 작업 내용

- 생존한 마법사가 파티에 있을 때 턴당 첫 버린 카드 회수의 AP 비용을 1 낮추는 임시 패시브를 추가했다.
- 할인은 최소 0이며 플레이어 턴 종료 시 사라지고 다음 턴에 다시 발동한다.
- 손패 비용 표시와 실제 카드 사용 비용에 할인값을 반영한다.

---
## 검증

- 패시브 구현 전 테스트 실패와 구현 후 성공을 확인했다.
- 첫 회수만 할인, 다음 턴 재발동, 마법사 전투 불능, 최소 비용 0을 검증했다.
- 실제 전투에서 할인된 AP 표시와 비용 0 카드 사용을 확인했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 104개 통과.

---
## 남은 작업

- 마법사의 나머지 전용 카드와 개별 일러스트, 다른 캐릭터의 전용 능력 구현이 남아 있다.
