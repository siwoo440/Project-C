# 289일차 유물 확장 · 불씨 없는 화로부터 가라앉은 제단의 뿌리까지

유물 시트 293~299행의 마지막 일곱 유물을 실제 전투, 원화, 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 불씨 없는 화로 | 화상으로 실제 체력 피해가 발생하면 20% 확률로 아군 행동력 1을 얻는다. 적 턴의 발동은 다음 실제 아군 턴에 지급한다. |
| 낙석의 예언석 | 실제 아군 턴이 네 번 시작될 때마다 생존 적에게 각각 일반 피해 16, 생존 아군에게 각각 일반 피해 4를 준다. |
| 늪의 수호목 씨앗 | 전투 시작에 생존 아군 전체에 각각 세 아군 턴 동안 재생 2를 부여한다. |
| 검은 늪의 심장수 | 중독이 활성인 적의 실제 공격력이 10% 감소한다. |
| 망령 안개의 등불 | 적의 실제 정신 피해가 20% 증가하고, 생존 아군 전체의 명중률이 5%p 낮아진다. |
| 부패한 수호석 | 실제 여섯 번째 아군 턴부터 생존 아군 전체의 수신 피해를 20% 줄인다. |
| 가라앉은 제단의 뿌리 | 전투당 한 번, 생존 아군 전원이 각자 최대 체력의 30% 이하가 되면 생존 아군 모두가 방어도 25를 얻는다. |

재생 회복량은 턴마다 2로 정했다. 아군 추가 턴도 실제 턴으로 센다. 낮은 체력의 보호막은 생존 아군 각자의 체력을 동시에 확인하며, 정상 전투의 한 번만 적용한다.

---

## 검증 결과

Unity EditMode 32건 통과, 실패와 건너뜀 0건. 상점 검사 2건과 실제 여섯 번째 아군 턴, 피해 예고, 수호자의 실제 피해 전환을 포함했다.

Windows 플레이어에서 마지막 유물 7종의 저장 복원을 확인했다. 생존 아군 네 명이 모두 자기 최대 체력의 30% 이하에 도달하자 방어도 25를 한 번씩 얻었다.
