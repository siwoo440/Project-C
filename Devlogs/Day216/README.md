# 216일차 시제품 공용 카드 4종 추가

탐사 보물에 검 두 장, 성배 한 장, 펜타클 한 장을 추가했다. 보물 창에서 카드를 받을 파티원을 선택하면 해당 파티원의 카드로 저장된다. 시트 공용 실물은 22종에서 26종으로 늘었다. 이 중 3종은 상점과 보물 양쪽에서, 23종은 보물에서 획득한다. 시제품 네 명의 전용 시작 카드 4종을 더하면 역할별 임시 시작 카드를 제외하고 총 30종이다. 두 검 카드의 원문에는 피해 유형이 지정되어 있지 않아 기존 ‘베기’와 같은 물리 피해·명중·방어 규칙을 사용한다. 공격 대상의 실제 체력 피해량과 관계없이 소유자의 방어도와 아군 전체 회복을 적용한다. ‘은총의 잔’은 최대 체력인 아군에게도 방어도를 준다. ‘집중 호흡’은 정신력을 더 올릴 수 없어도 뽑을 카드가 있으면 사용 가능하다. 이번에 사용한 카드는 드로우가 끝나고 버린 더미로 보낸다.

## 검증

Unity EditMode에서 신규 카드 검사 5개, 이전 공용 카드 검사 9개, 실제 획득·소유자 저장 통합 검사 2개가 통과했다. 217일차 탐사 이벤트 검사까지 포함한 실행 결과는 27개 통과였다.

- 네 그림 모두 원본 ZIP의 한글 동명 PNG와 SHA-256이 일치했다. 에셋 검사에서 실제 보물 카드·선택 소유자 설정·저장 원본·시트 행·행동력·효과 설명과 일러스트 연결을 대조한다.
- 전투 검사에서 실제 손패와 적·아군을 클릭한다. 피해 흡수, 지정 대상과 나머지 아군의 체력·방어도, 전투불능 아군 제외, 최대 체력·정신력에서의 후속 효과, 사용 비용과 카드 이동을 확인한다.
- 획득 통합 검사는 실제 방에서 공용 카드 전부를 받아 선택한 소유자에게 지급한 뒤, 탐사 파일에 저장하고 복원한 결과를 대조한다.
