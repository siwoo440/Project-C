# 199일차 아르카나 22명의 사망·회복·저장 회귀 검사

윈터폴에 출전하는 22명 전원을 대상으로 같은 캐릭터가 편성, 전투, 거점의 부활 대기, 저장 파일을 거친 뒤에도 올바른 상태로 돌아오는지 검사한다. 기획서의 미완료 항목인 전체 명단 회귀 검사를 다룬다. [기획서 8.2 남은 작업](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.phcdwm7q8pli)

---

## 검사 흐름

1. ‘세계’가 해금된 검증 계정에서 아르카나 22명을 네 명씩 다섯 조와 두 명 한 조로 나눈다. 거점의 지역 선택·편성·출발 버튼을 사용하고, 생성된 적과 접촉한 뒤 실제 전투 명단과 카드 소유자를 대조한다.
2. 전투 피해 함수로 아군을 전멸시킨 뒤 패배 확인과 거점 복귀 버튼을 누른다. 회복 대기가 두 번 남은 캐릭터와 한 번 남은 캐릭터는 편성할 수 없고, 두 번째 후속 탐사를 마친 캐릭터는 최대 체력으로 편성할 수 있어야 한다.
3. 귀환할 때마다 체력·정신력·사망 횟수·남은 회복 횟수를 22명 각각 대조한다. 메모리의 파티·회복 기록과 편성을 비우고 거점 자동 저장 파일을 다시 읽은 뒤, 상태와 빈 편성 칸까지 재검사한다.
4. 마지막 두 조의 회복도 확인하기 위해 먼저 회복한 두 조가 한 번씩 다시 출전한다. 총 여덟 번 탐사하며, 전체 명단이 사망 후 회복을 마치고 다시 편성 가능한 상태를 적어도 한 번씩 거쳤는지 확인한다.

## 재현과 검증 범위

Unity **6000.3.21f1**에서 Company Name과 Product Name을 모두 `ProjectCVerification`으로 설정한 검증 복제본을 사용한다. EditMode Test Runner에서 [RosterRecoveryFlowTests.AllCharactersFightDieRecoverAndReload](../../Assets/_ProjectC/Tests/Editor/RosterRecoveryFlowTests.cs)를 실행한다. 검사가 끝나면 이전 세계 해금 설정을 복원한다.

2026년 11월 19일 검증 복제본에서 전체 명단 회귀 검사가 통과했다. 여덟 번의 탐사에서 22명 모두의 전투·사망·회복 후 재편성을 확인했다. 같은 실행에서 튜토리얼 관련 검사 네 개도 통과해 총 다섯 개 중 실패와 건너뛰기는 없었다.

이 검사는 편성·사망·복구 경로를 확인하기 위해 맵 이동과 전투 피해량을 제어한다. 22명의 가능한 모든 조합, 캐릭터별 전략과 승률, 피로·부상·치료 규칙은 검사 범위 밖이다.
