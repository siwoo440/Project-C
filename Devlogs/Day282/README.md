# 282일차 유물 확장 · 보안 집행체 배지부터 격리실 번호표까지

유물 시트 245~252행 여덟 종을 원화, 실제 전투, 상점, 도감 및 탐사 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 보안 집행체 배지 | 기절이나 행동력 감소가 활성인 적에 대한 아군 카드의 직접 피해가 15% 증가한다. 서리 감옥이 발동시킨 행동 취소도 포함한다. |
| 회수 드론 갈고리 | 표식 상태의 생존 적을 아군 카드가 명중하면, 카드 한 번당 해당 적을 한 번 판정한다. 20% 확률로 다음 적 행동 하나를 취소한다. |
| 자기장 압축핵 | 아군의 실제 턴이 세 번 시작될 때마다 생존 적 전체의 회피율을 10%p 낮춘다. 두 적 턴 동안 유지된다. |
| 감시 코어 조각 | 모든 아군의 마법 저항력을 10 높인다. 첫 아군 턴의 기본 드로우는 한 장 줄어든다. |
| 폐열 방열판 | 아군이 화상으로 체력을 잃으면 40% 확률로 해당 아군의 공격력을 두 아군 턴 동안 1 높인다. 재발동 시 지속시간을 갱신한다. |
| 긴급 재부팅 스위치 | 전투당 한 번, 피해 뒤 체력이 최대치의 30% 이하인 생존 아군의 체력을 기본 12 회복한다. |
| 고장 난 블랙박스 | 아군이 실제로 전투불능이 될 때 공용 손패 상한 안에서 카드 두 장을 뽑는다. |
| 격리실 번호표 | 전투 시작에 아군과 적 진영에서 각각 무작위 생존자 한 명에게 각자의 두 턴 동안 표식을 부여한다. |

행동 취소는 적 행동 처리의 기존 경로에서 소모된다. 표식은 기존 상태 면역과 해제 규칙을 사용한다. 폐열의 공격력 강화는 다른 공격력 증가와 별도로 계산한다.

## 검증 결과

Unity EditMode 33건 통과, 실패와 건너뜀 0건. 중복 유물 진열과 구매 확인을 포함한 상점 검사 2건이 모두 통과했다.

Windows 플레이어에서 유물 8종의 저장 복원, 양 진영의 시작 표식, HP 28에서 체력 12 회복, 세 번째 아군 턴에 생기는 회피율 10%p 감소를 확인했다. 폐열 방열판의 별도 원화가 일반 공격력 증가 아이콘과 구별된다.
