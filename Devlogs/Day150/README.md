# 150일차: 피해 숫자·상세 툴팁 설정 연결

- 게임 플레이 설정의 피해 숫자 표시와 상세 툴팁 표시 방식을 실제 전투 화면에 연결하고 선택값을 기기 설정으로 저장한다.
- 피해 숫자를 꺼도 피격 강조와 방어도 흡수·회복·상태 문구는 유지한다.
- 카드와 상태 효과에 마우스를 올렸을 때 툴팁을 항상 표시하거나, 키를 누를 때만 표시하거나, 숨길 수 있다. 키 누름 방식은 왼쪽·오른쪽 Alt를 임시 사용한다.
- 상태 상세창을 캐릭터 옆에 배치하고 글자를 키웠으며, 캔버스 경계에 맞춰 잘리지 않도록 보정한다. [실제 전투 화면](StatusTooltip.png)에서 표시를 확인했다.
- 가상 키보드 입력과 실제 카드·상태 화면 갱신, 피해 숫자와 회복 숫자, 화면 양쪽 경계의 상태 상세창을 검사했다.
- Unity 전체 EditMode 검사 303개가 통과했다. 가상 키보드 검사는 테스트 환경의 수동 입력 갱신에 맞춰 실제 화면 갱신 함수를 호출했다.

## 후속 작업

- 프로젝트에서 실제 음원과 사운드 재생 경로를 찾지 못해 BGM·효과음·음성·환경음과 개별 음량 설정은 연결하지 않았다. 음원과 재생 구조가 준비된 뒤 검증해야 한다.
- 밝기, UI 크기, 개별 음량, 키 재설정, 언어 등 아직 지원하지 않는 설정은 기능 구현과 검증이 필요하다.
- 상세 툴팁용 Alt 키는 임시 선택이며 최종 조작키와 리바인드 방식은 기획 확인이 필요하다.
