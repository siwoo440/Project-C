# 139일차: 탑·별 임시 전용 능력 구현

- 탑의 `균열`은 모든 생존 적의 방어도를 각각 최대 3 제거한 뒤 각 적에게 기본 물리 피해 8을 준다.
- 별이 회복 카드를 사용하면 회복 대상에게 다음 아군 턴 체력 2 회복을 턴당 한 번 추가 예약한다.
- 별의 기존 `남은 빛` 회복 6과 패시브 회복 2는 별도 상태로 저장돼 다음 턴에 함께 발동한다.
- 탑의 추가 패시브와 두 캐릭터의 정상·각성·붕괴별 세부 효과는 기획 미정으로 남겨 둔다.
- `StarReservation.png`는 실제 탐사 조우 전투에서 별의 전용 카드를 사용해 촬영한 화면이다.
- 실제 광역 공격·기존 회복 관련 검사 13개와 전용 카드 저장·복원 등 추가 검사 5개가 통과했다.
- 기존 회복 합계와 무작위 적 공격을 반영한 뒤 Unity 전체 EditMode 회귀 검사 239개가 통과했다.
