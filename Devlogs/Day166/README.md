# 166일차 : 공용 카드 보상 소유자 선택

- 보물에서 공용 카드가 나오면 현재 탐사 파티원의 프로필 중 소유자를 직접 선택합니다.
- 선택 전에는 카드를 지급하거나 보물을 사용 처리하지 않으며, 취소 후 같은 보물을 다시 열 수 있습니다.
- 선택한 파티원에게 카드가 지급된 뒤에만 보물 사용 상태와 탐사 결과를 자동 저장합니다.
- 선택 중 저장을 불러오면 선택 창을 닫고 탐사 시간을 복원합니다. 사용하지 않은 보물은 같은 보상으로 다시 열 수 있습니다.
- 상점에 방문하기 전에도 실제 상품 원본에서 보물 후보를 읽습니다.
- 기존 고정 소유자 카드와 다른 종류의 보상은 기존 방식으로 지급합니다.
- 화면 이미지는 두 캐릭터로 구성한 시험 파티에서 실제 보물의 카드 소유자 선택 화면을 촬영한 것입니다.
- 검증: Unity EditMode 전체 검사 329개 통과.
