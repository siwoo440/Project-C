# 288일차 유물 확장 · 늪지 거머리 심줄부터 용암왕의 왕좌파편까지

유물 시트 285~292행을 실제 전투, 원화, 상점과 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 늪지 거머리 심줄 | 아군의 카드가 출혈 중인 적의 체력을 실제로 줄이면 감소한 체력의 10%만큼 사용자를 회복한다. |
| 독수액 핵 | 중독된 적이 전투불능이 되면 25% 확률로 나머지 생존 적에게 두 적 턴 동안 중독 1을 부여한다. |
| 진흙 골렘의 심토 | 실제 아군 턴 종료에 방어도가 남은 생존 아군 각각을 체력 3만큼 회복한다. |
| 늪의 요정 날개가루 | 회복 카드의 실제 생존 대상은 적 턴 한 번 동안 회피율이 10%p 증가한다. |
| 포식괴물의 빈 위장 | 적을 처치한 아군이 체력 10을 회복한다. 전투 시작에는 생존 아군이 각각 현재 체력에서 최대 5를 지불하며 체력 1 이상을 유지한다. |
| 불타는 협곡의 심장편 | 화상 중인 적에게 가해지는 실제 피해를 20% 높인다. |
| 산맥석상의 어깨조각 | 아군이 받는 물리 피해가 15% 감소하고 마법 피해가 5% 증가한다. |
| 용암왕의 왕좌파편 | 전투 시작에 적 전체에게 화상 1을 적 턴 두 번 동안 부여한다. 선두 생존 아군도 자기 턴 한 번 동안 화상 1을 받는다. |

피해 비례 회복에는 적의 실제 체력 손실을 사용한다. 포식괴물의 빈 위장이 요구하는 개시 체력은 생존에 필요한 마지막 체력 1을 남긴다. 왕좌파편의 단일 아군 대가는 선두 생존 아군에게 적용한다.

---

## 검증 결과

Unity EditMode 30건 통과, 실패와 건너뜀 0건. 상점 검사 2건과 직접 치유 카드가 실제 회피 상태를 부여하는 검사를 포함했다.

Windows 플레이어에서 유물 8종의 저장 복원을 확인했다. 전투 개시에 각 아군 체력 5가 차감됐고, 선두 아군은 아군 턴 한 번, 생존 적은 적 턴 두 번 동안 화상 1을 받았다.
