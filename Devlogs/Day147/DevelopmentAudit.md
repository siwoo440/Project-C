# 147일차 개발 일차 전체 점검

- 기획표의 1~146일차 146개는 완료 표시이며, 각 행의 개발 방향은 같은 일차의 실제 Git 커밋 제목과 일치한다.
- 기획표의 147~161일차 15개는 예정된 시제품 검증·보완 일정이다. 147일차는 상태 이상과 방 생성 규칙 점검으로 진행한다.
- 기획표 뒤의 89~158일차 후보 일정은 문서에 명시된 변경 전 추정치다. 실제 이력이나 현재 예정 일차와 같은 확정 일정으로 세지 않는다.
- 완료 표시가 제품 전체 완성을 뜻하지 않는다. 135~141일차 캐릭터의 미정 패시브와 정신 상태별 효과, 142일차 시제품 공용 카드 범위, 144일차 적 추가 패턴, 145일차 보스 확정 기획, 146일차 이벤트·유물 보완은 후속 작업이다.
- 시제품 목표는 이벤트 6~8개와 유물 약 15종이다. 146일차 기준 실제 유물 4종을 연결했고 윈터폴 기획 이벤트 8개는 미연결이다. 테스트용 이벤트와 유물은 이 수량에서 제외한다.
- 현재 탐사는 층 기반 절차 맵이며, 기획서의 구역 진행도 100% 보스 예약·구역 레벨·구간 배치 규칙과는 차이가 있다. 실제 예약·실패 후 유지·보스 처치 시 레벨 상승은 별도 구현과 저장 호환 검증이 필요하다.
- 기획서의 사용자 확인 임시 규칙 탭은 확정 전 검토 기록이다. 이 문서의 완료 표기와 실제 게임 구현 상태를 함께 확인한다.
