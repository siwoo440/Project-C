# 147일차: 상태 이상 지속·중독과 방 연결 점검

- [전체 개발 일차 점검](DevelopmentAudit.md)에서 기획표 1~161일차와 Git 커밋 제목을 대조했다. 1~146일차는 완료, 147~161일차는 점검 당시 예정이었다. 완료된 초기 구현의 후속 작업은 별도로 유지했다.
- 중독은 사용자 확인에 따라 대상 턴 시작에 현재 전체 수치만큼 피해를 주고 중첩 합계에서 1 감소한다. 수치가 0이 되면 기존 화상과 같이 제거한다.
- 화상은 턴 종료 피해와 전체 수치 1 감소를 처리한다. 자기 턴에 새로 받은 상태는 그 턴의 첫 지속 턴 감소를 생략하며, 화상 피해 자체는 정상적으로 적용한다.
- 일반 강화·약화는 대상 진영의 턴 종료에 지속 턴을 감소한다. 별의 예약 회복과 전차 표식은 기존 전용 처리 시점을 유지한다. 소환 적도 같은 상태 적용 감시를 사용한다.
- 턴 종료 처리 중 다른 유닛에게 연쇄 적용된 상태는 대상의 처리 순서를 반영해 첫 지속 감소를 정확히 생략한다.
- 전투 시작 유물로 부여된 1턴 효과는 첫 턴에 사용한 뒤 첫 턴 종료에 만료된다. 청동 향로의 실제 구매·저장 복원·전투 적용 흐름으로 확인했다.
- 게임 내 매달린 자 설명의 상태 분류 명칭을 디버프로 통일하고, 기획서에 버프·디버프 15종의 현재 효과와 임시 규칙을 정리했다.
- 중독·화상의 재부여 시에는 기존 중첩·긴 지속 유지 규칙을 사용하고 새로 받은 수치보다 낮지 않도록 갱신한다. 수치가 감소한 디버프 이전 시 감소량을 보존한다. 상태별 최종 중첩·갱신 기준은 기획 확정이 필요하다.
- 일반층·5층·10층의 각 500개 시드에서 모든 방과 관문에 도달할 수 있고 출입구가 양방향으로 연결되는지 검사했다. 최소 2·3·4개 방과 기본 14개 방의 휴식·상점 배치 제한도 확인했다.
- Unity 전체 EditMode 검사 289개가 통과했다.

## 남은 작업

- 현재 층 기반 맵은 기획서의 구역 진행도 100% 보스 예약·구역 레벨·구간 간 배치 규칙과 다르다. 기존 저장 호환을 고려한 구현과 실제 탐사 검증이 필요하다.
- 상태별 중첩·재부여·면역·정화 기준, 중독과 화상의 수치가 0일 때 제거하는 임시 처리, 적별 미구현 상태 및 패턴은 기획 확정과 밸런스 검증이 필요하다.
- [실제 전투 화면](StatusTooltip.png)에서 중독 아이콘을 확인했다. 상태 상세 설명창은 화면 위로 잘리는 기존 문제가 있어 위치 보정이 필요하다.
