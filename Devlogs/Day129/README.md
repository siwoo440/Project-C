# 129일차 바보·마법사 전용 능력 보완

---
## 작업 내용

- 사망한 소유자의 카드를 덱에서 제거하지 않고 일반 드로우와 바보 선택 후보에서 제외
- 생존 소유자의 카드가 버린 더미에만 있으면 기존 사망 카드 아래로 재구성하고, 유효한 카드가 없을 때 반복 없이 종료
- 사망 카드 아래에 남은 생존 카드를 바보의 패시브로 덱에 두거나 버릴 수 있게 처리
- 바보 선택 후보 또는 마법사 회수 후보가 없으면 해당 손패 카드 입력을 비활성화
- 부활 상태로 전환한 소유자의 카드가 다시 드로우 후보로 포함되는 동작 검증
- 바보 선택 드로우, 마법사 회수와 턴당 할인 패시브, 손패 화면 사용 조건을 개별 검증
- 전체 EditMode 회귀 검사 201개 통과
- 후보가 없는 전용 카드의 실제 손패 화면: `UnavailableCards.png` (검사 환경의 캡처용 렌더 설정 사용)

---
## 남은 작업

- 공용 카드의 사용자 직접 선택과 실제 전투 중 부활 화면 갱신은 별도 구현이 필요
- 바보의 ‘낯선 길’과 마법사의 ‘재정비’는 기획서의 검토용 설계안이며 아직 구현하지 않음
- 현재 역할별 임시 카드도 소유자가 지정된 구조이므로 해당 소유자의 사망 시 동일한 드로우 제한 적용
