# 131일차: 황제·교황 방어도 카드 보완

- 황제의 기존 카드는 기획 초안의 임시 비용 AP 2로 단일 공격을 유도하고, 사용자 확인에 따라 임시 방어도 3을 획득한다.
- 이미 황제를 공격하는 적, 공격이 아닌 행동, 사망하거나 무효인 대상은 유도할 수 없다.
- 교황의 준비는 적의 첫 공격 직전에 사용자 확인에 따른 임시 방어도 3을 부여하며 적 턴이 끝나면 미사용 준비가 사라진다.
- 연속 공격 피해 예고에 준비 발동과 잔여 방어도를 반영한다.
- 황제·교황의 추가 패시브 수치, 추가 카드와 정신 상태별 효과는 미정이며 미구현 상태다.
- `PreparationView.png`는 격리된 검증 프로젝트에서 임시 효과를 부여한 실제 전투 화면이다. 테스트 전투의 임시 배경과 적이 표시된다.
- 격리된 Unity 6000.3.21f1 프로젝트에서 전체 EditMode 회귀 검사 209개가 통과했다.
