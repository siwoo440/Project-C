# 서고 먼지갈피 명패

‘서고 먼지갈피’를 선택창 위의 독립 명패에 표시하고, 패널 안에는 ‘가져올 카드 선택’을 배치했습니다. 두 문구는 게임 언어 설정에 맞춰 표시합니다.

명패는 내장 이미지 생성으로 제작한 청록색 바탕과 황동 테두리의 투명한 가로 UI 원화입니다. 글자는 게임에서 표시합니다.

---

## 검증

- Unity 검사 16건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- 1600×900과 1280×800에서 명패와 카드 선택 제목이 각각의 영역 안에 표시됩니다. 실제 Windows 전투에서 다음 페이지의 세 번째 카드를 선택해 덱 순서·버린 카드·행동력을 대조했습니다.
