# 266일차 유물 확장 · 서고 먼지갈피부터 서늘한 창문못까지

유물 시트 178~185행의 원화와 효과를 획득, 구매, 도감, 전투 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 서고 먼지갈피 | 첫 아군 턴의 손패 준비 뒤 드로우 더미 맨 위 세 장까지 확인하고, 그중 선택한 한 장을 손패로 옮긴다. |
| 거울 뒤의 웃음 | 적이 생존 아군에게 제거 가능한 약화를 걸면 40% 확률로 그 적에게 같은 약화를 돌려준다. |
| 영주의 봉랍 | 일반 또는 정예 전투 시작에 생존 적 전체의 공격력을 두 적 턴 동안 2 낮춘다. |
| 만찬장의 기름등 | 네 번째 아군 턴마다 30% 확률을 한 번 판정한다. 성공하면 생존 적 전체에 중독 2를 두 적 턴 동안 부여한다. |
| 검은 식기함 | 생존 적 전체의 활성 출혈 중첩을 합해 3 이상이면 아군 턴에 한 번 카드 한 장을 뽑는다. |
| 파손된 오페라 가면 | 공포 상태인 적을 처치하면 생존 적 전체의 정신력을 4 낮춘다. |
| 낡은 종복 계약서 | 첫 생존 아군에게 종복의 표식을 부여한다. 그 아군은 표식이 남는 두 아군 턴 동안 공격력이 5 증가한다. |
| 서늘한 창문못 | 실명 적의 직접 공격에 명중한 아군이 받는 피해가 10% 감소한다. |

먼지갈피의 선택은 공용 행동력을 차감하지 않으며 남은 카드의 순서를 보존한다. 만찬장의 기름등은 생존 적 전체에 대해 한 번 판정한다. 계약서의 대상은 첫 생존 아군으로 정했다.

---

## 검증

- Unity 검사 33건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건이다.
- 서고 먼지갈피의 첫 페이지에서 두 후보를 보고 다음 페이지에서 세 번째 후보를 선택하는 동작을 확인했다.
- Windows에서 유물 8종의 저장과 불러오기, 세 번째 원본 카드의 손패 이동, 나머지 덱 순서와 행동력 보존을 확인했다. 전투 레벨 표시가 선택 카드 설명을 가리지 않도록 선택창의 표시 순서를 조정했다.
