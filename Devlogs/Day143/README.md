# 143일차: 카드 일러스트 제작·적용

- 내장 이미지 생성 도구로 전용 카드 20종과 공용 카드 4종의 그림을 제작했다. 마법사·별 전용 카드는 기존 전용 그림을 유지했다.
- 적용한 생성 이미지 24개는 `Assets/_ProjectC/Art/CardIllustrations/`에 보관하고 각 시작 카드에 개별 스프라이트로 연결했다.
- 카드 효과와 수치는 변경하지 않았다. 스프라이트는 UI 용도로 최대 텍스처 크기 1024, 밉맵 비활성화로 가져왔다.
- [실제 전투 화면](CardIllustrations.png)에서 시제품 캐릭터 전용 카드와 공용 카드의 그림을 확인했다.
- 기존 전용 그림 유지와 카드별 스프라이트 연결을 포함해 전체 Unity 테스트 249개가 통과했다.

## 이미지 생성 프롬프트

- 전용 카드: 기존 캐릭터 초상화를 외형 참조로 사용하고 얼굴·머리·의상 색을 유지하도록 지시했다. 각 효과를 작은 132×82 화면에서도 읽을 수 있는 가로형 애니메이션풍 판타지 게임 일러스트로 그리며 글자·UI·테두리·로고를 제외했다.
- 공용 카드: 공격하는 검, 충격을 막는 방패, 치유의 성배, 마법 지팡이를 각각 작은 카드에서 구분되는 가로형 판타지 일러스트로 생성했다. 글자·UI·테두리·로고는 제외했다.
- `FoolChoice`: 파란 두건의 바보가 빛나는 두 카드 중 하나를 선택하는 장면.
- `MagicianRepair`: 기존 마법사 전용 그림 유지.
- `PriestessWard`: 여사제가 동료 주위에 보호 결계를 만드는 장면.
- `EmpressFeast`: 여황제가 식탁의 동료들과 보호 마법을 나누는 장면.
- `EmperorGuard`: 황제가 방패로 들어오는 공격을 받아내는 장면.
- `HierophantPreparation`: 교황이 공격에 대비해 동료의 결계를 준비하는 장면.
- `LoversPartner`: 연인이 다른 동료와 빛나는 유대를 맺는 장면.
- `ChariotMark`: 전차가 표식이 있는 적에게 집중 공격하는 장면.
- `StrengthGuard`: 힘이 동료 앞에 서서 공격을 대신 받는 장면.
- `HermitArrange`: 은둔자가 책 위의 카드 세 장을 살펴 순서를 정하는 장면.
- `FateReroll`: 운명이 빛나는 운명의 수레바퀴로 공격 대상을 바꾸는 장면.
- `JusticeShare`: 정의가 저울과 보호광을 통해 동료와 피해를 나누는 장면.
- `HangedTransfer`: 매달린 자가 동료의 어두운 효과를 자신에게 옮기는 장면.
- `DeathFinisher`: 죽음이 약해진 적에게 마무리 일격을 가하는 장면.
- `TemperanceCleanse`: 절제가 동료의 어두운 효과를 빛으로 정화하는 장면.
- `DevilBloodPrice`: 악마가 대가를 치르고 강력한 일격을 사용하는 장면.
- `TowerShatter`: 탑이 여러 적의 방어를 충격파로 파괴하는 장면.
- `MoonHandChoice`: 달이 달빛 아래 두 카드 중 선택하고 하나를 버리는 장면.
- `SunChain`: 태양이 두 적을 잇는 황금빛 연속 공격을 하는 장면.
- `JudgementRescue`: 심판이 다친 동료를 급히 회복하는 장면.
- `WorldLink`: 세계가 동료들을 빛으로 연결해 보호하는 장면.
