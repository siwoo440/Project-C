# 226일차 유물 확장 · 파편화된 거울부터 부서진 메달까지

| 유물 | 발동 조건과 효과 |
| --- | --- |
| 파편화된 거울 | 전투 중 처음 사용한 카드의 임시 복사본을 원래 비용으로 같은 소유자의 손패에 추가한다. 손패가 가득 차 있으면 기회를 보존해 다음 사용 때 다시 시도한다. 복사본은 전투가 끝나면 사라진다. |
| 침식 잔향병 | 턴 종료로 카드를 정리하기 직전에 손패가 1장 이상이면 다음 아군 턴에 1장 추가 드로우한다. |
| 비상 식량팩 | 캠프에서 생존 아군의 체력 회복량 +30%. 캐릭터별 회복량의 소수점 이하는 버리고 최대 체력까지만 회복한다. |
| 검은 실타래 | 턴당 1회, 카드 효과 또는 턴 종료로 버려질 첫 손패 1장을 유지한다. 사용을 마친 카드, 덱에서 직접 버린 카드, 초과 드로우 카드는 제외한다. |
| 금빛 교환권 | 상점에서 카드 1장 제거 비용을 대신 지불한다. 제거 성공 시 교환권을 소모한다. 취소·실패 시 유지한다. |
| 붉은 잔재 부적 | 전투 시작 시 생존 아군 모두의 정신력 +2. |
| 퇴색한 군번줄 | 전투당 파티 전체 1회, 적의 직접 공격으로 생존 아군이 처음 잃을 체력 피해를 무효화한다. 방어도가 전부 흡수하면 소모하지 않으며 지속 피해·체력 비용에는 발동하지 않는다. |
| 부서진 메달 | 첫 아군 턴만 현재·최대 행동력 +1. 기본 6이면 7/7로 시작하고 다음 아군 턴에는 정상 최대치로 돌아온다. |

Windows 플레이어에서 첫 턴에 ‘빠른 계산 +1’을 써서 같은 소유자와 강화를 가진 복사본을 받았다. 실타래가 효과 버림을 한 번 막은 뒤, 그 카드는 같은 턴 종료 때 정상적으로 버려졌다. 이후 턴에는 ‘전진 베기’를 유지하고 기본 4장과 잔향병의 추가 1장을 뽑아 손패가 6장이 됐다.

Unity 통합 검사 26건에서 거울의 손패 초과 재시도, 적 선제 시 첫 아군 턴 판정, 여덟 유물의 등록·저장·획득과 기존 카드를 확인했다. 별도 캠프·상점 검사 26건에서는 교환권을 보유한 상태에서 취소·저장·복원한 뒤 한 번만 사용되는 경로도 확인했다.
