# 144일차: 윈터폴 일반 적·정예 초기 구현

- [별도 적 기획 문서](https://docs.google.com/document/d/19186DbhYJ1TEP6QNhKqDjun1p4eW3AVkwRrZJBQyu14/edit)의 쉬움 기본 수치를 사용해 일반 적 5종과 정예 2종의 조우, 전투 이미지, 기본 공격을 추가했다.
- 일반 적: 잿풍의 사냥꾼, 망가진 허수아비, 재먹는 구더기, 잿빛 방랑자, 재폭풍 추적자. 정예: 재의 파수꾼, 잿더미 종지기.
- 각 적은 현재 첫 기본 공격 하나를 반복한다. 화상이 있는 공격은 기획의 확률로 화상 2를 적용하고 대상의 턴 종료마다 2, 1 피해를 준다. 실명이 있는 공격은 기획의 확률과 지속 턴을 적용하며 공격 명중률을 25%p 낮춘다.
- 명시되지 않은 공격은 사용자가 확인한 임시 기준인 물리 피해, 속도 3~7, 무작위 생존 아군 대상을 사용한다. 태양의 두 공격은 각각 명중을 판정한다.
- 기존 피해 공식은 저항 퍼센트의 고정 피해 감소와 다르므로 문서의 퍼센트 숫자를 저항 수치로 임시 입력했다. 층과 정예에 따른 기존 전투 배율은 계속 적용된다.
- 기존 저장의 조우 목록은 유지하고, 새 탐사에서는 이전 일반·정예 테스트 조우를 새 적으로 대체했다. 임시 보스는 다음 개발 전까지 유지한다.
- [실제 전투 화면](WinterfallHunter.png)에서 새 적과 전투 UI의 연결을 확인했다.
- Unity 전체 EditMode 테스트 259개가 통과했다. 기존 저장 재저장, 실제 적 행동 생성, 화상·실명과 태양의 개별 명중 판정도 검증했다.

## 남은 작업

- 추가 공격 패턴과 패시브, 공포·은신·회피·소환, 파수꾼의 초기 방어도는 구현하지 않았다. 적별 어려움 수치에는 문서 간 확인이 필요한 항목이 있다.
- 마법 저항 계산 방식, 명시되지 않은 공격 유형과 속도, 실제 전투 난이도 및 보상은 이후 기획 확정과 밸런스 검증이 필요하다.

## 이미지 생성

- 기존 아군 캐릭터의 표현 방식을 참조해 투명 배경의 정면 전신 적 스프라이트 7개를 생성했다. 게임 화면에서 각 실루엣이 구분되도록 사냥꾼, 허수아비, 구더기, 방랑자, 추적자, 파수꾼, 종지기를 각각 표현했다.
- 원본 이미지는 `Assets/_ProjectC/Art/WinterfallEnemies/`에 보관하고 각 적 데이터에 연결했다.
