# 80일차 개발일지

---
## 작업 내용

- 황제 선택 시 임시 전용 카드 `황제의 수호` 한 장을 시작 덱에 추가했다.
- 공격을 예고한 적 한 명을 선택하면 공격 대상을 황제로 바꾸고 황제의 물리 방어력을 2턴간 3 올린다.
- 카드는 공용 행동력 1을 소비하며 임시 공용 카드 일러스트를 사용한다.
- 시작 덱 12장 중 나머지는 기존 역할 공용 임시 카드다.

---
## 검증

- 카드 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 거점 편성부터 탐사 조우, 카드 선택, 공격 대상 변경, 방어력 증가와 행동력 소비까지 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 91개 통과.

---
## 남은 작업

- 카드 이름과 수치는 임시값이며 황제의 나머지 전용 카드와 패시브는 미구현이다.
- 나머지 캐릭터의 전용 카드와 패시브 구현이 남아 있다.
