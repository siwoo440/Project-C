# 142일차: 카드 목록과 임시 수치 정리

- 기획 카드 시트 251개 항목과 프로젝트 카드 에셋 61종을 [카드 현황](CardInventory.md)에 정리했다.
- 사용자 확인에 따라 시제품 목표에는 바보·황제·여사제·전차의 전용 카드와 공용 카드만 포함한다.
- 시제품 4명의 시작 덱에 연결된 임시 카드 8종을 잠정 후보로 세면 목표 30~40종까지 22~32종의 차이가 있다. 상점 후보와 카드별 완성 여부를 검증한 최종 부족 수량은 미확정이다.
- 이름이 일치하는 테스트 카드 3종은 시트와 수치 또는 효과 범위가 달라 별도 비교가 필요하다.
- 22명의 시작 전용 카드, 카드 소유자, 고유 식별자와 저장 원본 연결 검사 및 관련 검사 3개가 통과했다.
