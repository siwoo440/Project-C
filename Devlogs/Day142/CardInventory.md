## 범위와 확인 결과

- 윈터폴 시제품 목표는 플레이와 검증이 가능한 카드 약 30~40종이다. 사용자가 확인한 집계 범위는 시제품 4명인 바보·황제·여사제·전차의 전용 카드와 공용 카드다. 카드 시트 251행은 전체 후보이며 시제품 확정 목록이 아니다.
- 시작 덱에 연결된 카드 에셋은 26종이다: 캐릭터별 전용 카드 22종과 역할별 공용 임시 카드 4종. 세계는 기존 해금 조건을 충족해야 편성할 수 있다.
- 한 번의 탐사는 최대 4명의 전용 카드와 편성된 역할별 공용 카드를 사용한다. 시작 덱은 총 12장이며 중복 카드가 포함된다.
- 별도로 테스트 카드 32종과 디버그 카드 3종이 존재한다. 테스트 덱 에셋에 들어간다는 사실만으로 일반 탐사에서 획득 가능하다고 판단하지 않는다.
- 시제품 4명 편성의 시작 덱에 연결된 범위 내 임시 카드는 전용 카드 4종과 역할 공용 카드 4종이다. 이 8종을 잠정 후보로 셀 경우 목표까지 22~32종이 더 필요하다. 임시 수치, 카드별 이미지와 실제 플레이 검증이 완료된 카드 수는 별도로 확인해야 한다.
- 임시 상점 카탈로그에는 테스트 카드 상품 3개가 등록돼 있다. 실제 구입, 공용 카드 해당 여부와 시제품 품질을 검증하기 전까지 위 8종에 합산하지 않는다.
- 시트 251개 이름 중 카드 에셋과 정확히 같은 이름은 테스트 카드 3종(강타·검풍·정화)이다. 세 항목은 비용·효과 수치 또는 정화 범위가 달라 같은 이름만으로 완성 처리할 수 없다. 시트에 공통 카드 ID가 없으므로 이름이 다른 카드의 동일성도 별도 검증해야 한다.
- 정상·각성·붕괴별 효과, 카드별 이미지, 보상·상점 획득 연결과 실제 플레이 검증은 별도로 확인해야 한다. 따라서 22~32종은 시작 덱 후보 8종만 셌을 때의 잠정 차이이며 최종 부족 수량이 아니다.
- 시트 설명이 비어 있는 항목은 3개다. 빈 값은 '미작성'으로 표시하며 나머지 값도 원본 기획상의 임시안일 수 있다.

## 후속 작업

- 강타: 시트는 AP 1·물리 피해 8, 테스트 에셋은 AP 2·물리 피해 26이다.
- 검풍: 시트는 AP 3·전체 피해 10, 테스트 에셋은 AP 3·전체 물리 피해 22다.
- 정화: 시트는 디버프 1개 제거, 테스트 에셋은 모든 디버프 제거다.
- 시제품 30~40종에 포함할 공용 카드 후보를 정하고 기존 상점 카드의 조건과 효과를 검증한다.
- 확정된 카드마다 시트 행과 에셋 ID를 연결하고, 이름과 수치가 달라도 같은 카드인지 개별 검증한다.
- 시트 설명이 없는 3개 항목과 카드의 확률·효과·대상·지속 시간 미정 항목을 기획에서 채운다.
- 사용 가능한 획득 경로, 실제 전투·저장 복원, 이미지와 정신 상태별 효과를 카드별로 검증한다.
