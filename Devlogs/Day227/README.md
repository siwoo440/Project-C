# 227일차 검 카드 확장 · 찌르기부터 견제 참격까지

여덟 카드 모두 행동력 1을 사용한다. 보물 보상에서는 카드를 받을 생존 파티원을 직접 선택한다.

| 카드 | 전투 효과 |
| --- | --- |
| 찌르기 | 적에게 물리 피해 7. 20% 확률로 출혈을 2턴 부여한다. 대상 턴 종료마다 체력 2 감소. 다시 부여하면 지속 시간 갱신. |
| 가로베기 | 선택한 적과 이웃한 칸의 적에게 각각 물리 피해 5. |
| 무릎 베기 | 적에게 물리 피해 6. 25% 확률로 대상의 다음 행동 1회 취소. |
| 검등 치기 | 적에게 5 피해, 기절(1턴) 15% |
| 피의 칼끝 | 적에게 6 피해, 출혈 상태면 추가 4 피해 |
| 방패 쪼개기 | 적에게 7 피해, 방어력 -1 (2턴) |
| 저지 베기 | 적에게 5 피해, 다음 공격 피해 -2 |
| 견제 참격 | 적에게 4 피해, 자신 회피율 +10% (1턴) |

출혈을 다시 걸면 피해량은 2로 유지하고 남은 기간을 2턴으로 갱신한다. 무릎 베기의 행동 취소는 다음 예고 한 번에 적용된다. 검등 치기의 기절은 해당 턴에 행동을 막는다. 저지 베기의 공격 약화는 대상이 상태 부여 행동을 해도 다음 직접 공격까지 남는다.

‘최후의 일격’을 끌 때는 실제로 사용할 수 있는 적만 강조한다. 최대 체력이 200인 적은 현재 체력이 41이면 일반 표시, 40이면 대상으로 강조된다.

Windows 플레이어에서 찌르기에 맞은 적은 방어 계산 후 체력이 50에서 44로 줄고 출혈이 2턴 표시됐다. 이어 무릎 베기로 체력이 39가 되었고 다음 행동 취소가 발동해 공격 예고선이 사라졌다.

카드 획득과 저장 복원, 전투 효과, 기존 유물을 확인한 Unity 검사 49건이 통과했다. 최종 화살표와 상태 표시를 적용한 뒤 관련 검사 3건을 다시 실행해 통과했다.
