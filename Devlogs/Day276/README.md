# 276일차 유물 확장 · 폐허의 태양문양부터 끝없는 순례자의 종까지

유물 시트 219~226행의 원화와 전투 효과를 실제 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 폐허의 태양문양 | 화상 중인 적에게 명중하는 아군의 직접 성배 카드 타격 피해를 5 높인다. |
| 검은 모래의 발목고리 | 아군 능력의 명시적 행동력 감소가 양수로 적용될 때 실제 대상에게 일반 피해 5를 준다. |
| 사막 망령의 빈 후드 | 생존 아군이 새 은신 상태에 들어갈 때 정신력을 3 회복한다. |
| 바람에 깎인 왕관 | 사막 조우에서 각 전투 카드의 첫 사용 기본 행동력 비용을 1 낮춘다. |
| 검은 태양의 식은 핵 | 개막에 생존 적과 아군에게 화상 강도 2를 적용한다. 적에게는 두 적 턴, 아군에게는 한 아군 턴 지속된다. |
| 모래여왕의 명령패 | 적 소환이 완료될 때마다 생존 아군 모두의 공격력이 1 증가한다. 전투가 끝날 때까지 누적된다. |
| 유리사막의 깨진 심장 | 적의 직접 타격으로 실제 잃은 체력의 10%를 공격자에게 피해로 돌려주고, 전투 중 아군이 받는 체력 회복을 10% 줄인다. |
| 끝없는 순례자의 종 | 여섯 번째 실제 아군 턴부터 생존 아군을 체력 5 회복시키고 생존 적의 정신력을 3 낮춘다. |

발목고리는 거인의 방패에 예약된 행동력 감소가 실제로 적용될 때 감소를 부여한 생존 시전자에게도 적용된다. 왕관의 할인은 같은 이름의 카드라도 실물 카드별로 계산하며, X 비용과 별도 필수 비용은 유지한다. 검은 태양의 식은 핵은 기존 화상 감쇠를 사용한다.

## 검증 결과

- Unity 검사 36건 통과. 상점 재고·구매 확인 2건을 모두 실행했다.
- 실제 성배 카드가 화상 중인 적에게 명중하면 폐허의 태양문양으로 기본 피해 5에 5가 더해지고, 검 타격·반향·일반 피해에는 가산되지 않음을 확인했다.
- Windows 플레이어에서 유물 8종을 저장 후 모두 복원했다. 전투 개막의 아군·적 화상과 적이 두 번 소환된 뒤 생존 아군 공격력 +2를 확인했다. [보유 유물](DesertRoyalRelics.png) · [개막 화상](BlackSunColdOpening.png) · [소환 후 공격력](SandQueenSummonAttack.png)
