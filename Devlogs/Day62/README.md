# 62일차 개발일지

---
## 작업 내용

- 전투에 사용할 수 있는 카드가 0장인 경우에도 런타임 덱을 생성할 수 있도록 수정했다.
- 빈 전투 덱은 추가 카드를 보충하지 않으며, 드로우 시 빈 손패를 유지한다.
- 잘못된 카드 목록 자체가 누락된 경우는 계속 오류로 처리한다.

---
## 검증

- 빈 전투 덱이 예외를 발생시키던 기존 동작을 테스트로 재현했다.
- 전투 시작과 다음 턴에서 빈 손패 유지 여부를 테스트했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 56개 통과.

---
## 남은 작업

- 실제 탐사 중 사망 이후 전투 장면 전체의 Play Mode 확인이 남아 있다.
- 거점 편성 화면, 덱 편성, 캐릭터별 전용 효과 연결이 남아 있다.
