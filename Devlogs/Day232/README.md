# 232일차 유물 확장 · 냉각 코일부터 침식 측정기까지

| 유물 | 발동 조건과 효과 |
| --- | --- |
| 냉각 코일 | 방어도가 남은 아군이 적의 직접 물리·마법 공격에 명중당하면 방어도를 차감하기 전에 피해를 1 줄인다. |
| 반쯤 탄 일지 | 전투에서 승리하면 25% 확률로 회차 덱에서 제거 가능한 카드 한 장을 무작위로 제거한다. 덱은 최소 10장을 유지하며 제거에 성공하면 일지를 소모한다. |
| 공명 수신기 | 전투 시작 시 생존 적 모두에게 공명 표식 1을 부여한다. 첫 아군 턴이 끝나면 해제된다. |
| 표식용 분필 | 공명 표식 또는 전차 표식이 있는 적에게 직접 공격 카드가 명중할 때 피해 +2. 두 표식이 있어도 한 타격에 한 번만 적용한다. |
| 붕대 더미 | 전투 중 처음 사용한 체력 회복 카드가 직접 회복시키는 대상마다 회복량 +4. 대상이 최대 체력이면 실제 회복량은 0이다. |
| 사각 금속판 | 아군이 물리 방어력 −2를 부여받을 때 감소량을 1로 줄인다. |
| 간이 정수기 | 캠프에서 휴식할 때 생존 아군 각각의 정신력 회복량 +2. 최대 정신력까지 회복한다. |
| 침식 측정기 | 침식지대에서 보상 골드 +10%. 침식지대가 추가되면 발동한다. |
