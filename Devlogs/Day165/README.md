# 165일차 : 공용 카드 상점 소유자 선택

- 공용 카드 구매 시 현재 탐사 파티에서 소유자를 직접 선택합니다.
- 임시 가격은 강타 80골드, 검풍 120골드, 정화 100골드입니다.
- 선택을 취소하거나 파티 외 캐릭터를 지정하면 골드와 카드가 변경되지 않습니다.
- 현재 소유 카드가 없는 파티원도 선택할 수 있으며, 구매 결과와 소유자는 저장 및 복원됩니다.
- 저장을 불러올 때 상점이 열려 있으면 초기화되지 않은 목록을 읽지 않도록 창을 닫습니다.
- 기존에 소유자가 지정된 상점 상품은 기존 방식으로 구매합니다.
- 공용 카드 보상의 소유자 선택은 다음 일차 작업으로 남아 있으며, 구현 전까지 해당 공용 카드는 보물 보상 후보에서 제외됩니다.
- 화면 이미지는 두 캐릭터로 구성한 시험 파티에서 실제 상점의 강타 소유자 선택 화면을 촬영한 것입니다. 화면 확인을 위해 시험 골드 500을 지급했습니다.

- 검증: Unity EditMode 전체 검사 328개 통과.
