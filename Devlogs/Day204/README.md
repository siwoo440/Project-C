# 204일차 윈터폴 잿더미 속에서 빛나는 것

윈터폴 이벤트 방의 잿더미에서 금속 같은 빛이 보인다. 맨손으로 조사하면 생존 파티원 한 명이 체력을 잃고, 도구를 쓰면 파티가 철판 한 개를 사용한다. 덮어두면 선택한 생존자의 정신력이 회복된다. [기획서 5.2.6](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.wi4rzj33f2lg)

---

## 세 가지 선택

| 선택 | 비용과 결과 |
| --- | --- |
| 맨손으로 뒤진다 | 선택한 생존자의 체력이 6 감소한다. 유물 획득 확률은 40%다. |
| 도구를 사용한다 | 철판 1개를 사용한다. 체력은 유지되고 유물 획득 확률은 70%다. |
| 덮어둔다 | 선택한 생존자의 정신력이 최대 100까지 3 회복된다. |

추첨에 실패해도 조사 비용은 사용한다. 행동자 선택을 취소하거나 철판이 부족하면 방을 다시 선택할 수 있다. 조사로 마지막 생존자가 쓰러지면 탐사가 실패하고 거점에서 회복 대기를 시작한다.

---

## 유물과 저장

실제 보물 방 상품과 유물 기획 시트, 저장 원본 목록에 모두 등록된 미보유 유물 중 한 개를 추첨한다. 모든 후보를 이미 보유했다면 비용을 보존하고 덮기를 선택할 수 있다. 같은 저장에서 같은 방을 다시 조사하면 동일한 확률 판정을 사용한다. 처리한 방은 다시 지급하지 않는다.

기존 저장의 현재 층은 최초 세 이벤트 또는 ‘재폭풍의 눈’을 포함한 네 이벤트 구성을 유지한다. 새 층부터 ‘잿더미 속에서 빛나는 것’이 등장할 수 있다. [잿더미 선택 처리](../../Assets/_ProjectC/Scripts/Exploration/AshPileEvent.cs) · [Unity 회귀 검사](../../Assets/_ProjectC/Tests/Editor/AshPileEventTests.cs)

## 실제 화면

Windows 플레이어에서 잿더미를 열고 맨손 조사 대상을 선택하는 화면까지 진행했다. 선택을 취소한 후 철판 한 개를 지급한 촬영용 파티로 도구를 사용해 유물을 얻는 결과를 확인했다. [세 가지 선택](AshPileChoices.png) · [생존 파티원 선택](AshPileActor.png) · [철판 소모와 유물 획득](AshPileOutcome.png)

2026년 11월 19일 Unity 6000.3.21f1 검증 복제본에서 잿더미 검사 3개, 재폭풍의 눈 검사 4개, 기존 보물 카드 검사 1개가 통과했다. 0부터 99까지의 추첨값 중 맨손은 39와 40, 도구는 69와 70에서 획득과 실패가 갈리는지 확인했다.

전체 회귀 검사 383개가 모두 통과했다. 철판 결제 직후 유물 지급이 실패했을 때 철판과 탐사 획득분 구분을 복원하고, 방을 다시 선택할 수 있는 경우도 포함한다.
