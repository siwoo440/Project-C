# 79일차 개발일지

---
## 작업 내용

- 황제 캐릭터의 임시 전용 효과에 사용할 적 공격 대상 변경 기반을 추가했다.
- 선택한 적의 공격 예고만 생존 아군으로 변경하고 예고 화면 갱신을 알린다.
- 상태 이상 행동, 사망자, 파티 밖 아군, 이미 같은 대상을 향한 행동은 변경하지 않는다.

---
## 검증

- 기능 구현 전 테스트 실패와 구현 후 성공을 확인했다.
- 유도된 공격의 실제 피해 대상과 다른 적 행동 유지, 사망자 차단을 확인했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 90개 통과.

---
## 남은 작업

- 이 기반은 아직 황제 카드에 연결되지 않아 게임에서 직접 사용할 수 없다.
- 황제 카드와 방어 효과, 다른 캐릭터 전용 카드와 패시브 구현이 남아 있다.
