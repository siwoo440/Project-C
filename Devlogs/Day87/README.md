# 87일차 개발일지

---
## 작업 내용

- 카드 선택 화면에 두 장씩 표시하는 페이지 이동 기능을 추가했다.
- 세 장 이상의 후보에서 이전·다음 버튼과 현재 페이지를 표시한다.
- 후보가 두 장 이하면 기존 바보 카드 화면을 그대로 사용한다.

---
## 검증

- 페이지 이동 기능이 없을 때 테스트 실패와 구현 후 성공을 확인했다.
- 세 번째 카드 선택, 첫 페이지와 마지막 페이지의 이동 제한을 검증했다.
- 바보 카드의 실제 선택 흐름을 포함한 전체 Unity 테스트 101개 통과.

---
## 남은 작업

- 마법사 전용 카드에 버린 카드 회수와 선택 화면을 연결해야 한다.
