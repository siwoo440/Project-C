# 74일차 개발일지

## 작업 내용

- 내장 이미지 생성 도구로 매달린 자·죽음·절제·악마의 임시 초상화를 제작했다.
- 기획서의 외형 초안을 참고해 캐릭터 에셋에 스프라이트를 연결했다.

---
## 이미지 생성 기준

- 매달린 자: 청록색 머리와 붕대, 낡은 망토를 지닌 인물.
- 죽음: 검은 머리와 붉은 끝머리, 검은 장례복의 인물.
- 절제: 연녹색 단발과 흰색·녹색 치유복의 치유사.
- 악마: 보라색 긴 머리와 뿔 장식, 검은 갑옷의 여성.
- 파일: `Assets/_ProjectC/Art/Portraits/ARC_12.png`~`ARC_15.png`.
