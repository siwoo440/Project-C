# 234일차 유물 확장 · 파손된 안테나부터 찢긴 우편봉투까지

| 유물 | 발동 조건과 효과 |
| --- | --- |
| 파손된 안테나 | 전투 시작 시 무작위 생존 적 하나의 행동 속도를 적 턴 두 번 동안 1 낮춘다. 최저 속도는 1이다. |
| 안전핀 묶음 | 아군 턴 종료 시 손패의 휘발 카드가 소멸하면 다음 턴에 쓸 카드를 한 장 뽑는다. 아군 턴당 한 번 발동한다. |
| 틈새 봉인왁스 | 카드가 전투 덱에서 제외되면 생존 소유자에게 방어도 3을 준다. 아군 턴당 한 번 발동한다. |
| 잔해 주머니 | 아군 턴의 드로우 직전 버린 더미가 10장 이상이면 한 장을 더 뽑는다. |
| 작은 금고 열쇠 | 상점 첫 방문에 30% 확률로 보류된 미보유 유물 한 종을 추가 진열한다. 방마다 첫 진열 결과를 저장한다. |
| 모래시계 파편 | 첫 아군 턴에 소모되고 해당 턴의 고정 행동력 비용을 1 낮춘다. 최소 비용은 0이다. |
| 구겨진 편지 | 첫 아군 손패에 펜타클 카드가 있으면 손패 상한까지 한 장을 더 뽑는다. |
| 찢긴 우편봉투 | 첫 아군 손패에 검 카드가 있으면 그 턴의 현재 및 최대 공용 행동력이 1 증가한다. |

작은 금고 열쇠의 확률은 원본 시트에 수치가 없어 이번 일차에 30%로 정했다. 안전핀과 봉인왁스가 사용할 카드 속성을 연결했고, 해당 속성의 발동은 검사 카드로 확인했다.

Windows 플레이어에서 검과 펜타클을 포함한 시작 손패를 검증했다. 첫 아군 턴에 행동력은 7/7로 표시됐고, 손패는 9장이었다. 비용이 1인 찌르기는 0으로 표시됐으며 적 상태 상세에 속도 감소 1과 2턴 지속이 표시됐다.

최종 Unity 통합 검사 110건이 통과했다. 신규 유물 검사 11건에는 유물별 등록, 적 선공, 첫 손패와 행동력, 휘발·제외와 버림 더미 임계치, 작은 금고 열쇠의 추가 진열 및 저장 복원이 포함된다.
