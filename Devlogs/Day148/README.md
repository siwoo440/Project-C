# 148일차: 전투 튜토리얼

- 첫 전투에서 손패, 카드 사용, 행동력, 정신력, 적 행동 예고, 턴 종료와 적 행동을 차례로 안내한다.
- 실제 카드 사용과 진영 턴 변경을 감지한다. 안내 전에 플레이어가 같은 행동을 했다면 이미 수행한 행동을 다시 요구하지 않는다.
- 화면을 어둡게 하고 대상 UI를 금색으로 강조한다. 설명 영역의 배경과 강조 효과는 전투 입력을 막지 않는다.
- 안내 건너뛰기와 전투 화면의 다시 보기 버튼을 제공한다. 게임 플레이 설정의 튜토리얼/힌트를 켜거나 끌 수 있다.
- 안내 완료와 건너뛰기 여부는 현재 기기의 설정 저장소에 기록한다. 다시 보기는 완료 여부와 자동 안내 설정에 관계없이 사용할 수 있다.
- 실제 전투에서 카드 선택·적 대상 선택·턴 종료·적 행동까지 진행하는 검사를 추가했다. [전투 안내 화면](Tutorial.png)은 실제 전투 씬에서 촬영했다.
- Unity 전체 EditMode 검사 295개가 통과했다.

## 후속 작업

- 각성·붕괴의 실제 발동 유도, 방어 카드 사용 및 전투 후 보상 안내는 별도 안내와 연계가 필요하다.
- 탐사·거점 안내와 도움말 전체 목록, 기기 간 또는 저장 슬롯별 안내 완료 상태는 후속 설계가 필요하다.
