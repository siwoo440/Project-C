# 123일차 화면·품질·음량 설정과 패널 모서리 개선

---
## 작업 내용

- 화면 모드, 해상도, 프레임 제한, 수직 동기화, 품질과 마스터 음량의 변경·저장·시작 시 복원
- 개별 음량 등 관련 시스템이 없는 설정의 변경 차단 유지
- 공용 패널의 장식적인 모서리를 간결한 금색 테두리로 교체하고 크기 변경 시 모서리 형태 유지
- 실제 실행 화면 캡처: `MasterVolume.png`
- 무인 Unity 검사에서는 화면 모드와 해상도 변경을 실행하지 않음
- 검증: 전체 EditMode 테스트 173개 통과

---
## 패널 이미지 제작 지시

기존 청록색 바탕과 황동색 테두리를 유지하며 네 모서리를 작고 단순한 사선으로 만들고, 긁힘과 돌출 장식 없이 여러 크기의 패널에 사용할 수 있도록 제작한다.
