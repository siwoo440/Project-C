# 248일차 유물 확장 · 식은 향 주머니부터 묵은 전투수첩까지

유물 시트 105·106·107·108·109·111·112·113행을 원화, 획득, 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 식은 향 주머니 | 전투 시작에 25% 확률로 생존 아군의 제거 가능한 디버프를 무작위로 하나 해제한다. |
| 작은 수정못 | 지팡이 카드의 직접 공격이 명중할 때마다 피해가 1 증가한다. |
| 금 간 방패끈 | 다른 할인을 적용한 후에도 기본 비용이 남은 전투의 첫 방어 카드 비용을 1 낮춘다. |
| 바랜 훈장 조각 | 검 카드를 사용하면 다음으로 사용할 방패 카드 소유자가 추가 방어도 2를 얻는다. |
| 젖은 성냥개비 | 아군이 적에게 화상을 부여할 때 20% 확률로 그 화상의 지속 시간이 1턴 늘어난다. |
| 깨진 안경알 | 실명 상태인 적을 카드로 직접 명중할 때마다 피해가 3 증가한다. |
| 누런 붕대 매듭 | 회복 카드의 실제 대상에게 적용된 출혈 지속 시간이 1턴 줄어든다. 남은 시간이 0이면 출혈이 해제된다. |
| 묵은 전투수첩 | 한 적에게 카드가 세 번 연속 명중하면 대상과 관계없이 다음 명중에 피해가 4 추가된다. |

훈장 조각의 예약은 턴을 넘어 유지된다. 수첩의 세 번은 각 타격의 실제 직접 명중으로 집계하며, 방어도가 전부 막은 명중도 포함한다.

## 검증 및 실제 촬영

- Unity EditMode 29건 통과, 실패 및 건너뜀 0건. 시작 정화, 명중 효과, 기존 성배 효과와 상점 검사 두 건을 포함한다.
- Windows 빌드 성공. Direct3D11에서 1600×900 화면 3장을 촬영했다. 유물 8종과 획득 순서를 실제 회차 저장에서 복원했다.
- [유물 8종과 금 간 방패끈 상세](WorkshopRelics.png)
- [첫 유료 방어 카드의 행동력 비용 0](FirstDefenseCardCost.png)
- [검 카드 다음 방패 카드의 방어도 10](SwordThenShieldBonus.png)

첫 방어 카드의 기본 비용 1이 0으로 내려갔고 사용해도 행동력이 줄지 않았다. 검 카드 다음 방패 카드로 방어도 8과 훈장 조각의 방어도 2를 받아 합계 10이 됐다. 다음 방어 카드의 비용은 1이었다.
