# 128일차 22명 전용 능력 공통 기반

---
## 작업 내용

- 각성·붕괴 중 정신력 변화를 기록하되 반대 임계값에 도달해도 기존 상태를 중복 발동하지 않음
- 저장 정신력이 0 또는 100인 캐릭터가 전투에 진입할 때 붕괴 또는 각성을 판정
- 자기 진영 턴 도중 발동한 정신 상태의 첫 턴 감소를 생략하고 상대 턴 중 발동한 상태는 다음 자기 턴부터 감소
- 물리 방어력·마법 저항력을 기획서 8.1의 비율식에 적용하고 약점 배율을 곱한 뒤 최종 피해를 버림 처리
- 피해 계산 표시를 실제 방어 비율식에 맞게 수정
- 검증: 관련 검사 19개 통과. 전체 검사 194개 중 193개 통과, 에셋 처리 지연으로 시간 초과된 카드 선택 화면 검사 1개는 단독 재실행 통과

---
## 대조 결과와 남은 작업

- 현재 시작 전용 카드가 연결된 캐릭터: 바보, 마법사, 여사제, 여황제, 황제, 교황, 전차, 별
- 나머지 14명은 현재 역할별 임시 카드가 사용되며 캐릭터별 전용 카드와 패시브 구현이 필요
- 개별 카드의 정상·각성·붕괴 효과, 사용 확정 시 효과 고정, 공용 카드 사용자 선택, 피해 흡수형 방어도는 별도 보완이 필요
- 사망한 소유자의 카드를 드로우에서 건너뛰고 부활 시 다시 허용하는 규칙도 보완이 필요
- 캐릭터별 미확정 수치와 효과는 완료된 것으로 간주하지 않음
