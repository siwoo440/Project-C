# 160일차 : 전투 시작 드로우 유물 추가

- 균열의 렌즈, 봉인된 봉투, 흐린 룬 조각을 각각 전투 시작 시 카드 한 장을 추가로 뽑는 유물로 추가했습니다.
- 세 유물은 한 전투의 시작 시 한 번씩 발동하며 함께 보유하면 드로우가 합산됩니다. 손패 초과 카드는 기존 규칙에 따라 버립니다.
- 실제 상점 구매·시트 가격·보물 후보·저장 복원과 전투 덱 연결을 확인했습니다.
- `DrawRelicsShop.png`는 세 유물이 실제 상점에 표시되는 화면입니다.
- 유물 이미지는 기존 유물 이미지를 참고해 이미지 생성 도구로 제작했습니다. 요청 내용은 보라색 균열이 있는 렌즈, 밀랍 봉인이 있는 봉투, 푸른 룬이 새겨진 석편입니다.
- Unity 편집 모드 검사 323개를 모두 통과했습니다.
