# 253일차 성배 카드 확장 · 부활의 씨앗부터 구원의 원까지

카드 시트 135~142행의 원화·효과를 연결하고 보물 보상과 회차에 저장한다.

| 카드 | 효과 |
| --- | --- |
| 부활의 씨앗 | 상태를 받은 아군이 쓰러지면 최대 체력의 20%를 올림해 1회 부활한다. 적 턴을 두 번 마칠 때까지 유효하다. |
| 축성 방벽 | 생존 아군 각각에게 방어도 12와 두 적 턴 동안 마법 피해 저항 10%를 준다. |
| 빛의 폭우 | 생존 적 전체에게 마법 피해 8을 주고 생존 아군 각각을 체력 12만큼 회복한다. |
| 순백의 맹세 | 지정 아군이 받을 다음 피해를 한 번 무효로 하고 정신력을 8 회복한다. |
| 고통 분산 | 두 적 턴 동안 적의 직접 피해 중 25%를 같은 상태의 생존 아군에게 나눈다. |
| 기적의 잔향 | 이번 아군 턴 동안 상태를 가진 아군의 직접 카드 회복량을 6 높인다. |
| 심판의 성수 | 지정 적에게 마법 피해 18을 주고, 명중 뒤 생존하면 해제 가능한 강화 1개를 제거한다. |
| 구원의 원 | 생존 아군 전체의 공포를 제거하고 각각 체력 8을 회복한다. |

부활의 씨앗은 피해 무효와 생존 보호를 먼저 정산한 뒤 실제 전투불능에 발동한다. 고통 분산은 원래 대상의 피해 감소 후 방어도 적용 전 수치의 25%를 내림한다. 나머지는 출전 순서대로 한 점씩 받는다. 기존 단일 연결과 대신 받기가 우선한다. 분담 몫은 분담자의 방어도를 건너뛰고 개인 피해 감소와 피해 보호를 적용한다. 빛의 폭우는 적 처치로 전투가 끝날 때 생존 아군의 회복을 적용한 상태로 승리를 정산한다.
