# 133일차: 설비 강화 화면 확대와 UI 적용

- 로비 설비 강화 창을 화면 크기에 맞춰 확대하고 제작한 금속 프레임 이미지를 적용했다.
- 설비 목록, 선택 단계, 현재·다음 효과와 강화 비용을 한글로 표시하고 보유 자원에는 기존 자원 아이콘을 사용한다.
- 설비 선택 강조, 스크롤, 자원 변화에 따른 강화 가능 상태, 닫기와 기존 F7 단축키를 연결했다.
- `FacilityPanel.png`는 격리된 검증 프로젝트에서 테스트 자원을 지급한 실제 로비 화면이다.
- 격리된 Unity 6000.3.21f1 프로젝트에서 전체 EditMode 회귀 검사 214개가 통과했다.
