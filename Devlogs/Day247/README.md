# 247일차 성배 카드 확장 · 축복부터 온기까지

카드 시트 104·105·106·107·108·109·111·114행의 원화와 효과를 연결한다. 보물에서 선택한 카드 소유자를 회차에 저장할 수 있다.

| 카드 | 효과 |
| --- | --- |
| 축복 | 생존 아군 전체의 물리 방어력을 2턴 동안 4 높인다. |
| 성스러운 방패 | 생존 아군 각자가 받을 다음 피해를 한 번 무효로 한다. |
| 생명의 빛 | 현재 전투에서 쓰러진 출전 아군 한 명을 최대 체력 30%로 되살린다. 소수점은 올린다. |
| 신성한 심판 | 모든 적을 마법 피해 12로 공격하고, 명중한 적의 불굴·전투불능 방지를 피해 직전에 해제한다. |
| 천상의 은총 | 생존 아군 각각의 체력을 20 회복시키고 이번 아군 턴 동안 각각 공격력 2를 부여한다. |
| 성배의 심판 | 생존 아군 각자가 받을 첫 치명 피해를 막아 체력 1로 생존시킨다. |
| 응급 처치 | 지정 아군을 체력 5 회복시키고 출혈 상태 하나를 해제한다. |
| 온기 | 지정 아군의 화상을 해제하고 방어도 3을 부여한다. |

천상의 은총의 추가 강화는 시트에 종류와 수치가 없어 공격력 2를 적용했다. 생명의 빛은 부활한 출전 아군의 정신력을 보존한다. 성배의 심판은 기존 피해 무효와 불굴로 막지 못한 치명 피해에 발동한다.

## 검증 및 실제 촬영

- Unity EditMode 34건 통과, 실패 및 건너뜀 0건. 성배 카드 획득과 저장, 부활과 치명 피해 방지, 상점 검사 두 건을 포함한다.
- Windows 빌드 성공. Direct3D11에서 1600×900 전투 화면 3장을 촬영했다.

- [생명의 빛과 지정 가능한 쓰러진 아군](LightOfLifeFallenTarget.png)

생명의 빛은 행동력 3을 지불하고 쓰러진 여사제를 체력 28/92로 부활시켰다. 여사제의 정신력 50은 유지됐다.
