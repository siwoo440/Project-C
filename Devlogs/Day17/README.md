# 17일차 개발일지 - 카드·적 행동 순서 및 캐릭터 움직임 연출 구축

---
## 개발 목표

- 카드 사용과 적 행동을 단계별 연출 순서로 실행
- 행동 중 카드 및 턴 종료 입력 잠금
- 공격자의 전진·복귀와 대상의 피격 흔들림 구현
- 회복 대상의 크기 변화 연출 구현
- 전투 종료 및 화면 비활성화 시 연출 상태 안전 복구

---
## 개발 환경

- Unity 6000.3.21f1
- 전진 거리: 22
- 전진 및 복귀 시간: 각각 0.12초
- 피격 흔들림 시간: 0.18초
- 피격 흔들림 거리: 6
- 회복 크기 배율: 1.08

---
## 주요 구현 내용

### 1. 공통 행동 순서 실행기 추가

- 플레이어 카드와 적 행동에서 함께 사용하는 `BattleActionSequenceRunner` 추가
- 공격 전진, 효과 적용, 대상 반응, 공격자 복귀 순서 통합
- 회복 준비, 효과 적용, 회복 반응 순서 통합
- 진행 중인 연출 취소와 원래 상태 복구 기능 추가

### 2. 캐릭터 움직임 연출 추가

- `BattleUnitMotionView`를 각 전투 유닛 화면에 자동 연결
- 아군은 오른쪽, 적은 왼쪽으로 전진하도록 진영별 방향 적용
- 유닛 전체가 아닌 초상화 영역만 움직여 체력 UI와 전투 배치 유지
- 피격 시 좌우 흔들림, 회복 시 크기 확대 후 복귀 연출 적용

### 3. 카드 행동 순서 개선

- 카드를 사용하는 즉시 결과가 표시되던 처리를 순차 연출 방식으로 변경
- 공격 카드의 피해 및 AP 소비를 타격 시점에 적용
- 회복 카드의 회복 및 AP 소비를 효과 시점에 적용
- 행동 완료 후에만 다음 카드 입력 허용

### 4. 입력 잠금 처리

- 행동 연출 중 카드 선택과 카드 사용 차단
- 행동 연출 중 턴 종료 버튼 차단
- 행동 완료, 취소, 전투 종료 시 입력 상태 복구

### 5. 적 행동 연출 통합

- 적 행동을 공통 순서 실행기로 연결
- 여러 적이 행동할 때 한 명씩 순차 실행
- 사망한 적은 움직임과 행동 대상에서 제외
- 적 공격의 피해 적용 시점과 피격 반응 시점 일치

### 6. 피해·회복 반응 연동

- 16일차 피해 및 회복 이벤트와 움직임 연출 연결
- 피해 발생 시 플로팅 숫자와 피격 흔들림 동시 출력
- 회복 발생 시 플로팅 숫자와 회복 크기 연출 동시 출력
- 연출 중 유닛이 사망해도 원래 위치와 크기 복구

### 7. 초상화 미설정 상태 보완

- 초상화가 없는 유닛도 위치와 움직임을 확인할 수 있도록 임시 색상 표시 적용
- 아군은 파란색, 적은 빨간색 계열로 구분
- 실제 초상화가 설정되면 원래 이미지 색상 사용

## 개발 결과

카드와 적 행동이 즉시 처리되지 않고 준비, 이동, 효과, 반응, 복귀 순서로 보이도록 개선했다. 공통 실행기를 사용해 플레이어와 적의 행동 흐름을 통일했으며, 이후 타격 이펙트와 사운드를 같은 효과 시점에 연결할 수 있는 구조를 마련했다.
