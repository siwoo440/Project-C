# 233일차 검 카드 확장 · 분노 해방부터 왕의 참격까지

| 카드 | 전투 효과 |
| --- | --- |
| 분노 해방 | 2턴 동안 사용자의 공격력은 6 증가하고 물리 방어력은 2 감소한다. |
| 처단의 검 | 적에게 물리 피해 20을 주고 이 공격으로 직접 처치하면 공용 행동력 1을 최대치까지 회복한다. |
| 균열 베기 | 모든 생존 적에게 물리 피해 8을 주고 명중한 적의 물리 방어력을 2턴 동안 2 감소시킨다. |
| 전장의 결의 | 생존 아군 전체의 공격력을 2턴간 2 늘린다. 사용 즉시 방어도 4를 주고 다음 아군 턴 시작에 생존 아군에게 다시 4를 준다. |
| 피의 역류 | 출혈 상태인 모든 생존 적에게 물리 피해 10을 준다. |
| 칼날 폭주 | 이번 턴 사용자가 쓰는 검 카드의 피해를 타격마다 4 늘린다. |
| 단죄 베기 | 버프가 있는 적에게 물리 피해 22를 준다. 명중 후 버프 하나를 제거한다. |
| 왕의 참격 | 모든 생존 적에게 물리 피해 18을 준다. 이후 살아 있는 적 중 최대 체력이 가장 높은 적에게 추가 물리 피해 12를 준다. 동률이면 전투 배치에서 앞선 적을 고른다. |

통합 Windows 플레이어에서 전장의 결의를 사용해 생존 아군 네 명의 즉시 방어도 4와 다음 턴 방어 예약을 확인했다. 제한 없는 예약 중첩은 내부 최대값 대신 현재 횟수로 표시한다.

격리된 검증 프로필에서 카드 획득·선택 소유자 저장, 전투 규칙, 상태 화면과 232일차 유물·상점 회귀를 포함한 73건이 통과했으며 실패와 건너뜀은 없었다.
