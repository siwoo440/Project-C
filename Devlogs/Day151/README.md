# 151일차: 전투 UI 이미지와 상태 아이콘 적용

- 이미지 생성으로 제작한 손패 패널, 카드 프레임, 비용 배지와 게이지를 전투 화면에 적용했다.
- 기존에 제작한 이미지로 전투 버튼과 상세 설명창의 디자인을 통일했다.
- 구현된 상태 효과 15종을 각각 정사각형 아이콘으로 표시한다. 왼쪽 아래는 남은 턴, 오른쪽 아래는 효과 수치이며 상세 설명에서 중첩과 효과를 확인할 수 있다.
- 아이콘은 사용 가능한 너비에 맞추어 최대 두 줄로 배치한다.
- [전투 화면](BattleHud.png)은 실제 전투 화면이며, 아이콘 확인을 위해 상태 효과를 임시로 부여했다.
- 검증: 전투 UI와 상태 아이콘 검사 및 Unity 전체 검사 307개 통과.
