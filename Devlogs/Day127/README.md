## 작업 내용

- 탐사 성공과 실패에 결과 화면과 거점 복귀 버튼을 표시하고 성공 정산 정보를 유지
- 환경 피해 전멸 후 사망 캐릭터의 회복 상태를 먼저 반영하고 거점 자동 저장
- 동일한 탐사 종료를 다시 저장하거나 다음 프레임을 처리할 때 회복 횟수 중복 차감 방지
- 설비 강화 유지, 회복 중 편성 제한, 다른 캐릭터로 재출발과 회복 완료 후 재출전 검증
- 실제 환경 피해 전멸부터 거점 복귀, 맵 선택, 편성, 재출발까지의 씬 흐름 검증
- 실제 탐사 실패 화면 캡처: `ExplorationFailure.png`
- 전체 EditMode 회귀 검사 180개 통과
