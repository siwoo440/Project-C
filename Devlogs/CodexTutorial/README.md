# 도감과 튜토리얼 사용성 개선

도감에서 내부 검증용 카드 7장을 제외하고 공개 카드 303장을 확인했다. 카드 배지에는 기존 종류 아이콘과 AP 비용을 표시한다. 분류 패널에서 종류순과 AP 비용순을 선택하고 같은 버튼을 다시 눌러 순서를 뒤집는다. 화살표는 현재 기준의 방향을 표시한다. 전액 비용인 `AP X`는 오름차순의 끝에 둔다.

등록 항목에 원화 52종을 추가하고 목록과 상세의 이미지 원본을 일치시켰다. 상태 효과 20종과 포션 1종의 설명을 한국어와 영어로 보완했다. 도감 분류에 공용 스크롤바를 적용했다. 거점·탐사·전투 도움말의 예시 화면과 장식 테두리를 같은 안쪽 영역에 배치했다.
