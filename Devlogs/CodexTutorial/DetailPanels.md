# 도감 상세 배경과 탐사 벽 충돌

도감 상세에 이미지 생성으로 제작한 배경 세 장을 적용했다. 제목은 중앙의 청록 명패에 배치했다. 왼쪽은 어두운 청록 바탕에 금색 모서리를 두른 원화 액자, 오른쪽은 설명을 읽기 쉽도록 장식을 외곽에 둔 설명판이다. 세 이미지는 각각 별도 스프라이트다. 모서리와 테두리를 보존하는 9분할로 패널 크기에 맞춘다.

- [상태 이상 · 은신 1280×800](DetailStealth1280x800.png)
- [카드 · 검격 반사 1600×900](DetailCard1600x900.png)
- [유물 · 파편화된 거울 1600×900](DetailRelic1600x900.png)

탐사에서 벽 스프라이트용 픽셀을 읽으려다 발생하는 외곽선 경고를 수정했다. 8개 지역의 벽 스프라이트를 임포트 시 미리 자르고 정사각형 충돌 외곽선을 지정했다. 원본 PNG와 픽셀 읽기 비활성 설정을 유지했다.

Unity 검사 60건 통과, 실패와 건너뜀 0건. Windows 실행본에서 벽 충돌, 인접 바닥 이동, 탐사와 전투 진입을 확인했다. 이번 실행 로그의 스프라이트 외곽선 생성 경고는 0건이었다.
