# 272일차 유물 확장 · 유리모래 렌즈부터 재폭풍 재주머니까지

유물 시트 203~210행의 효과와 투명 원화를 구현하고 실제 상점 및 회차 저장에 등록한다.

| 유물 | 효과 |
| --- | --- |
| 유리모래 렌즈 | 실명 중인 적에게 명중하는 아군의 직접 마법 카드 타격 피해를 4 높인다. |
| 말라붙은 선인장즙 | 아군이 건 중독의 지속 피해를 1 늘리고 전투 중 아군이 받는 체력 회복을 5% 낮춘다. |
| 폭풍막이 천조각 | 아군이 적의 직접 광역 타격에 명중당할 때 피해 적용 전에 방어도 3을 얻는다. |
| 잠복충 더듬이 | 첫 실제 아군 턴에 사용한 첫 직접 공격 카드의 첫 유효 타격 피해를 6 높인다. |
| 폐광 검은 모래 | 적의 물리 방어력을 실제로 낮추면 20% 확률로 중독을 두 적 턴 동안 부여한다. |
| 황폐한 가죽끈 | 현재 체력이 최대치의 50% 이하인 적에게 주는 아군의 직접 카드 타격 피해가 10% 증가한다. |
| 순례자의 깨진 나침판 | 정신력이 최대치의 30% 이하인 아군이 적에게 받는 정신 피해가 30% 감소한다. |
| 재폭풍 재주머니 | 화상 중인 적이 실제로 쓰러지면 무작위 생존 적 한 명에게 같은 수치의 화상을 두 적 턴 동안 전이한다. |

잠복충 더듬이는 해당 카드가 모두 빗나가도 첫 공격 기회를 사용한다. 피해와 회복의 비율 계산에는 기본 전투 정산의 정수 내림을 적용한다. 실제 적이 쓰러질 때 전이가 일어나며 같은 적의 보스 단계 전환에서는 발생하지 않는다.
