# 탐사 오브젝트 F 키 상호작용

이벤트, 보물, 휴식, 상점과 이용 가능한 계단에 닿으면 캐릭터 오른쪽에 ‘F : 상호작용’이 표시됩니다. 안내는 카메라 이동을 따라가며, 새로 F를 누르면 가까운 대상의 원래 동작이 실행됩니다. 탐사 도움말에도 같은 조작을 적용했습니다.

---

## 검증

- Unity 검사 15건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows 탐사에서 원거리 F 입력, 이미 F를 누른 채 접근, 범위 이탈을 확인했습니다. 근접 상태에서 새로 F를 눌러 실제 이벤트를 열었고, 완료 뒤에는 같은 대상의 안내와 상호작용이 사라졌습니다.
