# 111일차: 탐사 상태 복원과 이어하기

---
## 작업 내용

- 저장 파일의 버전·캐릭터·카드·유물·소모품·상점 식별자와 수치를 검증한 뒤 탐사 상태를 복원한다.
- 파티·시작 덱·회차 덱·강화 단계, 층·시드·위치, 조우·이벤트·위험·상점·휴식 상태와 거점 자원을 복원한다.
- 거점 저장과 탐사 저장 중 최신 유효 데이터를 선택해 이어한다.
- 새로하기를 확인하면 이전 탐사 저장을 제거하고, 취소하면 유지한다.
- 현재 프로젝트의 카드·유물·소모품을 참조하는 저장 복원용 원본 목록을 추가했다.

---
## 검증과 남은 작업

- 실제 탐사 씬의 시드·위치·파티와 자원 복원, 손상 데이터 차단, 새 게임 저장 정리 및 빈 덱 유지를 검증했다.
- 격리된 Unity 프로젝트 복사본에서 전체 EditMode 테스트 156개 통과.
- 저장·불러오기 슬롯 화면은 112~113일차, 자동 저장 지점은 114일차에 구현한다.
- 실제 사용자 화면에서의 시각 배치와 독립 실행 빌드는 확인하지 않았다.
