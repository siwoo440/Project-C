# 251일차 성배 카드 확장 · 해독 의식부터 생명수까지

카드 시트 125·126·127·128·130·131·132·133행의 원화와 효과를 연결하고 보물 보상과 회차 저장에 등록한다.

| 카드 | 효과 |
| --- | --- |
| 해독 의식 | 생존 아군 전체의 중독을 없애고 각각 체력 4를 회복한다. |
| 수호 성가 | 생존 아군 각자에게 방어도 8을 준다. |
| 성역 | 아군이 받는 피해를 10% 낮춘다. 적 턴을 두 번 마치면 효과가 끝난다. |
| 빛의 징벌 | 모든 생존 적에게 마법 피해 8을 주고, 명중한 불사형 적에게 피해 4를 추가한다. |
| 희생 치유 | 시전자 체력 6을 지불하고 지정 아군을 체력 20만큼 회복한다. 시전자 체력이 7 이상일 때 자신에게도 사용할 수 있다. |
| 고요한 찬가 | 생존 아군의 공포 적용을 30% 확률로 막는다. 적 턴을 두 번 마치면 효과가 끝난다. |
| 축복 전이 | 살아 있는 서로 다른 아군 두 명을 지정해, 첫 아군의 복사 가능한 강화 하나를 둘째에게 복사한다. |
| 생명수 | 지정 아군을 즉시 체력 10만큼 회복하고 다음 아군 턴 시작에 체력 6을 회복한다. |

축복 전이는 제공 아군의 강화 적용 순서에서 둘째 아군이 받을 수 있는 첫 강화를 고르며 수치와 지속시간, 중첩을 복사한다. 개별 아군에 연동된 보호나 일회용 예약은 제외했다. 고요한 찬가는 기존 면역을 먼저 적용하며, 찬가로 막지 못한 공포에는 조용한 종끈의 별도 판정이 이어진다.

## 검증과 실제 화면

Unity EditMode 검사 40건이 통과했다. 상점 진열과 구매 확인 검사 2건을 포함했으며 실패와 건너뜀은 각각 0건이다. Windows 독립 실행 플레이어에서 1600×900으로 촬영했다.

- `BlessingTransferChooseAlly.png`에서 강화 보유자를 선택한 뒤 다른 아군을 고르는 화면을 확인했다.
- `BlessingTransferResolved.png`에서 같은 수치와 지속 시간의 강화가 마법사에게 적용되고 바보의 원래 강화도 유지되는 것을 확인했다.
- `WaterOfLifeRecoveryQueued.png`에서 생명수로 체력 10을 즉시 회복하고 회복 예약이 표시되는 것을 확인했다. 다음 아군 턴에 예약 회복 6이 실제로 적용됐다.
