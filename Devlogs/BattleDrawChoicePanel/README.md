# 서고 먼지갈피 카드 선택창

전투 화면을 회색 반투명 배경으로 덮고, 중앙에 카드 선택 패널을 배치했습니다. 카드 원화, 이름, AP, 설명의 영역을 나누고 긴 설명을 휠로 읽을 수 있게 했습니다. 페이지 이동과 취소 버튼은 카드 아래에 배치했습니다.

---

## 검증

- Unity 검사 14건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows 전투에서 실제 마우스로 다음 페이지의 세 번째 카드를 선택했습니다. 덱 순서와 행동력, 버린 카드가 그대로 유지되는 것을 확인했습니다.
- 1600×900과 1280×800에서 설명과 레벨 표시가 겹치지 않는 선택창을 촬영했습니다.
