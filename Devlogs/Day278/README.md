# 278일차 유물 확장 · 사막의 마지막 물방울부터 정전 기록칩까지

유물 시트 227~234행의 효과와 새 원화를 유물 목록, 상점 및 탐사 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 사막의 마지막 물방울 | 생존 아군 중 부상자가 있는 첫 아군 턴에 생존 아군 전원이 체력을 20 회복한다. 발동 후 전투 종료까지 아군이 받는 체력 회복이 20% 감소한다. |
| 폭풍왕의 회전 고리 | 아군이 적의 공격을 회피할 때 생존 적 하나를 무작위로 골라 일반 피해 6을 준다. |
| 묻힌 도시의 문장 | 사막 이벤트에서 원래 보상을 받은 뒤 추가 보상 하나를 한 탐사에 한 번 고른다. |
| 끊어진 구리선 | 아군의 확률형 감전 부여 확률을 5%p 높인다. |
| 폐전지 조각 | 첫 실제 아군 턴의 최대 및 현재 행동력을 1 높이고, 두 번째 실제 아군 턴에는 각각 1 낮춘다. |
| 녹슨 나사 묶음 | 기계형 적이 아군에게 직접 주는 공격 피해를 2 줄인다. |
| 깨진 렌즈캡 | 아군이 활성 표식이 있는 적을 공격할 때 명중률을 10%p 높인다. |
| 정전 기록칩 | 벙커 이벤트의 함정이 주는 체력 피해를 15% 줄인다. |

지역 한정 효과는 이벤트 원본이 지정한 사막 또는 벙커에서 적용한다. 현재 이벤트 원본의 지역 분류는 그대로 유지한다. 사막과 벙커에서의 발동은 해당 지역을 명시한 검증용 이벤트에서 확인한다.
