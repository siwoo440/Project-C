# 267일차 지팡이 카드 확장 · 심연의 주문부터 공허 붕괴까지

카드 시트 193~199행의 원화와 효과를 전투, 보물 획득, 도감과 회차 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 심연의 주문 | 지정 적에게 마법 피해 15를 준다. 명중한 생존 적의 정신력이 8 감소한다. |
| 대폭발 | 생존 적 전체에 마법 피해 28을 준다. 명중한 생존 적에게 60% 확률로 화상 2를 두 턴 동안 부여한다. |
| 절대영도 | 생존 적 전체에 마법 피해 18을 준다. 명중한 생존 적은 각각 50% 확률로 다음 행동 한 번을 잃는다. |
| 폭풍의 눈 | 생존 적 전체에 마법 피해 14를 두 차례 준다. 타격 시 감전 중인 적에게 해당 타격의 피해 8을 더한다. |
| 마도 해방식 | 실제로 지불한 현재 행동력 X마다 생존 적 전체에 마법 피해 6을 준다. X가 4 이상일 때 명중한 생존 적에게 각 30% 확률로 한 적 턴 기절을 적용한다. |
| 시간 정지 | 생존 적 전체의 다음 행동을 한 번 취소하고 아군 공용 손패에 카드 한 장을 뽑는다. |
| 공허 붕괴 | 지정 적에게 마법 피해 45를 준다. 그 적을 처치하지 못하면 자신의 정신력이 10 낮아진다. |

시간 정지의 아군 드로우는 기존 공용 손패를 사용한다. 절대영도의 행동력 1 감소는 적마다 다음 행동 한 번 취소로 정산한다. 공허 붕괴는 대상이 살아 있는 보스 단계 전환을 처치 실패로 처리한다.

---

## 검증

- Unity 검사 31건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건이다.
- 실제 Windows 전투에서 마도 해방식을 사용해 행동력 6을 한 번 지불하고 살아 있는 시험용 적 둘에 각각 방어 적용 전 마법 피해 36을 기록했다.
- 공허 붕괴의 실패 비용이 한 번에 정신력 10인지 확인했다. 원본 공격 처치, 반향 처치, 생존 보스의 단계 전환을 각각 재현했다.
