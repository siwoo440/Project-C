# 100일차: 별 예약 회복 카드

---
## 구현 내용

- 별의 전용 시작 카드 `남은 빛`을 추가하고 전용 일러스트를 연결했습니다.
- 아군 한 명에게 예약 회복을 부여하며, 다음 아군 턴 시작에 임시 수치인 체력 6을 회복합니다.
- 기존 재생과 예약 회복을 별도 상태로 처리하고, 대상이 사망하면 회복하지 않습니다.
- 카드의 비용은 임시로 AP 1을 사용합니다.

---
## 검증

- 별도 Unity 프로젝트 복사본에서 EditMode 전체 테스트 115개 통과.
- 다음 턴 발동, 사망 시 불발, 기존 재생과의 독립 처리 및 카드 일러스트 연결 확인.

---
## 남은 작업

- 별의 예약 회복 관련 패시브와 방어도 효과 구현.
- 회복 수치와 카드 비용의 실제 플레이 밸런스 조정.
