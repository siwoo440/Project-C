# Windows UI 텍스처와 탐사 이벤트창 최적화

UI 텍스처 10종의 PC 임포트 최대 크기를 조정했다. 상점 확인창에도 쓰이는 비용 배지는 1024, 튜토리얼 페이지 버튼과 도감 상세에 확대되는 상태 아이콘 4종은 512, 그 외 작은 아이콘은 256으로 설정했다. 원본 PNG와 Unity 에셋 식별자를 보존했다.

탐사 이벤트창의 전체 화면 복사와 CPU 픽셀 루프를 GPU 캡처와 축소로 바꿨다. 같은 해상도의 작은 배경 텍스처를 다시 쓰고 크기가 바뀌면 이전 배경을 해제한다. 두 해상도에서 기존 화면의 방향과 어두운 배경 표현, F 키 입력, 이벤트 닫기 후 이동 복원을 확인했다.

## 전후 비교

동일한 격리 프로젝트를 Windows·Direct3D 11로 빌드했고 두 플레이어를 연달아 실행했다. 시간은 이벤트 배경 캡처 호출의 메인 스레드 경과 시간이다.

| 측정 항목 | 적용 전 | 적용 후 |
| --- | ---: | ---: |
| Unity 전체 빌드 보고서 | 1,140,076,844 B | 1,081,066,188 B |
| `Gallery_Data` | 1,087,157,822 B | 1,028,147,166 B |
| 조정한 텍스처 10종의 빌드 바이트 합계 | 63,015,520 B | 4,003,872 B |
| 1600×900 중앙값, 11회 | 2.0904 ms | 0.0151 ms |
| 1600×900 95백분위 | 2.5730 ms | 1.3266 ms |
| 1280×800 중앙값, 10회 | 1.6124 ms | 0.0183 ms |
| 1280×800 95백분위 | 2.2440 ms | 0.1034 ms |

`Gallery_Data`는 59,010,656 B, 약 59.0 MB 줄었다. 1600×900에서 첫 캡처는 2.7440 ms에서 2.6281 ms로 줄었으며 같은 화면을 반복해서 열 때 감소 폭이 더 컸다.
