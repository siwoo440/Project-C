# 279일차 펜타클 카드 확장 · 룬 장벽부터 무한 계약까지

카드 시트 242~249행과 제공된 원화 8장을 실제 보물 획득, 소유자 선택, 탐사 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 룬 장벽 | 생존 아군마다 방어도 10을 얻는다. 다음 아군 턴의 최대 및 현재 행동력이 1 증가한다. |
| 금빛 미끼 | 생존 적 전체에 표식을 한 적 턴 동안 부여한다. 적의 직접 공격 피해를 두 적 턴 동안 10% 낮춘다. |
| 계약 파기 | 기본 행동력 3과 추가 행동력 1을 함께 지불한 뒤, 생존 아군마다 가장 먼저 적용된 해제 가능 약화 하나를 제거한다. |
| 고대 계산식 | 카드 3장을 뽑는다. 이번 아군 턴에 뽑은 카드의 고정 기본 행동력 비용이 1 증가한다. |
| 룬 폭주 장치 | 비용을 지불한 직후 남은 행동력마다 생존 적 전체에 기본 마법 피해 4를 준다. |
| 황금률 | 비용을 지불한 직후 남은 행동력마다 생존 아군 전체의 체력을 기본 5 회복한다. |
| 운명의 재작성 | 다른 손패를 모두 버리고 시전자 소유의 서로 다른 전설 카드 2장을 이번 전투에 생성한다. |
| 무한 계약 | 보유한 행동력을 전부 X로 지불하고 체력을 X×4 지불한다. 이번 턴에 행동력 X×2를 얻으며, 시전자의 체력은 1 이상 남아야 한다. |

금빛 미끼의 피해 감소는 기존 고정 공격 보정 뒤에 적용하며, 적 예고와 실제 타격에서 같은 값을 사용한다. 룬 폭주 장치와 황금률은 결제 직후 잔여 행동력을 카드 한 장당 한 번 확정하므로 대상별 정산 중 행동력이 변해도 원본 수치는 유지된다.
