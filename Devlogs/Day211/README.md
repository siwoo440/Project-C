# 211일차 윈터폴 탐사 이벤트 ‘유리화된 들판’

유리처럼 굳은 땅속에서 그림자가 손을 뻗는다. 플레이어는 직접 유리를 깨거나, 다음 전투에 영향을 주는 방식으로 들판을 통과한다. [기획서 5.2.13](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.wi4rzj33f2lg)

---

## 세 가지 선택

| 선택 | 적용 결과 |
| --- | --- |
| 유리를 깨서 꺼낸다 | 선택한 생존자 한 명이 체력 6을 잃고 자신의 덱에 카드 한 장을 받는다. 등록된 희귀 공용 카드와 잿빛 저주의 확률은 각각 50%다. 체력이 6 이하면 쓰러지고 마지막 생존자라면 탐사가 끝난다. |
| 조심히 지나간다 | 다음 실제 전투에서 모든 생존 아군의 회피율이 10%p 오른다. 적이 두 번째 턴의 행동을 마치면 효과가 끝난다. |
| 눈을 감고 달린다 | 다음 실제 전투의 첫 아군 턴에 모든 생존 아군이 실명으로 명중률 15%p를 잃는다. 기존에 적이 부여하는 실명은 25%p를 유지한다. |

---

## 전투와 저장

유리를 깰 행동자 선택을 취소하면 체력과 덱을 그대로 유지한다. 방 식별자로 카드 분기를 고정해 선택 전 저장을 다시 불러와도 같은 결과가 나온다. 선택 후에는 방 완료 기록, 체력, 카드 소유자가 함께 복원된다.

회피와 실명은 같은 다음 전투에 함께 적용할 수 있다. 서로 다른 방에서 같은 효과를 예약해도 강도와 지속 턴은 한 번분이다. 지도 조각으로 일반 적을 피하면 두 효과 모두 대기 상태를 유지한다. 실제 전투가 시작되면 아군 상태 아이콘과 적 공격의 상세 명중률에 반영된다.

이벤트 목록 버전 4 이하를 사용한 기존 저장은 현재 층의 배치를 유지한다. 새 층부터 버전 5의 여덟 후보에 들판이 들어간다. [행동과 전투 시작 효과](../../Assets/_ProjectC/Scripts/Exploration/GlassFieldEvent.cs) · [명중 판정](../../Assets/_ProjectC/Scripts/Battle/BattleHitChance.cs) · [자동 검사](../../Assets/_ProjectC/Tests/Editor/GlassFieldEventTests.cs)

Unity에서 210·211일차 관련 검사 18건이 모두 통과했다. 들판 검사 3건은 선택지·삽화 공개, 희귀 카드와 저주의 실제 지급·사망·취소·재불러오기, 전투 씬의 명중률과 아군·적 턴별 만료를 확인했다.
