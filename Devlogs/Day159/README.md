# 159일차 : 유물 상점 가격 범위 적용

- 실제 상점의 시트 유물은 구매 가격 범위 안에서 상점 방과 상품 식별자에 따라 가격이 정해집니다.
- 같은 상점에서는 다시 열거나 저장을 불러와도 같은 가격을 유지하며, 표시 가격과 실제 골드 차감액이 일치합니다.
- 시트에서 찾을 수 없는 테스트 상품과 다른 상품 종류는 기존 가격을 유지합니다.
- `RelicPriceShop.png`는 가격이 적용된 실제 상점 화면입니다.
- 유물 판매 기능과 미구현 유물 효과는 후속 작업입니다.
- Unity 편집 모드 검사 319개를 모두 통과했습니다.
