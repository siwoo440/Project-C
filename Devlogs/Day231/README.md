# 231일차 검 카드 확장 · 피의 맹세부터 돌파 참격까지

| 카드 | 전투 효과 |
| --- | --- |
| 피의 맹세 | 사용자 체력 5를 소모해 2턴 동안 사용자의 검 카드 피해를 5 늘린다. |
| 방어 붕괴 | 적에게 물리 피해 10을 주고 2턴 동안 물리 방어력을 3 낮춘다. |
| 위협 돌진 | 적에게 물리 피해 9를 준다. 명중 시 35% 확률로 1턴 동안 공포를 부여해 대상의 회피를 막는다. |

| 마무리 자세 | 이번 턴에 사용자가 체력 50% 이하인 적에게 주는 카드 피해가 30% 증가한다. |
| 피의 추적 | 출혈 상태인 생존 적 한 명에게 물리 피해 16을 준다. |

| 돌파 참격 | 현재 가로열의 모든 생존 적에게 물리 피해 14를 준다. |

Windows 플레이어에서 피의 맹세를 쓰자 바보의 체력이 94에서 89로 줄었다. 절단 일격은 체력이 절반보다 높은 잿빛 방랑자에게 맹세를 포함한 원본 피해 23을 주었다. 방어 적용 후 적의 체력은 50에서 28로 줄고 받는 회복량 −50%가 2턴 표시됐다.

## 도감 화면 최적화

도감은 화면에 보이는 행과 인접 행의 셀만 만들고, 스크롤하거나 정렬하면 같은 셀에 다른 항목을 연결한다. 기존 여섯 열과 이름 순·역순, 상세 팝업은 유지한다.

| 비교 항목 | 기존 | 변경 후 |
| --- | ---: | ---: |
| 등록 유물 37개 초기 셀 생성 | 37개 | 36개 |
| 등록 유물 37개를 네 번 정렬할 때 추가 생성 | 148개 | 0개 |
| 비교용 549개 초기 셀 생성 | 549개 | 36개 |
| 비교용 549개를 네 번 정렬할 때 추가 생성 | 2,196개 | 0개 |
| 비교용 549개 목록 최초 구성 | 159.826ms | 12.853ms |
| 비교용 549개 목록 네 번 정렬 | 919.719ms | 4.835ms |

Unity 에디터 640×480에서 같은 자료와 절차로 한 번 예열한 뒤 세 번 재서 중앙값을 비교했다. 기존 도감 유물 37개에는 테스트 유물 2종이 포함된다. 37개 목록 스크롤 8회는 0.997ms에서 1.844ms로 늘었고, 549개 목록에서는 12.806ms에서 8.973ms로 줄었다. 플레이어의 전체 프레임 시간은 별도로 측정한다.
