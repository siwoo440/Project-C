# 210일차 타버린 허수아비

윈터폴의 새 층에서 ‘타버린 허수아비’를 만날 수 있다. 조사와 소각은 행동할 생존자를 먼저 고른다. 대상으로 선택한 사람이 비용을 치르고 카드 변화를 받는다. [기획서 5.2.7 타버린 허수아비](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.wi4rzj33f2lg)

| 선택 | 행동자에게 적용되는 결과 |
| --- | --- |
| 조사한다 | 정신력 4 감소. 희귀 공용 카드 한 장 또는 잿빛 저주 한 장을 각각 50% 확률로 자신의 덱에 추가 |
| 불태운다 | 체력 4 감소. 자신의 덱에 잿빛 저주가 있으면 한 장 제거 |
| 지나친다 | 비용과 보상 없이 방을 완료 |

잿빛 저주는 손패 한 칸을 차지한다. 사용할 수 없지만 다른 효과로 버리거나, 턴이 끝나 버린 더미에 들어간 뒤 다시 뽑을 수 있다. 조사 전 탐사를 불러오면 같은 방에서 같은 보상이 나온다. 보상 확정 후에는 카드와 소유자, 실제 지불한 비용, 사건 완료 여부가 함께 저장된다.

---
## 검증

- 저장된 층의 배치 버전을 구분한다. 지도 조각까지의 기존 층은 여섯 후보를 유지하고, 새 버전은 허수아비를 추가한다.
- 조사 선택 취소, 결정 전 불러오기, 확정 뒤 중복 입력과 저장 왕복을 검사한다. 불태우기는 자신의 저주가 없을 때, 두 장일 때, 다른 사람만 보유할 때 및 마지막 생존자의 체력이 4일 때를 검사한다.
- 저주가 일반 상점과 보물 후보에 없는지, 전투 손패와 행동 관리자 양쪽에서 사용이 막히는지, 버리기와 재드로우가 가능한지 검사한다.
- Unity EditMode에서 허수아비 전용 검사 4개가 모두 통과했다. 210·211일차 관련 검사 전체 결과는 18개 통과다. 허수아비 원화와 잿빛 저주 카드 그림의 실제 연결도 확인했다. Windows 플레이어에서 저주를 받은 결과와 실제 손패를 촬영했다.
