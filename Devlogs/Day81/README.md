# 81일차 개발일지

---
## 작업 내용

- 여사제 선택 시 임시 전용 카드 `여사제의 결계` 한 장을 시작 덱에 추가했다.
- 공격이 예고된 아군을 선택하면 2턴간 물리 방어와 마법 저항을 각각 2 올린다.
- 공격 예고가 없는 아군은 선택할 수 없으며 카드 사용에 공용 행동력 1을 소비한다.
- 카드에는 기존 임시 공용 일러스트를 사용한다.

---
## 검증

- 카드 연결 전 실제 전투 테스트 실패와 연결 후 성공을 확인했다.
- 편성, 탐사 조우, 예고 대상 제한, 방어력과 저항력 증가, 예상 피해 감소를 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 92개 통과.

---
## 남은 작업

- 카드 이름과 수치는 임시값이며 여사제의 나머지 전용 카드와 패시브는 미구현이다.
- 다른 캐릭터의 전용 카드와 패시브 및 개별 카드 일러스트 구현이 남아 있다.
