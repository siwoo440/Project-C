# 탐사 원화 확대와 몬스터 추격

탐사 주인공과 몬스터, 계단·보물 상자·휴식처·상점·이벤트·퇴색 위험물에 제작 원화를 적용했습니다. 몬스터는 수호자형과 야수형 두 종류의 탐사 원화를 사용합니다. 각 캐릭터 원화에 여덟 방향별로 두 가지 보행 자세를 배치했습니다.

캐릭터·상호작용 오브젝트와 벽등·사슬·잔해의 그림을 두 배로 키웠습니다. 캐릭터의 발과 장식의 기준점을 유지하면서 좁은 통로와 전투 접촉에 쓰는 기존 충돌 범위를 보존했습니다.

몬스터가 시야 안의 플레이어를 발견하면 머리 위에 표식이 뜨고 실제 바닥을 따라 접근합니다. 대각선에서 벽 모서리를 관통할 수 없으며 시야를 놓치면 잠시 마지막 위치로 이동한 뒤 원래 위치로 돌아갑니다.

## 검증

- Unity 검사 42건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows 윈터폴 탐사에서 캐릭터와 물건의 이미지 크기, 원래 충돌 폭, 감지 범위 밖 정지, 통로에서의 추격과 보행 자세 변화, 입력 차단 중 정지, 같은 적과의 접촉 전투를 확인했습니다.
