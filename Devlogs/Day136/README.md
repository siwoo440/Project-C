# 136일차: 운명·정의 임시 전용 카드 구현

- 운명의 `갈림길`은 무작위 대상을 선택하는 적의 예정 공격을 다시 굴린다. 같은 대상도 다시 선택될 수 있다.
- 실제 조우에서 재굴림을 시험할 수 있도록 시험용 독 적의 첫 공격 대상을 임시로 무작위로 설정했다.
- 정의의 `공정한 판정`은 다른 아군의 첫 예정 공격을 방어력과 방어도 적용 후 절반씩 분담한다. 홀수 피해는 원래 대상에 한 점 더 배정한다.
- 분담자가 사망하거나 적의 공격 대상이 바뀌면 기존 분담은 해제되며, 행동 상세에는 원래 대상과 분담자의 예상 피해를 표시한다.
- 두 캐릭터의 패시브와 정상·각성·붕괴별 세부 효과는 기획 미정으로 남겨 둔다.
- `JusticeSharing.png`는 실제 탐사 조우 전투에서 정의의 전용 카드를 사용해 촬영한 화면이다.
- 실제 카드 사용·피해 예고·전용 카드 저장 복원을 포함한 관련 검사 11개가 통과했다.
- Unity 전체 EditMode 회귀 검사 228개가 통과했다.
