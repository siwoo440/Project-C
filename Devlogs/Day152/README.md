# 152일차: 거점부터 보스까지 전체 흐름 검증

- 실제 거점의 탐사 버튼에서 지역과 네 명의 파티를 선택하고 탐사에 출발했다.
- 일반 조우 접촉, 전투 승리, 결과 확인, 보상 지급과 탐사 복귀를 연결해 확인했다.
- 10층까지의 반복 이동은 층 진행 호출로 단축하고 보스 조우를 직접 시작했다. 실제 보스 전투와 결과 확인, 탐사 성공, 보상 중복 방지, 거점 복귀 및 저장 복원을 검사했다.
- 전투의 적 처치는 테스트용 피해로 단축했다. 따라서 이 검사는 모든 층의 실제 이동과 일반 플레이 난이도, 보스의 모든 패턴을 사람이 직접 플레이해 검증한 결과가 아니다.
- 기획서의 구역 진행도 기반 보스 등장과 현재 층 기반 진행 방식의 차이는 별도 후속 과제로 남는다.
- 검증: 실제 씬 연결 통합 검사를 포함한 Unity 전체 검사 308개 통과.
