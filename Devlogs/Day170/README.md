# 170일차 : 정신력 게이지 색상 개선

- 정신력 수치는 기존대로 0~100을 사용하며 50을 중립으로 유지합니다.
- 정신력 0은 빨강, 50은 중립색, 100은 파랑이며 그 사이 수치는 연속적으로 보간합니다.
- 각성·붕괴 중에도 현재 정신력에 따라 색이 변하며 상태 이름과 지속 턴을 표시합니다.
- 빈 게이지에도 색상 바탕을 표시하고 어두운 색상에서 글자 대비를 높였습니다.
- `MentalGaugeBattle.png`는 실제 전투에서 확인을 위해 네 캐릭터의 정신력을 0·25·75·100으로 설정한 화면입니다.
- 검증: Unity EditMode 전체 검사 335개 통과.
