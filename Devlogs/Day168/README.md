# 168일차 : 상점 할인 유물 추가

- 유물 시트의 세룰리온 배지에 상점 10% 할인과 신규 유물 아이콘을 적용했습니다.
- 보유 시 카드·유물·포션 구매와 카드 제거 비용이 할인되며 판매 대금은 변하지 않습니다.
- 임시 규칙으로 할인액의 소수점은 버립니다. 배지 구매에는 획득 전 가격을 적용합니다.
- 배지 구매·보물 획득·판매와 저장 복원을 지원합니다.
- 유물 시트의 설명과 기획서 임시 결정 탭에 할인 범위와 계산 규칙을 기록했습니다.
- `DiscountedShop.png`는 확인을 위해 시험 골드를 지급하고 배지를 구매한 뒤 촬영한 상점 화면입니다.
- 검증: Unity EditMode 전체 검사 333개 통과, 이후 판매 완료 표시와 할인 거래 추가 검사.
