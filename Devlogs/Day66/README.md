# 66일차 개발일지

---
## 작업 내용

- 내장 이미지 생성 도구로 세룰리온 거점의 다크 판타지풍 배경을 제작했다.
- 배경을 Unity Resources 텍스처로 가져와 거점 캔버스의 가장 뒤에 배치했다.
- 배경 이미지가 캐릭터 선택 등 UI 입력을 가로막지 않도록 처리했다.

---
## 이미지 생성 기준

- 산업 설비와 타로 문양이 어우러진 어두운 지휘실, 청록색 조명, 2D 판타지 게임 일러스트.
- 중앙 UI 가독성을 위한 낮은 대비, 글자·로고·인물 제외.
- 파일: `Assets/_ProjectC/Resources/UI/LobbyBackground.png`.

---
## 검증

- 배경 텍스처 로딩, 전체 화면 배치, 입력 통과 여부를 테스트했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 61개 통과.
- Play Mode의 실제 화면 비율과 시각적 배치는 아직 확인하지 않았다.
