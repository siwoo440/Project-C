# 281일차 펜타클 카드 확장 · 현자의 룬부터 완성된 의식까지

시트 250~252행의 펜타클 전설 카드 세 장에 제공 원화, 전투 효과, 보물 보상, 카드 소유자와 회차 저장을 연결한다.

| 카드 | 비용 | 효과 |
| --- | ---: | --- |
| 현자의 룬 | 5 | 행동력 2를 얻으며, 이번 아군 턴에 아군이 사용하는 카드의 적용 수치를 50% 높인다. 같은 강화는 중첩되지 않는다. |
| 시간의 동전 | 4 | 현재 아군 턴이 끝나면 적 행동 전에 추가 아군 턴이 시작된다. 추가 턴의 최대 및 현재 행동력이 2 줄고, 실제 적 턴이 끝난 뒤에 다시 시전할 수 있다. |
| 완성된 의식 | 6 | 기존 손패 상한 안에서 공용 카드 3장을 뽑고 행동력 3을 얻는다. 생존 적의 공격력을 각각 2 적 턴 동안 1 낮춘다. |

현자의 룬은 피해·회복·방어도 등 카드가 직접 적용하는 수치를 0.5부터 올림해 정수로 반올림한다. 비용, 확률, 지속시간과 독립 유물 발동은 각자의 원래 수치를 사용한다. 시간의 동전으로 시작한 추가 턴에는 일반 아군 턴의 손패와 상태 이상 처리가 적용되며, 적은 해당 턴 구간에 행동하지 않는다.
