# 285일차 유물 확장 · 원자로 심장편부터 용암 이끼 포자병까지

유물 시트 261~268행의 원본에 실제 원화와 전투 효과를 연결한다. 기존 상점 가격 범위와 회차 저장 식별자를 사용한다.

| 유물 | 효과 |
| --- | --- |
| 원자로 심장편 | 화상 또는 감전이 활성인 적에게 아군 카드가 직접 주는 피해를 15% 높인다. 두 상태가 함께 있어도 한 번 적용된다. |
| 격납고 봉인장치 | 보스전에서 적이 실제로 두 턴을 마치기 전까지 아군이 받는 적 전투 피해를 20% 줄인다. |
| 폐기장 왕관 | 적이 실제로 쓰러질 때 무작위 생존 아군 한 명이 방어도 6을 얻는다. |
| 마지막 안전등 | 전투당 한 번, 생존 아군의 정신력이 실제로 0에 도달하면 정신력 10을 회복한다. |
| 그을린 돌끈 | 아군이 화상으로 받는 실제 피해를 1 줄인다. 최소 피해는 0이다. |
| 검은 현무암 조각 | 전투당 한 번, 아군이 받는 첫 양수 직접 적 타격의 피해를 방어도 적용 전에 3 줄인다. |
| 재 묻은 장갑 | 화상 상태인 적에게 검 카드가 직접 명중하면 방어 전 피해를 2 높인다. |
| 용암 이끼 포자병 | 아군의 실제 턴이 세 번 시작될 때마다 현재 체력이 가장 낮은 부상 아군 한 명의 체력을 4 회복한다. |

선제 적 턴도 격납고의 두 적 턴에 포함된다. 시간의 동전으로 아군 턴을 한 번 더 진행하면 포자병의 아군 턴 횟수에는 포함되고 격납고의 적 턴 횟수는 유지된다. 피격 예고는 현무암의 실제 사용 기회를 소비하지 않는다.

---

## 검증 결과

Unity EditMode 38건 통과, 실패와 건너뜀 0건. 중복 유물 진열과 구매 확인을 포함한 상점 검사 2건을 모두 실행했다.

실제 Windows 보스전에서 기본 피해 20의 첫 타격은 예고와 실제 피해가 모두 13이었다. 두 번째 타격은 16이었다. 마지막 안전등은 정신력이 처음 0에 도달할 때 10을 회복했고 두 번째에는 발동하지 않았다. 유물 8종의 저장 복원을 확인했다.
