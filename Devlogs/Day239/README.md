# 239일차 방패 카드 확장 · 보호막 분배부터 위험 차단까지

원본 시트 70~78행 중 신규 방패 카드 8종과 원본 PNG를 연결한다. 72행 철벽은 기존 카드다.

| 카드 | 기본 AP | 전투 효과 |
| --- | ---: | --- |
| 보호막 분배 | 1 | 생존 아군 두 명을 차례로 선택해 각자 방어도 4를 준다. 두 번째 선택 후에 행동력을 한 번 사용한다. |
| 균형 잡기 | 0 | 자신에게 방어도 3을 주고, 소유자가 다음에 사용할 유료 방패 카드의 기본 비용을 1 낮춘다. |
| 도발 | 2 | 다음 적 턴의 단일 공격에서 시전자가 우선 대상이 되며 물리 방어력이 4 증가한다. |
| 방패 반격 | 2 | 다음 적 턴에 살아 있는 시전자의 방어도가 직접 공격을 흡수할 때마다 공격자에게 고정 피해 8을 준다. |
| 수호의 원 | 2 | 생존 아군 전체의 직접 적 공격 피해를 두 적 턴 동안 10% 줄인다. |
| 방어 전진 | 2 | 선택한 적에게 물리 피해 8을 주고, 카드 소유자가 방어도 10을 얻는다. |
| 파열 방패 | 2 | 현재 방어도의 절반을 내린 값을 기본 물리 피해로 쓴다. 시전자의 방어도는 보존한다. |
| 위험 차단 | 2 | 지정한 아군에게 들어오는 다음 양수 직접 공격의 피해를 방어도 흡수 전에 70% 줄인다. |

도발의 우선 대상에는 단일 적 공격만 적용한다. 몸으로 막기가 이미 예약됐다면 해당 보호 규칙이 실제 타격을 이어받을 수 있다.

| 상태 | 그림의 주제 |

| [수호의 원](../../Assets/_ProjectC/Resources/UI/Battle/GuardianCircleStatusIcon.png) | 녹색 원형 결계로 이어진 방패 세 개 |

## 검증 및 실제 화면

- Unity EditMode 통합 검사 74건 통과. 실패 0건, 건너뜀 0건. 카드 원화·보상·소유자 복원과 상점 회귀 검사를 포함한다.
- Windows Direct3D 11 플레이어에서 두 아군에게 방어도 4를 각각 지급하는 보호막 분배와 균형 잡기의 다음 방패 비용 할인, 도발 대상, 위험 차단 70%를 확인했다.
- 파열 방패의 동적 표시가 보유 방어도 7에서 물리 피해 3으로 바뀌는 것을 확인했다.
