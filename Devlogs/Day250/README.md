# 250일차 유물 확장 · 조용한 종끈부터 무딘 칼 장식까지

유물 시트 114~121행의 원화와 효과를 실제 획득, 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 조용한 종끈 | 아군에게 걸릴 공포를 30% 확률로 막는다. 기존 상태 면역을 먼저 적용한다. |
| 반쯤 탄 부적 | 아군이 턴 종료에 받는 화상 피해를 방어도 적용 전에 1 줄인다. |
| 균열 가루병 | 아군이 자신의 턴에 적을 처치할 때 20% 확률로 현재 행동력이 1 회복된다. 기존 행동력 상한을 적용한다. |
| 빛 잃은 목걸이 | 피해 직전 체력이 최대값의 30% 이하인 아군이 받는 피해를 비율 경감 뒤 2 줄인다. 분담 피해에도 적용한다. |
| 작은 고해패 | 정신력 50 이하인 시전자의 직접 회복 카드의 체력 회복량을 2 높인다. |
| 검은 먼지병 | 전투에서 활성 약화가 있는 적에게 처음 카드로 직접 명중했을 때 피해를 3 높인다. |
| 헐거운 탄띠 | 실제 첫 아군 턴 동안 최대 행동력과 현재 행동력을 각각 1 높인다. |
| 무딘 칼 장식 | 처음 사용한 검 피해 카드의 첫 명중에 피해 3을 더한다. 첫 카드의 타격이 전부 빗나가면 그 전투의 기회를 소모한다. |

시트의 코스트 증가는 공용 행동력 회복 또는 첫 턴 행동력 증가로 구체화했다. 검은 먼지병은 방어도에 전부 막힌 명중에도 발동하며, 발생한 고정 감소는 체력 비용과 구분한다.

## 검증과 실제 화면

Unity EditMode 검사 37건이 통과했다. 상점 진열과 구매 확인 검사 2건이 포함됐으며 실패와 건너뜀은 각각 0건이다. Windows 독립 실행 플레이어에서 1600×900으로 촬영했다.

- `LateWinterRelics.png`에서 여덟 유물의 획득과 중복 획득 정산 및 저장 복원 뒤 보유 목록을 확인했다.
- `DulledBladeFirstHit.png`에서 무딘 칼 장식이 적용된 첫 찌르기 원본 피해 10과 적 체력 50→41을 확인했다.
- `DulledBladeSecondHit.png`에서 같은 적과 카드로 후속 찌르기 원본 피해 7과 적 체력 41→35를 확인했다.
