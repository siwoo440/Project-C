# 254일차 유물 확장 · 네크레이트 실금석부터 균열 봉합실까지

유물 시트 130~137행을 원화, 전투, 획득, 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 네크레이트 실금석 | 전투 시작에 생존 적 전체의 마법 피해 저항을 5%p 낮춘다. 적 턴을 두 번 마치면 끝난다. |
| 보랏빛 맥동핵 | 아군이 적에게 침식 계열로 명시한 약화를 적용할 때 일반 피해 3을 준다. |
| 어비스 먼지시계 | 실제 아군 턴이 세 번 시작될 때마다 생존 적 전체의 정신력을 3 낮춘다. |
| 검은 균열침 | 활성 약화가 있는 적에게 카드가 직접 명중할 때 치명타 확률을 10%p 높인다. |
| 공허에 닿은 렌즈 | 아군 카드의 확률형 실명 판정이 있을 때 확률을 15%p 높인다. |
| 침식된 맥박줄 | 전투 시작에 무작위 생존 아군 한 명의 정신력을 3 낮추고, 실제 첫 두 아군 턴 동안 공격력을 2 높인다. |
| 보라색 결정눈 | 아군 카드의 표식이 적에게 적용되면 적 턴 두 번 동안 별도 물리 방어 약화 1을 부여한다. |
| 균열 봉합실 | 침식 피해로 실제 체력을 잃었던 아군이 전투 종료 시점에 생존하면 체력 6을 회복한다. |

침식 약화와 확률형 실명은 해당 효과가 있는 카드 원본에서 명시한다. 현재 원본 카드와 적의 분류를 유지했다. 균열 봉합실은 결과에 저장할 체력을 기록하기 전 체력 회복을 한 번 적용한다.

## 실제 검증

Unity 검사 31건이 통과했다. 상점 검사 2건을 포함하며 실패와 건너뜀은 각각 0건이다. Windows Direct3D 11 실행판에서 유물 8종의 획득 순서와 저장·복원을 확인했다. 첫 전투에서 실금석은 적 마법 저항을 5%p 낮추고 두 적 턴 동안 유지됐으며, 맥박줄은 한 아군의 공격력을 2 높이고 정신력을 3 낮췄다. 균열 봉합실의 전투 종료 회복은 Unity 검사에서 확인했다.

## 보유 유물 조회 시간

Windows 실행판의 Mono 런타임에서 각 경로를 표본당 20,000번씩, 7개 표본으로 측정했다. 표의 값은 호출당 중앙값이며 단위는 ns다. 보유 유물 141개는 이 시점 저장 카탈로그에서 유물 ID가 유효한 전체 원본 수다.

| 보유 수 | 없는 효과 조회 | 최초 항목 조회 | 전투 시작 후보 탐색 | 카드 사용 후보 탐색 | 공격 명중 후보 탐색 | 상태 적용 후보 탐색 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 30.4 | — | 47.2 | 45.5 | 47.6 | 47.0 |
| 16 | 195.0 | 39.0 | 202.3 | 207.2 | 209.2 | 213.8 |
| 64 | 693.1 | 41.2 | 600.5 | 590.6 | 563.7 | 556.4 |
| 141 | 1406.6 | 39.0 | 1121.8 | 1080.9 | 1172.0 | 1099.6 |

141개 보유 시 마지막 항목의 효과 조회는 1405.9ns였다. 네 발동 경로는 전투 발동기와 같은 획득 순서 복사 및 후보 조건 탐색을 측정했다. 모든 경로에서 측정된 호출당 관리 힙 할당은 0.0바이트였다.
