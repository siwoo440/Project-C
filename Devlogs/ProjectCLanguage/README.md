# 한국어·영어 전환

설정의 ‘언어 → 언어 선택’에서 한국어와 영어를 전환할 수 있습니다. 새 설치의 기본값은 한국어입니다. 선택은 PC에 저장되며 다음 실행에도 적용됩니다.

영어 모드에서는 메뉴, 설정, 탐사, 전투와 카드·유물·이벤트 등의 화면 표시 문구를 내장 번역표로 표시합니다. 숫자와 서식 표시를 포함한 2,869개 항목의 형식을 비교했습니다. 카드, 캐릭터, 조우 식별자를 사용하는 저장 구조를 보존했습니다.
