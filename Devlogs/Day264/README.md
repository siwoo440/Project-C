# 264일차 유물 확장

커튼 고정핀부터 잠긴 서랍 열쇠까지 윈터폴 유물 8종을 추가했습니다. 은신 중 직접 피해와 회피, 강화 대상 회복, 보물방의 추가 골드, 첫 전투 손패 효과를 기존 유물 적용 경로에 연결했습니다.

## 검증

- Unity EditMode 32건 통과. 상점 진열과 구매 확인 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows 독립 실행에서 새 유물 8종의 저장과 불러오기를 확인했습니다.
- 실제 전투 첫 손패에서 기존 찌르기와 함께 행동력 0 임시 찌르기가 한 장 생기고, 사용 후에도 행동력과 탐사 덱의 카드 수가 유지되는 것을 확인했습니다.
