# 97일차 개발일지

---
## 작업 내용

- 교황의 조건부 방어 카드에 사용할 `방어 준비` 상태를 추가했다.
- 아군이 적의 물리·마법 공격을 처음 받을 때 해당 공격에만 임시 방어력을 적용한다.
- 사용하지 않은 준비는 적 턴 종료 시 사라지며 환경 피해에는 소모되지 않는다.
- 여러 적이 같은 아군을 공격하면 첫 공격의 피해 예고에만 준비 효과를 반영한다.

---
## 검증

- 기능 구현 전 테스트 실패와 구현 후 성공을 확인했다.
- 첫 공격 피해와 예고 일치, 두 번째 공격 미적용, 적 턴 종료 만료를 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 108개 통과.

---
## 남은 작업

- 교황 전용 카드와 패시브에 아직 연결되지 않아 게임에서 직접 사용할 수 없다.
- 기획서의 별도 방어도는 현재 임시 방어력으로 대체했다.
