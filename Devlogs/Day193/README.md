# 193일차 카드·유물 획득과 저장 점검

강타·검풍·정화는 상점과 보물에서, 작은 치유·불덩이·마력탄은 보물에서 파티원을 선택해 얻는다. 유물은 시트에 있는 10종과 초기 시험용 2종이 두 경로에 등록돼 있다.

| 대상 | 보물에서 획득 | 일반 파티의 상점에서 구매 |
| --- | --- | --- |
| 강타, 검풍, 정화 | 3종 | 3종 |
| 작은 치유, 불덩이, 마력탄 | 3종 | 보상 전용 |
| 잿빛 인장, 깨진 멜로디 박스, 청동 향로, 부유석 조각, 봉쇄문 인증키, 균열의 렌즈, 봉인된 봉투, 흐린 룬 조각, 검은 손수건, 세룰리온 배지 | 10종 | 10종 |
| 회복 유물, 최대 체력 유물 | 2종 | 2종 |

---
## 고정 소유자 상품

기존 공격·마법 공격·자가 회복 상품 3종은 출전 명단 22명에 없는 시험 캐릭터 `CHR_TEST` 전용이다. 일반 파티에서는 살 수 없는 카드가 상품 목록에 보였고, 보물에서 뽑으면 지급에 실패해 다른 종류의 보상으로 넘어갔다. 상점 목록과 보물 후보를 만들 때 현재 덱에서 해당 소유자를 확인한다. 시험 캐릭터가 포함된 덱은 세 상품을 계속 사용한다.

---
## 보물 재추첨

보물에서 미보유 유물을 찾는 동안 이미 가진 유물이 후보로 뽑히면, 버린 후보마다 중복 유물 보상 50골드가 지급됐다. 보물 방은 보유 여부를 먼저 확인한 뒤 신규 유물만 지급한다. 유물을 모두 모은 상태에서는 대체 보상을 추첨할 때 골드가 그대로인지 검사한다.

---
## 검증 범위

- 카드 시트 251행·유물 시트 298행과 프로젝트 원본을 표시 이름으로 대조했다. 이름이 일치하는 카드 원본은 6종, 유물 원본은 10종이다. 프로젝트의 식별자 있는 카드 원본 64종과 유물 원본 12종은 모두 저장 카탈로그에 등록돼 있다.
- 통합 검사에서 일반 파티의 상점 구매와 보물 획득을 각각 수행한다. 구매 때마다 골드 차감을 검사하고, 보물 카드 6종은 구매 카드와 다른 파티원에게 지급한다.
- 구매 직후와 보물 획득 후에 각각 독립 파일에 저장한다. 메모리의 파티·덱·유물·골드·상점·탐사 상태를 지우고 파일을 읽어 카드 순서와 소유자, 유물 획득 순서, 판매 완료 상품, 잔액, 사용한 보물 방을 대조한다.
- Unity 6000.3.21f1에서 획득·거래·저장과 관련된 검사 21개가 모두 통과했다. 일반 파티에서 시험 카드가 보이던 현상은 수정 전 실패와 수정 후 통과를 각각 확인했다.
