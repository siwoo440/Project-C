# 86일차 개발일지

---
## 작업 내용

- 마법사 캐릭터의 카드 재활용에 사용할 버린 카드 회수 기능을 추가했다.
- 선택한 카드 인스턴스를 그대로 손패로 옮겨 소유자와 강화 상태를 유지한다.
- 손패가 가득 찼거나 버린 더미에 없는 카드는 회수하지 않는다.

---
## 검증

- 기능 구현 전 테스트 실패와 구현 후 성공을 확인했다.
- 소유자 유지, 중복 회수 차단, 손패 상한과 전체 카드 보존을 검증했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 100개 통과.

---
## 남은 작업

- 회수할 카드 선택 화면과 마법사 전용 카드, 패시브 연결 전이므로 게임에서 직접 사용할 수 없다.
