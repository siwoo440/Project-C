## 검증 기준

카드는 원화, 코스트, 대상과 효과, 보상에서 소유자 선택, 저장 후 덱 복원을 확인한다. 유물은 보유 전후 효과, 발동 횟수, 획득·판매·저장 복원을 확인한다. 282일차에 배정한 방패 카드 3종은 원본의 빈 비용·효과·대상을 확정한 뒤 등록한다.

원본 카탈로그는 최초 접근 시 한 번 파싱하고 이름 색인을 재사용한다. 원본 행 순서는 보존한다. 도감은 보이는 셀과 원화부터 로딩하고, 전투는 현재 보유 유물과 해당 행동의 발동 조건만 검사하는 방향으로 확장한다. 마지막 통합 검증에서 첫 로드와 재조회, 이미지 메모리, 도감 스크롤의 프레임 시간을 각각 측정한다.

## 에디터 실측

Unity 에디터에서 각 시트의 모든 이름을 64회 조회했다. 카드 16,064건은 순차 검색 12.147ms, 색인 조회 0.540ms였다. 유물 19,072건은 12.418ms와 0.598ms였다. 같은 자료를 64번 다시 읽고 파싱하는 데 카드 39.907ms·유물 34.342ms가 걸렸고, 최초 로딩 후 캐시 접근은 각각 0.001ms·0.002ms였다. 이 측정은 데이터 조회 구간만 포함한다. 카드·카탈로그·방어도·획득 및 복원 관련 검사 20건이 통과했다.
