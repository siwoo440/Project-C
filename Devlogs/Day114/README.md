# 114일차 로비 화면 재배치와 경고 버튼 확대

---
## 작업 내용

- 참고 배치에 맞춰 오른쪽 메뉴, 상단 골드·설정, 하단 도감·물자·설비 강화 배치
- 기존 자동 파티 편성 화면과 거점 개발용 정산 패널 제거
- 실제 골드와 물자 변경 내용을 로비에 즉시 반영
- 기존 설비 강화와 설정 화면 연결, 테스트 자원 지급 버튼 제거
- 새로하기와 저장 확인창의 버튼을 가로·세로 1.5배 확대
- 기존 탐사·전투 테스트를 삭제된 화면 대신 파티 데이터 준비 방식으로 전환
- Unity EditMode 전체 테스트 159개 통과
- 실제 실행 화면 캡처: `Warning.png`, `Lobby.png`

---
## 이어지는 작업

- 탐사 버튼의 맵 선택과 새 편성 화면 연결은 115~116일차에 진행
- 아직 연결되지 않은 로비 메뉴는 입력을 비활성화해 미구현 기능을 구분
- 씬 전환 로딩 화면은 117일차에 진행
