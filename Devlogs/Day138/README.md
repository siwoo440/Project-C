# 138일차: 절제·악마 임시 전용 카드 구현

- 절제의 `균형 처치`는 선택한 아군의 디버프를 모두 제거하고 이로운 효과는 유지한다.
- 악마의 `달콤한 거래`는 자신의 체력 5를 소모해 적에게 기본 물리 피해 20을 준다.
- 체력이 5 이하이면 사용을 막으며, 체력 소모는 피격과 별도로 처리해 방어도에 흡수되지 않는다.
- 체력 회복이나 소모 시 손패의 카드 사용 가능 상태를 즉시 갱신한다.
- 두 캐릭터의 패시브와 정상·각성·붕괴별 세부 효과는 기획 미정으로 남겨 둔다.
- `BloodPrice.png`는 실제 탐사 조우 전투에서 악마의 전용 카드를 사용해 촬영한 화면이다.
- 실제 카드 사용·기존 캐릭터 능력 관련 검사 12개와 전용 카드 저장·복원 등 추가 검사 4개가 통과했다.
- Unity 전체 EditMode 회귀 검사 235개가 통과했다.
