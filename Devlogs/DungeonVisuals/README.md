# 지하 던전과 전투 화면 개선

---

## 탐사

바닥과 벽에 각 네 가지 석재 변형을 추가했다. 층 시드와 타일 좌표에 따라 재질을 섞고, 바닥과 맞닿은 방향에 맞춰 돌 테두리가 직선과 모서리에서 이어진다. 벽등, 격자, 사슬, 석재 조각, 뿌리, 부서진 격자가 맵 곳곳에 표시된다. 장식과 테두리는 충돌을 추가하지 않는다.

Windows 실행판의 첫 확대 화면에서 기존 바닥의 검은 외곽선이 눈에 띄어, 기본 재질을 그릴 때 검은 여백을 잘라 표시했다. 원래 이미지와 물리적 타일 크기는 그대로 보존된다.

---

## 전투

상단은 석재 바닥이 보이는 지하 금고 전장으로, 하단은 카드와 행동력이 표시되는 곳의 검은 배경으로 제작했다. 캐릭터의 발과 적의 아래쪽 원화를 기준으로 접지 그림자가 전투 동작을 따라간다. 별도 원화가 없는 대체 표시에는 그림자가 생성되지 않는다.

ImageGen으로 어두운 청록 석재 바닥과 벽, 장식, 벽면 턱, 측면에서 보이는 지하 금고, 카드 아래 검은 석재 배경을 제작했다. 탐사 원화는 Unity Tile Palette에서 개별 스프라이트로 선택할 수 있다.

---

## Windows 실행 확인

- Unity 검사 13건 통과, 실패 0건, 건너뜀 0건. 상점 검사 2건 포함.
- 인접 벽의 가로·세로 배치 2,048가지에서 맞닿는 원화 픽셀의 불일치가 없었다. 실제 탐사 화면에서는 바닥 5종, 벽 재질 5종, 연결 벽 모양 12종, 장식 6종을 사용했다. 네 타일 레이어는 실제 저장 복원 뒤 같은 자리에 같은 원화로 표시됐다.
- 1600×900과 1280×800에서 위아래 배경을 확인했다. 실제 공격 전진과 복귀 때 발밑 그림자가 원화를 따라갔고, 전투 중 소환된 적에게도 그림자가 적용됐다.
