# 마이너 카드 선택창

레벨업 선택창에 금속 테두리와 카드 세 장을 배치했습니다. 이름, 원화, 설명, 대상과 효과 수치가 각각 독립된 영역에 표시됩니다. 카드에 원화가 없는 경우 효과 종류에 맞는 기존 전투 아이콘을 표시합니다.

---

## 검증

- Unity 검사 4건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows에서 레벨 2에 도달해 선택창을 열고 1600×900과 1280×800에서 글자가 그래픽이나 다른 영역과 겹치지 않는 것을 확인했습니다.
- 실제 마우스로 갑옷 균열을 골랐을 때 남은 선택권이 0회가 되고 생존 적 둘에게 방어력 감소가 적용됐습니다. 화면의 적은 효과 확인용 시험 편성입니다.
