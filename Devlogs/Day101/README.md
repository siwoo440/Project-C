# 101일차: 전투용 SD 캐릭터 그림

---
## 구현 내용

- 첨부된 전투 화면을 참고해 오른쪽을 바라보는 SD 전신 그림을 제작했습니다.
- 바보부터 교황까지 ARC_00~ARC_05의 그림을 각 캐릭터에 연결했습니다.
- 전투 화면에 전용 그림을 원본 비율로 표시하고, 그림이 없는 경우 기존 초상화를 사용합니다.
- 캐릭터 선택 화면에서 사용하는 기존 초상화는 유지합니다.

---
## 검증

- 별도 Unity 프로젝트 복사본에서 EditMode 전체 테스트 122개 통과.
- 6명 각각의 이미지 연결과 전투 표시, 원본 비율 및 미설정 시 대체 표시 확인.
