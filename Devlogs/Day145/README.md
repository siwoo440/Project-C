# 145일차: 윈터폴 보스 초기 구현

- 주요 기획서의 보스 이름과 전투 방향, 임시 밸런스 시트의 기본 체력 350·공격력 18·방어력 12·저항력 12를 사용했다. 사용자의 선택에 따라 기존 보스 배율을 추가 적용하므로 1층 보스 체력은 875, 첫 행동의 방어 계산 전 공격력은 24다.
- 보스는 생존 상태에서 체력이 50% 이하가 되면 2단계로 전환한다. 이전 예고와 남은 타격을 취소하고 플레이어 턴의 공통 정리를 한 번 실행한 뒤 다음 턴의 새 예고를 준비한다.
- 일반 턴 종료에도 일반 손패와 남은 행동력을 정리한다. 유지·휘발 카드 종류는 아직 구현되지 않아 별도 처리 대상이 없다.
- 각 패턴은 대상과 피해를 예고하며, 정신력 감소 및 실명 부여 행동도 상세 예고에 표시한다. 실명 공격이 빗나가면 피해와 추가 효과를 적용하지 않는다.
- 예전 저장은 원래 조우 목록을 유지한다. 144일차 조우 버전의 임시 보스도 그대로 유지하고 새 탐사에만 새 보스를 배치한다.
- [실제 보스 전투 화면](AshstormCore.png)에서 보스 이미지와 전투 화면 연결을 확인했다.
- Unity 전체 EditMode 테스트 264개와 추가 집중 테스트 7개가 통과했다. 실제 보스 전투와 승리 결과, 연속 공격 취소, 기존 조우 버전 재저장을 확인했다.

---
## 개발 임시 패턴

- 1단계 `재 균열`: 물리 기본 피해 18, 적중 시 정신력 -4. `잿빛 장막`: 물리 기본 피해 18, 적중 시 정신력 -2와 실명 1턴.
- 2단계 `폭풍 심화`: 물리 기본 피해 22, 적중 시 정신력 -6과 실명 2턴. `심핵 맥동`: 마법 기본 피해 20, 적중 시 정신력 -8.
- 실명은 해당 공격이 적중하면 확정 적용하며 공격 명중률을 25%p 낮춘다. 대상은 무작위 생존 아군, 행동 속도는 임시 시트의 7~12다. 피해에는 기존 층·보스 배율이 적용된다.
- 위 수치와 단계 기준은 개발 중 정한 값으로, 확정 기획이 아니다. 기획서의 사용자 확인 임시 규칙 탭에도 별도 표시했다.

## 남은 작업

- 보스 패턴과 단계 조건의 최종 기획·난이도 조정, 유지·휘발 카드 처리, 보스 전용 연출과 사운드는 후속 작업이다.
- 구역 탐사 수치에 따른 보스 예약과 지역 레벨 흐름은 별도로 기획과 실제 동작을 대조해야 한다.
