# 258일차 유물 확장 · 네크레이트 손톱가루부터 어둠에 잠긴 팔찌까지

유물 시트 146~153행의 신규 원화, 효과, 획득, 상점 및 회차 저장 연결을 적용한다.

| 유물 | 효과 |
| --- | --- |
| 네크레이트 손톱가루 | 중독 상태인 적에게 검 카드가 직접 명중하면 피해가 3 증가한다. |
| 바닥 없는 병 | 전투 시작에 생존 아군 전체의 정신력을 4 낮춘다. 실제 첫 아군 턴 동안 현재와 최대 행동력을 각각 2 높인다. |
| 검은 심연판 | 전투에서 생존 아군 중 처음으로 실제 정신 피해를 받을 대상의 피해를 1회 무효로 한다. |
| 뒤집힌 별문장 | 같은 아군 턴에 서로 다른 속성의 카드 세 종류를 사용하면 카드 한 장을 뽑는다. 한 턴에 한 번 적용한다. |
| 균열 먹는 새장 | 적 턴 시작에 서로 다른 활성 약화가 세 개 이상인 생존 적에게 각각 일반 피해 5를 준다. |
| 어비스 공명석 | 전투에서 지팡이 카드 세 번을 사용할 때마다 정산 후 생존 적 전체에 일반 피해 6을 준다. |
| 네크레이트 봉인핵 | 생존 아군에게 제거 가능한 약화가 적용될 때 20% 확률로 그 약화를 해제한다. |
| 어둠에 잠긴 팔찌 | 은신이 해제된 아군의 다음 직접 카드 명중 피해를 8 높인다. |

검은 심연판은 피해나 적 약화에 따른 실제 정신 피해에 발동한다. 바닥 없는 병의 시작 정신 비용이나 카드의 자발적 지불은 심연판을 소모하지 않는다. 별문장의 속성은 게임 시트에 있는 검·방패·성배·지팡이·펜타클이다. 팔찌의 피해 증가 기회는 실제 직접 명중에서 소모하며, 전투 종료 및 전투불능 정리에서 발동하지 않는다.

## 검증

- Unity 검사 38건 전부 통과. 실패와 건너뜀 각 0건. 상점 실동작 검사 2건 포함.
- Windows Direct3D 11 실행에서 유물 8종의 저장과 복원을 확인했다. 바닥 없는 병은 첫 아군 턴의 행동력을 6에서 8로 높였고, 생존 아군 네 명의 정신력을 50에서 46으로 낮췄다. 검은 심연판의 첫 피해 무효 효과는 병의 비용에서 소모되지 않았다.
