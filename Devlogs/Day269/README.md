# 269일차 펜타클 카드 확장 · 황금 동전부터 계약까지

카드 시트 200~207행의 원화와 효과를 보물 획득, 소유자 선택, 도감, 실제 전투와 회차 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 황금 동전 | 현재 행동력 1을 회복한다. |
| 집중 | 아군 공용 손패에 카드 한 장을 즉시 뽑는다. |
| 전술 교환 | 손패의 다른 카드 두 장을 골라 버리고 카드 두 장을 뽑는다. |
| 강화 주문 | 고른 손패 카드의 다음 실제 사용에서 기본 효과 수치를 50% 높인다. |
| 효율적 사용 | 이번 아군 턴 동안 모든 아군 카드의 기본 행동력 비용이 1 감소한다. 개별 필수 비용과 X 비용은 유지한다. |
| 고대의 룬 | 아군 공용 손패에 카드 두 장을 즉시 뽑는다. |
| 운명의 바퀴 | 현재 행동력 X와 같은 수의 다른 손패 카드를 고른 뒤, 실제 행동력 X를 지불하고 그 카드들을 이번 전투에서 제외한다. 생존 아군 전원은 X마다 체력 3을 회복한다. |
| 계약 | 사용자 체력이 10을 초과할 때 체력 10을 지불하고 현재 행동력 3을 회복한다. |

232일차 저장 구조의 실제 필드를 사용한 입력에서 기존 카드·유물 식별자와 소유자를 복원한다. 확장된 전체 저장 카탈로그의 원본, 순서 및 소유자도 같은 저장 서비스로 왕복 검증한다.

---

## 검증

- Unity 검사 34건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건이다.
- 실제 Windows 전투에서 선택을 시작한 뒤 행동력 2가 유지됐다. 두 카드를 확정하면 고른 두 장만 전투에서 제외되고 행동력 2가 소모됐으며, 체력이 부족한 생존 아군의 체력이 6 회복됐다. 화면의 적은 시험 편성이다.
- 공용 선택창의 둘째 페이지에 세 번째 후보가 표시되며 부분 선택 취소 시 비용이 발생하지 않는 것을 확인했다.
