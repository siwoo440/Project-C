# 64일차 개발일지

---
## 작업 내용

- 거점에 아르카나 22명의 이름과 출전 상태를 표시하는 편성 화면을 추가했다.
- 출전 가능한 캐릭터를 최대 4명 선택하고 다시 선택해 해제할 수 있다.
- 사망·회복 상태에 따라 선택 가능 여부와 남은 회복 횟수를 표시한다.
- 세계는 첫 회차 클리어 해금 기능이 연결되기 전까지 선택 불가로 표시한다.

---
## 검증

- 22개 버튼 생성과 캐릭터 선택·해제, 세계 선택 제한을 테스트했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 58개 통과.

---
## 남은 작업

- 선택한 파티를 실제 덱과 탐사 출발 흐름에 연결해야 한다.
- 세계의 클리어 후 해금, 캐릭터 전용 효과, Play Mode 화면 검증이 남아 있다.
