# 149일차: 탐사·거점 튜토리얼과 안내 화면 개선

- 실제 로비에서 캐릭터, 구역 선택 후 편성, 치료·부활 대기, 설비와 탐사 출발을 안내한다. 로비 물음표 버튼으로 안내를 다시 볼 수 있다.
- 탐사에서는 실제 이동을 확인한 뒤 접촉 방식의 전투·이벤트·특수 방과 방 종류를 안내한다. 맵 초기 자동 배치를 직접 이동으로 잘못 인식하지 않는다.
- 두 안내는 기존 튜토리얼/힌트 설정과 별도의 기기별 완료 기록, 건너뛰기와 다시 보기를 지원한다.
- 전투·거점·탐사 안내 화면을 어두운 배경과 왼쪽 예시 이미지, 오른쪽 제목·설명·확인 버튼의 구성으로 변경했다. 이미지와 배경은 게임 입력을 차단하지 않는다.
- 전투·거점·편성·설비 예시는 실제 게임 화면을 사용한다. 탐사 맵 예시는 촬영된 화면에 맵이 보이지 않아 기존의 이미지 누락 표시를 임시로 사용한다.
- [전투 안내 화면](TutorialBattle.png)과 [거점 안내 화면](TutorialLobby.png)을 실제 게임 씬에서 촬영했다. 실제 씬에서 거점 도움말과 탐사 이동을 검사했다.
- Unity 전체 EditMode 검사 299개가 통과했다.

## 후속 작업

- 기획서의 F키 상호작용과 현재 접촉 방식의 차이를 해결한다. 실제 조작이 바뀌면 안내 문구와 예시를 함께 수정한다.
- 실제 탐사 맵이 포함된 예시 이미지, 이벤트·보물·휴식·상점의 개별 안내와 후속 튜토리얼 화면을 보완한다.
- 치료·부활의 예외 조건, 긴급 대기, 구역 진행도와 기기·슬롯별 안내 저장 정책은 추가 안내 및 검증이 필요하다.
