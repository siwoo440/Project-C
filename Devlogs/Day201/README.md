# 201일차 윈터폴 재폭풍의 눈 이벤트

윈터폴 이벤트 방에서 재가 원형으로 말려 올라간 자리에 검은 유리처럼 생긴 눈이 나타난다. 플레이어는 행동을 고른 뒤 그 행동을 수행할 생존 파티원 한 명을 지정한다. [기획서 5.2.9 재폭풍의 눈](https://docs.google.com/document/d/1IfctBvi7AwvcTYr1pMGpoq9Ly1B2lvQRlDHUNiM1BGE/edit?tab=t.wi4rzj33f2lg)

## 세 가지 선택

| 선택 | 행동자에게 일어나는 일 | 보상 |
| --- | --- | --- |
| 응시한다 | 정신력이 8 감소한다. | 희귀 공용 카드 한 장을 받는다. 카드를 받을 파티원은 응시자와 별도로 고른다. |
| 돌로 깨뜨린다 | 체력이 7 감소한다. 체력이 0에 이르면 사망한다. | 철판과 나사를 한 개씩 받는다. |
| 눈을 피한다 | 정신력이 1 회복된다. 최대치는 100이다. | 추가 물품은 없다. |

희귀도는 카드 기획 시트에서 읽고, 실제 공용 카드 상품과 저장 가능한 원본이 모두 있는 카드만 추첨한다. 201일차의 해당 카드는 성배 카드 ‘회복의 물결’이다. 행동자나 소유자 선택을 취소하거나 카드 지급에 실패하면 정신력, 덱, 이벤트가 선택 전 상태를 유지한다.

마지막 생존자가 쓰러지면 기존 환경 피해와 같은 전멸 정산을 거친다. 이번 탐사에서 얻은 잔여 재화가 회수되고 사망한 파티원의 회복 대기가 거점 저장에 반영된다. 생존했다면 행동자의 수치와 획득 자원·카드 소유자·방 처리 상태를 탐사 저장에 함께 기록한다.

## 이전 저장과 회귀 검사

이전 저장에서 복원한 층은 기존 세 이벤트의 후보와 정렬 순서를 유지한다. 같은 층을 다시 저장해도 이벤트 배치와 이미 해결한 방 식별자가 유지된다. 다음 층으로 내려가면 ‘재폭풍의 눈’이 새 후보에 들어간다.

검사에는 원본 삽화와 희귀 카드 등록, 행동자·소유자 지정, 선택 취소, 보상 지급 실패, 선택 전후 불러오기, 중복 수령 방지, 마지막 생존자 사망 후 거점 복원이 포함된다. [이벤트 처리 코드](../../Assets/_ProjectC/Scripts/Exploration/AshstormEyeEvent.cs) · [Unity 회귀 검사](../../Assets/_ProjectC/Tests/Editor/AshstormEyeEventTests.cs)

2026년 11월 19일 Unity 6000.3.21f1 검증 복제본에서 재폭풍의 눈 검사 네 개와 기존 보물 카드 소유자 검사 한 개가 모두 통과했다.
