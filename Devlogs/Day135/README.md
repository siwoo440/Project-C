# 135일차: 힘·은둔자 임시 전용 카드 구현

- 힘의 `버팀목`은 선택한 다른 아군을 향한 첫 예정 공격을 힘에게 돌린다.
- 은둔자의 `기록 대조`는 현재 덱 위에서 최대 세 장을 보여 주고 선택한 카드를 맨 위로 옮긴다.
- 한 번 보호와 세 장 확인은 사용자가 승인한 방향을 바탕으로 설정한 임시 동작이다.

- `HermitChoice.png`는 실제 탐사 조우 전투에서 전용 카드를 사용해 촬영한 화면이다.
- 관련 전투·덱 규칙 검사 19개와 실제 탐사 저장·복원을 포함한 추가 검사 6개가 통과했다.
- 저장 원본 목록을 보완한 뒤 Unity 전체 EditMode 회귀 검사 223개가 통과했다.
