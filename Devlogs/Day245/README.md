# 245일차 전설 방패 카드 확장 · 최후 방벽부터 영원의 방패까지

카드 시트 96~99행 원화와 네 카드의 효과를 연결한다. 보물에서 소유자를 정하고 회차에 저장할 수 있다.

| 카드 | 효과 |
| --- | --- |
| 최후 방벽 | 생존 아군 전원이 각각 최대 체력의 30% 이하일 때 사용한다. 생존 아군에게 각각 방어도 25를 부여한다. |
| 수호자의 심장 | 지정된 다른 생존 아군이 적의 직접 공격으로 쓰러지기 직전, 시전자가 그 공격을 한 번 대신 받고 체력 1 이상으로 생존한다. |
| 반사의 성채 | 다음 적 턴의 직접 공격으로 생존 아군이 잃은 체력을 합산한다. 그 적 턴이 끝날 때 합계의 절반을 내림하여 모든 생존 적에게 고정 물리 피해로 돌려준다. |
| 영원의 방패 | 생존 아군 전원에게 적 턴 3회 동안 직접 피해 30% 감소와 마법 피해 저항 20%를 부여한다. |

수호자의 심장 발동 시점은 치명 피해 직전으로 확정했다. 평소 방어와 피해 방지를 반영한 뒤에도 치명적인 적 직접 타격에 발동한다. 원래 대상의 체력과 방어도가 유지되고 시전자의 생존 보정은 대신 받은 그 타격에 적용된다.

반사의 성채는 실제로 감소한 체력을 합산하는 기준을 적용했다. 적 직접 타격에서 실제로 나뉜 아군 체력 피해도 해당 파티 합계에 포함한다.
