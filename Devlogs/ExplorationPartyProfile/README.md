# 탐사 파티 프로필

탐사 화면 왼쪽 아래의 네 파티 프로필에 금속 테두리를 적용했습니다. 원본 초상화와 이름 옆에 하트와 정신도 아이콘을 배치했습니다. 붉은 HP 바와 푸른 정신도 바에는 각각 현재값과 최대값을 표시합니다.

---

## 검증

- Unity 검사 6건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows에서 실제 탐사 이벤트로 네 파티원의 상태를 바꾸고 숫자와 게이지가 바로 갱신되는 것을 확인했습니다. 바보는 HP 94/94에서 77/94, 정신도 50/100에서 78/100으로 바뀌었습니다.
