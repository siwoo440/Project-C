# 257일차 지팡이 카드 확장 · 얼음 화살부터 마력 해방까지

카드 시트 151·152·153·155·156·157·158·159행의 원화, 획득, 선택 소유자와 전투 효과를 연결한다.

| 카드 | 효과 |
| --- | --- |
| 얼음 화살 | 지정 적에게 마법 피해 6을 준다. 명중하면 다음 적 턴의 행동 속도를 1 낮춘다. |
| 전격 | 서로 다른 생존 적을 최대 두 명 골라 마법 피해 7씩 준다. 적이 하나면 한 번 타격한다. |
| 마력 보호막 | 대상 아군의 마법 저항력 수치를 다음 적 턴 동안 6 높인다. |
| 빙결 | 대상 적이 다음 적 턴 동안 행동하지 못하게 한다. |
| 마력 증폭 | 생존 아군의 마법 카드 공격력을 5 높인다. 시전 턴을 포함해 아군 턴 두 번 동안 적용된다. |
| 번개 폭풍 | 생존 적 전체에게 마법 피해 8을 준다. 명중한 생존 적은 다음 적 턴 시작에 감전 피해 1을 받는다. |
| 운석 낙하 | 생존 적 전체에게 마법 피해 20을 준다. 명중한 생존 적은 다음 적 턴 동안 기절한다. |
| 마력 해방 | 남은 행동력 전체를 지불하고 지정 적에게 지불량 1당 기본 마법 피해 7을 준다. |

원본에서 감전의 피해량과 시점을 따로 정하지 않아 다음 적 턴 시작에 방어도를 건너뛰는 피해 1을 적용했다. 얼음 화살은 적의 이미 선택된 행동과 대상은 유지하면서 해당 행동의 실제 순서를 다시 정렬한다. 마력 해방의 행동력은 대상 확정 시 한 번만 결제한다.

---

## 검증

- Unity 검사 35건 전부 통과. 실패와 건너뜀 각 0건. 상점 실동작 검사 2건 포함.
- Windows Direct3D 11 에서 마력 해방의 대상 확정 전 행동력 6을 유지했다. 확정 후 한 번 결제해 행동력 0, 기본 마법 피해 42, 잿빛 방랑자의 실제 체력 50 → 14를 확인했다.
- [대상 선택](ManaReleaseChooseTarget.png)과 [타격 후 결과](ManaReleaseDamage.png)를 1600×900으로 촬영했다.
