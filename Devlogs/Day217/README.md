# 217일차 탐사 이벤트 삽화 크기와 비율 고정

불탄 수레에서 선택지가 세 개에서 결과 확인 한 개로 줄어들어도 왼쪽 삽화의 크기와 위치를 유지한다. 화면 크기에 맞춘 정사각형 틀 안에 원화를 원래 가로세로 비율로 표시한다. 남는 세로 공간은 오른쪽 결과 설명에 사용한다.

| 해상도 | 세 가지 선택 | 수레 해체 결과 | 삽화 틀 한 변 | 선택 후 네 모서리 최대 이동 |

| 1024×768 | ![4대3 화면에서 수레 행동 선택](Cart4x3Choices.png) | ![4대3 화면에서 수레 해체 결과](Cart4x3Outcome.png) | 290.54픽셀 | 0픽셀 |

Windows 플레이어에서 수레 해체를 선택하고 생존 파티원을 지정한 뒤 촬영했다. 두 해상도에서 선택·결과 화면의 삽화 내부 픽셀이 모두 일치했다. Unity 회귀 검사는 버튼이 3개에서 1개와 2개로 바뀔 때 틀과 원화 표시 영역의 크기 및 위치를 비교한다.

수정 전 같은 검사에서 틀의 경계 차이는 140이었다. 수정 후 관련 검사 27개와 전체 Unity 검사 434개가 모두 통과했다.
