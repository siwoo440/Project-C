# 246일차 유물 확장 · 녹슨 표지판부터 닳은 가죽 장갑까지

유물 시트 95·96·98·99·100·102·103·104행의 원화, 효과, 상점과 회차 저장을 연결한다.

| 유물 | 효과 |
| --- | --- |
| 녹슨 표지판 | 새 일반 층의 막다른 선택 곁방에서 재의 파수꾼의 보스 변형이 등장할 확률을 5%포인트 높인다. 배치 결과를 저장한다. |
| 순백 손수건 | 전투가 끝날 때 30% 확률로 생존 아군에게 남은 제거 가능한 디버프 중 무작위 하나를 해제한다. |
| 은빛 톱니 | 아군 턴의 기본 드로우로 카드 2장 이상이 실제로 손에 들어오면 첫 생존 아군에게 방어도 2를 부여한다. |
| 구겨진 포스터 | 전투 시작 시 생존 적에게 공포를 부여한다. 첫 아군 턴이 끝날 때 해제된다. |
| 끊어진 기도 끈 | 각 전투 시작 시 생존 아군 전원의 정신력을 각각 3 회복한다. |
| 마른 잉크병 | 스킬 카드의 사용과 선택이 끝나면 20% 확률로 카드 한 장을 뽑는다. |
| 구부러진 은못 | 표식이 있는 적을 카드로 직접 명중할 때마다 피해가 2 증가한다. |
| 닳은 가죽 장갑 | 방어도를 부여하거나 아군을 보호하는 카드의 효과를 적용하면 카드 소유자가 방어도 2를 얻는다. |

녹슨 표지판의 조우는 재의 파수꾼 변형으로 확정했다. 일반 층의 선택 곁방에 배치하는 전용 보스 조우를 추가했다. 시트에 수치가 없는 표지판의 확률 증가는 5%포인트, 순백 손수건의 정화 확률은 30%를 적용했다.

## 검증 및 실제 촬영

- Unity EditMode 33건 통과, 실패 및 건너뜀 0건. 선택 보스·정예 조우 분리, 선택 방 저장과 상점 검사 두 건을 포함한다.
- Windows 빌드 성공. Direct3D11에서 1600×900 화면 3장을 촬영했다. 실제 플레이어에서 유물 8종과 획득 순서가 회차 저장으로 복원됐다.
