# 103일차: 아군과 적군 전투 표시 확대

---
## 작업 내용

- 공용 전투 유닛의 카드 배경을 제거하고 캐릭터 표시 영역을 104×110에서 260×275로 확대했습니다.
- 이름과 체력 표시를 그림 아래로 옮기고 정신력과 상태 표시 공간을 확보했습니다.
- 양 진영에 동일하게 적용하며, 대상 선택은 캐릭터 윤곽선으로 표시합니다.
- 확대된 그림이 다른 유닛의 클릭 영역을 가리지 않도록 유닛별 입력 영역을 유지합니다.

---
## 검증

- 별도 Unity 프로젝트 복사본에서 EditMode 전체 테스트 128개 통과.
- 아군과 적군의 크기, 배경 투명도, 이름과 체력 위치 및 선택 윤곽선 확인.
- 사용자 화면에서의 실제 배치는 확인하지 않았습니다.
