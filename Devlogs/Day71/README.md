# 71일차 개발일지

---
## 작업 내용

- 내장 이미지 생성 도구로 시제품 파티의 임시 초상화 4종을 제작했다.
- 바보·여사제·황제·전차 캐릭터 데이터에 초상화 스프라이트를 연결했다.
- 기존 전투 유닛 화면에서 캐릭터 초상화를 사용한다.

---
## 이미지 생성 기준

- 기획서의 캐릭터별 외형 초안을 참조한 정사각형 판타지 게임 초상화.
- 바보는 하늘색 망토와 금발, 여사제는 흑발과 은색 달 장식.
- 황제는 남색 군복과 갑옷, 전차는 푸른 머리와 전투용 고글.
- 파일: `Assets/_ProjectC/Art/Portraits/ARC_00.png`, `ARC_02.png`, `ARC_04.png`, `ARC_07.png`.

---
## 검증

- 네 캐릭터의 스프라이트 참조와 바보의 전투 출전 시 초상화를 확인했다.
- 별도 프로젝트 복사본에서 전체 Unity 테스트 68개 통과.
- 실제 화면의 배치·잘림 여부는 시각적 확인이 남아 있다.
