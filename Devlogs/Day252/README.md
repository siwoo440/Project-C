# 252일차 유물 확장 · 낡은 성수 마개부터 녹슨 회로핀까지

유물 시트 122~129행을 신규 원화, 획득, 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 낡은 성수 마개 | 성배 카드가 처음으로 체력을 실제 회복시킬 때 그 카드의 직접 회복량을 대상마다 3 높인다. |
| 흔들리는 펜촉 | 펜타클 카드 사용 정산 뒤 손패에 빈자리가 있고 뽑을 카드가 있을 때 15% 확률로 한 장 뽑는다. |
| 꺼진 등불 심지 | 실제 은신 상태일 때 아군의 회피율을 5%p 높인다. |
| 흠집 난 주사위 | 전투 시작에 무작위 생존 아군을 골라 첫 아군 턴 공격력 1 또는 즉시 방어도 3을 준다. |
| 손때 묻은 동전줄 | 상품과 카드 제거 서비스의 공통 할인율을 5%p 높인다. |
| 갈라진 지도핀 | 층과 방 식별자로 미완료 사건마다 10%를 판정한다. 발견한 비축품을 고르면 골드 10을 얻는다. |
| 어두운 피리구멍 | 공포가 걸린 적에게 카드가 직접 명중하면 피해가 2 증가한다. |
| 녹슨 회로핀 | 기계형 적에게 처음 직접 명중한 카드 피해를 4 높인다. |

유물은 실제 은신 상태와 적 데이터에 명시된 기계형 분류를 읽는다. 현재 등록된 적 원본에는 기계형 분류가 명시되어 있지 않아 회로핀의 조건은 별도 전투 검사에서 검증한다. 지도핀은 같은 방을 다시 열거나 저장을 불러와도 같은 선택지를 보여준다.
