# 153일차: 전투 수치 점검과 입력 관리자 중복 수정

- [전투 데이터 표](BalanceSnapshot.md)에 캐릭터 22명, 시작 카드 26종, 윈터폴 적 8종의 현재 원본 수치를 정리했다.
- 실제 10층 보스 전투의 체력·첫 공격력과 기본 카드의 피해를 측정하고 기획서의 임시 전투 길이 목표와 비교했다. 단순 계산은 실제 플레이 결과가 아니다.
- 탐사 UI가 만든 입력 관리자가 장면 전환 후에도 남아 거점의 입력 관리자와 중복되는 문제를 수정했다. 탐사 최초 진입, 일반 전투 후 복귀와 거점 귀환에서 입력 관리자 및 신규 입력 모듈을 확인했다.
- 모든 층의 실제 플레이, 22명 조합별 승률, 각성 활용과 정신력 안정 전략별 보스 턴 수는 아직 측정하지 않았다.
- 최종 확정 규칙에 맞춰 일반·정예 전투의 도주를 허용하고 보스전 도주는 계속 차단했다. 정예 도주 차단 오류를 수정 전 검사에서 재현했다.
- 검증: 수정 전 정예 도주 및 입력 관리자 중복 실패 재현, 수정 후 관련 검사와 Unity 전체 검사 311개 통과.
