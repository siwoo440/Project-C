# 280일차 유물 확장 · 감시 포드 렌즈부터 기계벌레 껍질까지

유물 시트 236~243행 여덟 종의 원화와 효과를 제작하고 상점, 도감, 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 감시 포드 렌즈 | 전투 시작에 무작위 생존 적 한 명을 두 적 턴 동안 표식한다. |
| 누전 코일 | 감전 중인 적에게 아군의 지팡이 카드가 직접 명중하면 방어 적용 전 피해를 4 높인다. |
| 압착 집게 손잡이 | 행동력 감소 또는 서리 감옥의 행동 취소가 활성인 적에게 아군 카드의 직접 피해를 10% 높인다. |
| 열원 탐색기 | 전투 중 처음으로 실명 아군이 실제 공격할 때, 해당 공격의 실명 명중률 감소를 무시한다. |
| 컨베이어 톱니 | 기계형 적을 타격해 출혈을 걸 때 출혈을 물리 방어 약화 2로 바꾼다. 기존 출혈 확률에 20%p를 더하며 약화는 두 적 턴 동안 유지된다. |
| 누전 포탑 탄피 | 방패 카드 사용 완료 후 다음 공격에서 처음 명중한 생존 적을 20% 확률로 두 적 턴 동안 감전시킨다. |
| 스크랩 주사기 | 아군 회복 카드의 체력 회복량을 20% 높인다. 실제 체력이 회복된 대상마다 독립적으로 20% 확률을 판정해 한 아군 턴 동안 공격력을 1 낮춘다. |
| 기계벌레 껍질 | 적의 직접 광역 공격으로 아군이 받는 피해를 10% 줄인다. |

서리 감옥의 행동 취소는 원래 경직 한 건에 출처를 기록한다. 경직이 소모되거나 만료되면 압착 집게 손잡이의 조건도 끝난다. 일반 경직에는 이 출처가 없으며, 게임이 사용하는 행동력 감소 상태도 유효하다. 기계형 출혈 치환은 원본의 기계형 분류를 읽으며 해당 자료를 가진 검사 대상으로 확인한다.
