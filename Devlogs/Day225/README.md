## 전투 튜토리얼

안내를 읽는 동안 불투명한 패널이 뒤쪽 손패, 레벨 표시, 공격 화살표를 가린다. 카드 사용 단계에서는 실습 버튼으로 안내를 접고 손패의 카드를 실제 대상 위로 끌어다 놓는다. 카드를 사용하면 행동력 설명으로 돌아간다.

| 안내를 읽을 때 | 카드를 직접 사용할 때 |
| --- | --- |
| ![레벨 표시와 화살표를 가린 전투 튜토리얼](BattleTutorialPanel.png) | ![안내를 접고 진행하는 카드 실습](BattleTutorialPractice.png) |

상점 관련 Unity 검사 25건과 튜토리얼 관련 검사 7건이 통과했다. 전투 검사는 손패 드래그와 적 대상 지정, 행동력 차감, 턴 종료와 다음 안내 표시까지 확인한다.
