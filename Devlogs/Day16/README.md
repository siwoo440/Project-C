# 16일차 개발일지 - 피해·회복 플로팅 숫자 및 전투 피드백 구축

---
## 개발 목표

15일차에 구현한 공통 피해 계산 결과와 회복량을 전투 화면에서 직접 확인할 수 있도록 시각 피드백을 추가했다.

16일차 완료 기준은 다음과 같다.

- 피해 적용 전용 이벤트 추가
- 회복 적용 전용 이벤트 추가
- 피해·회복 플로팅 숫자 생성
- 물리·마법·회복 색상 구분
- 숫자 상승과 페이드아웃
- 피격·회복 강조 오버레이
- 연속 효과 중첩 표시
- 이벤트 연결과 해제 처리

---
## 1. 피해·회복 이벤트 분리

`BattleUnitRuntime`에 다음 이벤트를 추가했다.

- `DamageTaken`: 대상 유닛과 `BattleDamageResult` 전달
- `HealthRestored`: 대상 유닛과 실제 회복량 전달

기존 `HealthChanged`는 HP 게이지와 체력 숫자 갱신 용도로 유지한다.

피해와 회복 결과를 분리하여 화면이 체력 차이를 다시 계산하지 않고 실제 적용량을 바로 사용할 수 있도록 구성했다.

---
## 2. 플로팅 숫자 구현

`BattleFloatingTextView`가 유닛 영역 내부에 전투 결과 숫자를 코드로 생성한다.

표시 규칙:

| 효과 | 표시 | 색상 |
|---|---|---|
| 물리 피해 | `-피해량` | 주황·붉은색 |
| 마법 피해 | `-피해량` | 하늘색 |
| 일반 피해 | `-피해량` | 흰색 |
| 회복 | `+회복량` | 초록색 |

표시 숫자는 프로젝트 공용 동적 TMP 폰트를 사용한다.

---
## 3. 상승·페이드 애니메이션

플로팅 숫자는 생성 후 다음 순서로 동작한다.

1. 유닛 초상화 영역 위에 생성
2. 약 0.75초 동안 위쪽으로 55만큼 이동
3. 이동 시간에 따라 투명도 감소
4. 표시 완료 후 오브젝트 자동 제거

게임 시간 정지의 영향을 줄이기 위해 실제 프레임 시간을 사용한다.

Unity Animator나 Animation Clip 연결 없이 코루틴으로 처리한다.

---
## 4. 연속 효과 위치 분산

짧은 시간에 여러 효과가 발생하면 각 플로팅 숫자가 서로 다른 위치에서 생성된다.

- 가로 위치 3단계 분산
- 세로 시작 위치 2단계 분산
- 최대 6개 위치 순환
- 숫자별 독립 코루틴 실행
- 먼저 생성된 숫자 제거가 다른 숫자에 영향 없음

전체 대상 카드와 여러 적의 순차 행동도 각각 별도 숫자로 표시할 수 있다.

---
## 5. 전투 강조 오버레이

`BattleCombatFeedbackView`가 유닛 전체 영역에 반투명 색상 오버레이를 코드로 생성한다.

피해 또는 회복이 발생하면 효과 색상을 약 0.18초 동안 표시하고 빠르게 투명하게 만든다.

오버레이 규칙:

- 물리 피해: 주황빛 강조
- 마법 피해: 하늘빛 강조
- 일반 피해: 흰색 강조
- 회복: 초록색 강조
- UI 레이캐스트 차단 없음

기존 진영 테두리를 변경하지 않으므로 카드 대상 선택 강조와 충돌하지 않는다.

---
## 6. BattleUnitView 연결

`BattleUnitView`가 런타임 유닛의 피해·회복 이벤트를 구독한다.

연결 처리:

- 유닛 Bind 시 피해 이벤트 등록
- 유닛 Bind 시 회복 이벤트 등록
- 전투 피드백 컴포넌트 자동 추가
- 피해 이벤트 발생 시 피해 숫자와 오버레이 표시
- 회복 이벤트 발생 시 회복 숫자와 오버레이 표시
- Unbind 시 이벤트 연결 해제

별도의 Inspector 참조 없이 유닛 프리팹 인스턴스에 필요한 컴포넌트를 런타임으로 추가한다.

---
## 7. 기존 전투 흐름 유지

시각 피드백은 기존 전투 계산을 변경하지 않는다.

- 피해량: `BattleDamageResult.AppliedDamage` 사용
- 회복량: `RestoreHealth`의 실제 회복량 사용
- HP 게이지: 기존 `HealthChanged` 이벤트 사용
- 사망 판정: 기존 `Died` 이벤트 사용
- 행동 예고: 기존 예상 피해 계산 유지

표시 숫자와 실제 HP 변화량이 같은 결과값을 사용한다.

## 16일차 결과

카드 공격, 적 공격과 회복 결과가 유닛 위의 색상 숫자와 짧은 강조 효과로 표시되도록 구현했다.

피해 유형과 회복을 색상 및 부호로 구분하고, 실제 HP 변화량을 그대로 표시하여 Console 없이도 전투 결과를 확인할 수 있게 되었다.

모든 피드백 UI는 코드로 자동 생성되므로 기존 Scene과 Prefab 연결을 변경하지 않는다.
