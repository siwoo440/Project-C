# 207일차 시제품 공용 카드 8종 확장

검·방패·성배·지팡이·펜타클 카드 여덟 종을 탐사 보물에 추가했다. 보물에서 선택한 파티원이 카드를 소유하고, 탐사를 저장한 뒤에도 같은 카드와 소유자가 복원된다.

| 원본 행 | 카드 | 속성·등급 | 행동력 | 전투 효과 |
| ---: | --- | --- | ---: | --- |
| 11 | 전장의 외침 | 검·전설 | 2 | 아군 전체의 공격력을 2턴 동안 3 증가 |
| 60 | 방패 들기 | 방패·일반 | 1 | 자신에게 방어도 8 부여 |
| 79 | 장갑 강화 | 방패·희귀 | 2 | 선택한 아군 한 명의 물리 방어력을 2턴 동안 5 증가 |
| 112 | 맑은 물 | 성배·일반 | 1 | 선택한 아군 한 명의 중독을 제거하고 체력 3 회복 |
| 123 | 정신 회복 | 성배·희귀 | 2 | 아군 전체의 정신력 5 회복 |
| 134 | 대정화 | 성배·특수 | 3 | 아군마다 먼저 적용된 해제 가능한 디버프 한 개 제거 |
| 154 | 화염구 | 지팡이·희귀 | 2 | 모든 적에게 각각 마법 피해 10 |
| 214 | 빠른 계산 | 펜타클·일반 | 0 | 카드 한 장을 뽑고 손패 한 장을 골라 버리기 |

‘맑은 물’은 최대 체력인 아군의 중독도 제거한다. 중독이 없는 부상자는 회복만 받는다. ‘장갑 강화’의 방어력과 ‘화염구’의 피해 속성은 기존 전투의 물리 방어력과 지팡이 마법 피해 규칙을 적용했다. [카드 원본 시트](https://docs.google.com/spreadsheets/d/1kvG8KUHTjFWNxejOwYquZ8Uy626iSmQOyxq7vsNmGvs/edit#gid=192551616)

## 시제품 수량

시트 공용 실물은 14종에서 22종으로 늘었다. 상점에서도 구매할 수 있는 기존 3종과 보물 전용 19종이다. 시제품 4명인 바보·황제·여사제·전차의 전용 시작 카드 4종과 역할 공용 임시 시작 카드 4종을 포함하면 고유 카드가 30종으로, 목표 30~40종의 하한에 도달한다. 역할 공용 임시 카드 4종을 제외하면 26종이다.

## 검증

- 원본 압축 파일의 동명 PNG 여덟 개와 Unity에 등록한 그림의 SHA-256이 모두 일치했다. 전용 검사는 원본 행·이름·설명·행동력·속성, 소유자 선택 보물 등록과 저장 원본 연결도 대조한다.
- 전투 검사는 실제 손패와 아군을 클릭해 버프의 수치와 지속시간, 중독만 제거하는 회복, 대상별 정화, 전체 마법 피해를 검사한다. ‘빠른 계산’은 행동력이 0인 상태에서 쓰고, 실제 선택 창에서 뽑은 카드를 버린다.
- 획득·저장 통합 검사는 카드를 받을 파티원을 보물 창에서 선택하고, 탐사 상태를 지운 뒤 저장 파일에서 카드와 소유자가 복원되는지 검사한다.
- Unity EditMode에서 공용 카드 전용 검사 9개와 획득·저장 통합 검사 2개가 모두 통과했다. 실제 손패·보물 창을 조작하는 검사는 플레이 모드에 진입해서 실행했다.
