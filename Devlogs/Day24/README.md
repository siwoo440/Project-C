# 24일차 : 적 다중 행동 패턴 및 순차 행동 선택 시스템 구축

---
## 개발 목표

- 적 하나가 여러 행동을 순서대로 사용하도록 확장
- 공격과 상태 이상 행동을 하나의 패턴 목록에서 관리
- 적마다 독립적인 패턴 진행 순번 유지
- 행동 패턴의 대상·속도·수치를 개별 설정
- 행동 예고에서 현재 패턴 정보 제공

---
## 구현 내용

---
### 1. 적 행동 패턴 데이터 추가

- `EnemyActionPatternData` 직렬화 데이터 추가
- 행동 표시 이름과 행동 종류 저장
- 공격력과 물리·마법 피해 유형 저장
- 상태 이상 종류·수치·지속 시간·최대 중첩 저장
- 대상 선택 규칙과 최소·최대 행동 속도 저장
- 공격과 상태 이상 행동의 설정 유효성 검사

---
### 2. 적 데이터의 다중 행동 지원

- `EnemyData`에 순차 행동 패턴 목록 추가
- 인스펙터에서 행동 단계를 순서대로 설정 가능
- 패턴 목록과 지정 순번 행동을 안전하게 조회
- 기존 단일 행동 필드는 호환 행동으로 유지
- 패턴 목록이 비어 있거나 모두 잘못된 경우 기존 행동 사용

---
### 3. 적별 순차 패턴 관리

- 적 런타임별 다음 패턴 순번 저장
- 행동 준비 시 현재 순번의 유효 행동 선택
- 잘못된 패턴 단계는 건너뛰고 다음 유효 단계 검색
- 마지막 행동 이후 첫 번째 행동으로 자동 순환
- 동일한 원본 데이터를 사용하는 적도 순번을 독립적으로 관리

---
### 4. 사망·소환·대상 재선택 연동

- 적 사망과 제거 시 저장된 패턴 순번 정리
- 소환 적은 첫 번째 패턴부터 시작
- 예정 대상 사망 시 현재 패턴의 대상 규칙으로 재선택
- 패턴 준비 후 실제 실행까지 같은 행동 설정 유지
- 기존 속도 기반 적 행동 순서 유지

---
### 5. 행동 예고 Canvas 확장

- 패턴 행동 이름 표시
- 현재 순번과 전체 패턴 수 표시
- 기존 행동 순서·속도·효과·대상 예고 유지
- 예고 영역을 세 줄에서 네 줄 크기로 확장
- 네 줄 표시에 맞춰 글자 크기 조정
- 런타임 생성 Canvas 코드에서 직접 반영

---
### 6. 테스트 적 패턴 적용

- `Test Enemy`: `물리 견제 → 마법 집중` 반복
- 물리 견제는 첫 번째 생존 아군 대상
- 마법 집중은 현재 체력이 가장 낮은 아군 대상
- `중독 실험체`: `독침 공격 → 중독 분사` 반복
- 독침 공격은 첫 번째 생존 아군 대상
- 중독 분사는 무작위 생존 아군 대상

---
## 행동 패턴 규칙

- 적 하나당 한 번에 예정 행동 하나만 생성
- 행동 준비 시점에 패턴 단계와 속도 확정
- 실행 직전에 행동 종류를 다시 선택하지 않음
- 대상만 사망한 경우 같은 패턴 규칙으로 새 대상 선택
- 유효한 패턴이 없을 때만 기존 단일 행동 사용
- 패턴 진행 상태는 전투 런타임 동안만 유지
