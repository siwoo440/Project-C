# 141일차: 심판·세계 임시 전용 카드

- 심판: 선택한 생존 아군을 8 회복한다. 회복 전 체력이 최대 체력의 50% 이하면 4를 추가 회복한다.
- 세계: 선택한 생존 아군에게 방어도 3을 준다. 이번 턴 다른 두 캐릭터의 전용 카드가 사용됐다면, 체력 비율이 가장 낮은 다른 생존 아군에게도 방어도 3을 준다.
- 세계의 최종 탐사 승리 해금, 해금 기록 유지, 전용 카드의 탐사 저장·복원 흐름을 확인했다.
- 전체 Unity 테스트 247개가 통과했다.
- 두 캐릭터의 추가 패시브와 정상·각성·붕괴별 상세 효과는 기획 확정 후 구현한다.
