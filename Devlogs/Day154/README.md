# 154일차: 경제 수치 점검과 전멸 재화 처리

- [경제 데이터 표](EconomySnapshot.md)에 윈터폴 보상, 설비별 강화 비용과 임시 상점 가격을 정리했다. 1층 일반 전투 1회의 재료 보상과 1단계 설비 비용도 비교했다.
- 탐사 중 지출은 사용자가 정한 대로 기존 재화부터 차감한다. 전멸하면 남은 탐사 획득 골드·나사·철판·전선을 잃고 기존 재화 잔액은 유지한다.
- 유물의 직접 골드 획득과 실패한 상점 거래의 환불도 기존·탐사 재화 구분을 유지한다.
- 탐사 저장에 획득 재화 잔액을 함께 보관하고, 전체 재화보다 큰 잘못된 획득분은 복원하지 않는다. 이전 저장에는 획득 출처 정보가 없으므로 기존 잔액은 보존하고 복원 이후 획득분부터 구분한다.
- 실제 플레이에 따른 탐사별 수입과 2~3회·4~6회 설비 강화 목표는 아직 측정하지 않았다. 전멸 시 유물·포션 등 아이템의 기존 보유분과 탐사 중 획득분 분리는 별도 점검이 필요하다.
- 검증: 사용자 선택 소비 예시, 직접 골드 획득, 상점 실패 환불, 탐사 저장 복원·손상 차단·이전 저장 보존과 Unity 전체 검사 313개 통과.
