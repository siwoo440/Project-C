# 156일차 : 전원 출전 불가 긴급 대기 추가

- 보유 캐릭터 전원이 출전할 수 없을 때 거점에 무료 긴급 대기 버튼을 표시합니다.
- 긴급 대기는 부활 대기를 한 단계 줄이며, 출전 가능한 캐릭터가 생기면 사용할 수 없습니다.
- 재화, 경험치, 호감도와 탐사 완료 횟수는 증가하지 않습니다. 대기 중 저장과 불러오기도 확인했습니다.
- 피로도와 치료 대기는 아직 구현되지 않아 긴급 대기에 포함되지 않았습니다.
- `EmergencyWait.png`는 화면 확인을 위해 모든 보유 캐릭터를 임시로 회복 대기 상태로 설정해 촬영했습니다.
- Unity 편집 모드 검사 316개를 모두 통과했습니다.
