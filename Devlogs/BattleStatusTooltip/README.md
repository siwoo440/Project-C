# 전투 상태 상세

글자와 제목을 금속 테두리 안쪽에 배치했습니다. 설명이 길면 고정 제목 아래에 세로 스크롤바가 나타납니다. 휠을 돌리거나 손잡이를 끌어 본문을 끝까지 읽을 수 있습니다.

---

## 검증

- Unity 검사 11건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- Windows 윈터폴 전투에서 짧은 상태 목록과 효과 15개의 긴 목록을 확인했습니다. 마우스를 패널로 옮겨 휠을 위아래로 돌리고, 손잡이로 마지막 항목까지 이동한 뒤 패널 밖에서 닫히는 것을 확인했습니다.
