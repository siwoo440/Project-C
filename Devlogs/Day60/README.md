# 60일차 개발일지

---
## 작업 내용

- 파티 선택 상태를 관리하는 `PartySelection`을 추가했다.
- 사망·회복 중·출전 불가 캐릭터와 중복 선택, 4명 초과 선택을 차단했다.
- 캐릭터 선택 해제와 빈 자리 재편성을 지원한다.
- 출발 직전 빈 파티와 선택 후 변경된 출전 상태를 다시 검증한다.

---
## 검증

- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 54개 통과.
- 상태 변경 후 사망 캐릭터 출전 차단과 인원 제한을 테스트했다.

---
## 남은 작업

- 실제 거점 화면, 덱 구성, 탐사 출발 버튼과 파티 선택 상태를 연결해야 한다.
- 캐릭터별 전용 카드와 패시브는 아직 구현되지 않았다.
