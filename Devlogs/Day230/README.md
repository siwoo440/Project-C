# 230일차 유물 확장 · 낡은 동전지갑부터 봉인된 지도까지

![별도 투명 배경으로 제작한 유물 8종](RelicIcons.png)

| 유물 | 발동 조건과 효과 |
| --- | --- |
| 낡은 동전지갑 | 전투에서 승리하면 보상 골드 +10%. 추가량의 소수점 이하는 버린다. |
| 균열 채집용 핀셋 | 「잿더미 속에서 빛나는 것」에서 유물 획득에 성공한 뒤 30% 확률로 미보유 유물 후보 하나를 추가한다. 후보 두 개 중 하나를 고른다. |
| 흑연 연필 | 확인으로 덱 위의 카드 한 장을 골라 손패에 넣으면 카드 1장을 추가로 뽑는다. 턴당 1회. |
| 결단의 리본 | 확인으로 고른 카드의 결정 추가 효과가 실제로 발동하면 공용 행동력 +1. 턴당 1회이며 결정 카드 추가 후 발동한다. |
| 무거운 철제 장화 | 적의 직접 공격으로 파티가 실제로 잃을 체력을 1 줄인다. 파티 전체에서 턴당 세 번까지 적용한다. |
| 흰 장미 코사지 | 사용자의 정신력이 50 이상이면 체력 회복 카드의 직접 회복량이 대상마다 1 증가한다. |
| 검은 장미 코사지 | 사용자의 정신력이 30 이하이면 공격 카드의 첫 직접 적중 피해 +2. 파티 전체에서 턴당 한 번 발동한다. |
| 봉인된 지도 | 탐사 도중 사용하면 현재 층의 출발 방으로 한 번 돌아간다. 이미 처리한 방과 받은 보상은 유지된다. 이동에 성공하면 지도는 소모된다. |

Windows 플레이어의 잿더미 이벤트에서 핀셋이 발동해 잿빛 인장과 금속 향로를 후보로 표시했다. Unity 검사에서 선택 취소 후 재진입해도 후보가 유지되는 것과, 유물 하나를 지급한 뒤 이벤트가 다시 보상하지 않는 것을 확인했다. 봉인된 지도는 출발 방까지 이동하고 실제 소모한 뒤 재획득해도 같은 탐사 동안 다시 쓸 수 없다.

유물 신규·관련 경로 21건과 기존 검 카드·유물·화면 회귀 46건이 통과했다.
