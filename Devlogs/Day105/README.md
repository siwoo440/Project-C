# 105일차: 메인 메뉴 이미지와 네 버튼

---
## 작업 내용

- 승인된 시안을 기준으로 배경, 로고, 버튼 장식을 각각 별도 이미지로 제작했습니다.
- `CHAOS` 글자와 O 안쪽 별을 검정색으로 변경하고 검정 글자의 광택을 낮췄습니다.
- `10_MainMenu` 씬에 새로하기, 이어하기, 설정, 나가기 버튼을 배치했습니다.
- 버튼 문구를 한글 텍스트로 표시하고 마우스·키보드 선택 색상을 연결했습니다.
- 새로하기는 기존 거점 진입 동작, 설정은 설정 씬 왕복, 나가기는 게임 종료 동작을 사용합니다.
- 저장 기능이 아직 없으므로 이어하기는 비활성 상태입니다.
- Unity가 생성한 아틀라스 메타 파일의 공백 오류를 정리했습니다.

---
## 검증

- 별도 Unity 프로젝트 복사본에서 전체 EditMode 테스트 145개 통과.
- 메인 메뉴 씬의 독립 이미지, 네 버튼 문구와 상태, 버튼 재연결 시 중복 실행 방지 확인.
- 부트 → 메뉴 → 설정 → 메뉴 → 거점의 실제 씬 흐름 확인.
- 컴퓨터 UI 자동화와 독립 실행 빌드는 사용하지 않았습니다.
- 사용자 화면에서의 최종 시각 배치는 별도 확인이 필요합니다.
