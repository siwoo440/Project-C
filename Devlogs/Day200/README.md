# 200일차 탐사 지도와 방별 튜토리얼

탐사 도움말은 다섯 장이다. 첫 장에서는 WASD나 방향키로 한 걸음 움직여야 오른쪽 화살표가 활성화된다. 이후에는 이전·다음 페이지를 자유롭게 오갈 수 있다. 기존 완료 기록이 있는 플레이어는 탐사 도움말 버튼에서 새 내용을 다시 볼 수 있다.

| 페이지 | 실제 화면에서 확인할 내용 |
| --- | --- |
| [1. 탐사 이동](GuideMap.png) | 석재 타일의 경계와 이동 경로 |
| [2. 이벤트](GuideEvent.png) | 표식에 접촉한 뒤 선택지와 결과를 확인하는 방법 |
| [3. 보물](GuideTreasure.png) | 공용 카드를 받을 파티원을 고르거나 같은 방에서 나중에 선택하는 방법 |
| [4. 휴식](GuideRest.png) | 방의 위험도, 파티 회복 및 카드 강화 |
| [5. 상점](GuideShop.png) | 상품 가격과 보유 유물 판매, 구매 카드의 소유자 선택 |

삽입한 예시와 다섯 페이지 모두 Windows 플레이어에서 1600×900으로 촬영했다. 탐사 씬에서 이동 입력으로 첫 장을 넘기고 실제 화살표 버튼으로 끝까지 진행했다. 자동 검사에서도 각 페이지의 제목과 이미지 원본, 뒤로 가기, 건너뛰기와 다시 보기를 확인했다.
