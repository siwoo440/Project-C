# 109일차: 새로하기 경고 패널

---
## 작업 내용

- 새로하기 버튼을 누르면 현재 진행과 미저장 데이터가 사라지고 기존 저장이 덮어써질 수 있음을 안내한다.
- 확인을 누른 경우에만 새 게임을 시작하고, 취소하면 현재 메뉴와 진행 상태를 유지한다.
- 경고 표시 중 다른 메뉴 입력을 막고 취소 버튼에 키보드 초점을 둔다. Escape 키로도 취소할 수 있다.

---
## 검증

- 경고 표시·취소 시 상태 유지와 확인 후 초기화·거점 진입 흐름을 검사했다.
- 격리된 Unity 프로젝트 복사본에서 전체 EditMode 테스트 151개 통과.
- 실제 사용자 화면의 시각 배치와 독립 실행 빌드는 확인하지 않았다.
