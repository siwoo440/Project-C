# 202일차 검 보물 카드 3종

탐사 보물에서 검 카드 세 장을 획득하고 소유할 파티원을 선택할 수 있다. 윈터폴의 ‘재폭풍의 눈’을 응시하면 기존 희귀 카드 ‘회복의 물결’과 함께 ‘연속 베기’, ‘이연참’도 나올 수 있다.

| 카드 | 희귀도 | 행동력 | 선택한 적 한 명에게 주는 기본 피해 |
| --- | --- | ---: | --- |
| 베기 | 일반 | 1 | 4씩 1회 |
| 연속 베기 | 희귀 | 2 | 4 + 4, 총 2회 |
| 이연참 | 희귀 | 2 | 6 + 6, 총 2회 |

시트에 피해의 속성은 따로 지정되어 있지 않아 기존 검 공격과 같은 물리 피해를 적용했다. 같은 적에게 각 타격의 명중, 약점, 물리 방어력, 남은 방어도를 순서대로 계산한다. 첫 공격이 빗나가도 두 번째 공격은 시도한다. 적이나 공격자가 사망하거나 보스 단계 전환이 예약되면 남은 타격을 중단한다. 행동력과 카드 한 장은 사용 시 한 번만 소모한다. ## 시제품 카드 수량

202일차 기준 시트에서 실제 보물로 받을 수 있는 공용 카드는 14종이다. 이 중 강타·검풍·정화는 상점에서도 살 수 있고, 나머지 11종은 보물 전용이다. 바보·황제·여사제·전차 편성의 시작 덱 12장은 캐릭터 전용 4종과 역할 공용 임시 카드 4종으로 구성된다. 두 목록을 실제 카드 ID와 이름으로 대조한 결과 중복은 0종이다.

역할 공용 임시 카드까지 포함한 플레이 가능 카드는 22종이다. 기획 목표 30~40종까지 8~18종이 남는다. 임시 역할 카드 4종을 제외한 집계는 18종이다.

## 검증

- 그림 세 장의 SHA-256을 원본 카드 압축 파일의 ‘베기.png’, ‘연속 베기.png’, ‘이연참.png’와 대조해 모두 일치함을 확인했다.
- 기존 탐사 저장은 카드 ID, 소유자 ID, 강화 단계를 보관한다. 타격 횟수는 카드 원본에서 읽으며, 타격 수가 없는 기존 공격 카드에는 1회를 적용한다.
- `SwordTreasureCardTests`는 시트와 보상·그림·저장 원본을 대조하고, 손패에서 카드를 사용해 방어도 소진, 전차의 표식, 실명 중 명중, 처치·보스 전환 시 연타 중단을 검사한다. 기존 강화 강타만 추가한 탐사 파일로 소유자와 강화 단계도 검사한다. `AcquisitionPersistenceTests`는 실제 보물에서 선택한 카드와 소유자를 파일에 저장하고 복원한다.
- 203일차까지 반영한 Unity EditMode 전체 380개가 모두 통과했다. 검 카드 전용 검사 6개, 획득·저장 검사 2개, 재폭풍의 눈 검사 4개를 포함한다.
