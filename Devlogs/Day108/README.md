# 108일차: 거점 이어하기

---
## 작업 내용

- 메인 메뉴에서 저장 파일의 버전과 내용을 검사해 이어하기 활성 여부를 결정한다.
- 이어하기 선택 시 저장을 다시 검증하고 거점 상태를 복원한 후 거점 씬으로 이동한다.
- 복원 실패 시 메뉴와 현재 상태를 유지하고 이어하기 버튼을 비활성화한다.
- 거점 이어하기 전에 이전 탐사 회차 상태를 정리한다.

---
## 검증과 남은 작업

- 저장 파일 없음, 잘못된 파일, 정상 복원, 클릭 전 저장 손상 상황을 테스트했다.
- 격리된 Unity 프로젝트 복사본에서 전체 EditMode 테스트 150개 통과.
- 탐사 중 저장과 탐사 위치에서 이어하기는 아직 구현하지 않았다.
- 실제 사용자 화면에서의 시각 확인과 독립 실행 빌드는 수행하지 않았다.
