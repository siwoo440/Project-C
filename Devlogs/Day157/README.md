# 157일차 : 유물 데이터 기반 구축

- 유물 시트의 이름과 설명, 구매·판매 가격 범위와 편차 298종을 게임 리소스로 보관합니다.
- 검은 손수건, 은빛 톱니, 구겨진 포스터의 시트 가격 오류를 임시값으로 정리하고 같은 범위를 자료에 반영했습니다.
- 이 자료는 실제 획득 가능한 유물과 별도로 관리합니다. 개별 유물의 효과, 상점 가격 연결, 판매와 이미지 제작은 이후 작업입니다.
- 유물 298종의 이름 중복과 가격 편차를 자동 검사합니다.
- Unity 편집 모드 검사 317개를 모두 통과했습니다.
- 카드 시트에서는 제목을 제외한 251종을 확인했으며, 개별 카드 효과와 시트 이미지 적용은 별도 작업입니다.
