# 229일차 검 카드 확장 · 급소 노림부터 쌍검 연무까지

| 카드 | 행동력 | 전투 효과 |
| --- | ---: | --- |
| 급소 노림 | 1 | 적 한 명에게 물리 피해 6. 이 타격의 치명타 확률 +10%p. |
| 칼날 정비 | 0 | 이번 턴에 사용자의 다음 검 피해 카드의 모든 타격에 피해 +3. 카드 사용 시 소모하고, 다시 걸면 +3으로 갱신한다. |
| 전열 정돈 | 1 | 선택한 아군에게 방어도 5와 한 턴 동안 공격력 +1. |
| 처형 베기 | 2 | 체력이 최대치의 50% 이하인 적 한 명에게 물리 피해 18. |
| 피바람 | 2 | 모든 적에게 물리 피해 6. 적중한 생존 적마다 30% 확률로 출혈 2턴 부여. |
| 검격 반사 | 2 | 다음 아군 턴 전까지 적의 직접 물리 공격에 체력을 잃고 생존하면 실제 체력 손실의 절반을 한 번 돌려준다. 소수점은 버리고 상대 방어를 무시한다. |
| 파고들기 | 2 | 적 한 명에게 물리 피해 12. 그 타격에서 상대 임시 방어도의 30%를 건너뛰며, 건너뛴 방어도는 남는다. |
| 쌍검 연무 | 2 | 생존한 적 중 하나를 타격마다 뽑아 물리 피해 4를 총 네 번 준다. |

칼날 정비 후 쌍검 연무의 원본 피해는 타격당 7이었다. 네 타격의 방어 계산을 마치자 적 체력이 50에서 26으로 줄었다. 파고들기는 건너뛸 방어도 양을 내림한다. 방어도 10이면 3을 건너뛰고, 방어도 3이면 전부 계산한다.

Unity 최종 검사 57건에서 보물 획득, 지정한 파티원 소유권과 저장 복원, 상태 표시 및 228일차 유물과의 조합을 확인했다.
