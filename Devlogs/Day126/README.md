# 126일차 저장 안정성 검증

---
## 작업 내용

- 저장 파일을 교체할 때 이전 정상본을 별도 복구본으로 보관하고 원본이 손상되거나 없을 때 사용
- 이전 저장을 불러오는 슬롯과 확인창에 복구 사실을 표시하고 복구 파일의 저장 시각을 표시
- 지원하지 않는 새 버전의 원본과 복구본 덮어쓰기 방지
- 거점과 탐사 저장이 같은 슬롯을 번갈아 사용할 때 현재 정상 원본 우선
- 슬롯 삭제와 탐사 종료 시 복구본도 정리하여 삭제한 진행 상황의 재등장 방지
- 저장 중 남은 임시 파일은 정상 저장으로 인식하지 않음
- 실제 Unity 저장 중 임시 파일 작성 단계에서 독립 테스트 프로세스를 강제 종료한 뒤 원본 저장 복원 확인
- 강제 종료 검증은 임시 파일 작성 시점을 대상으로 하며 모든 저장 단계와 저장 장치 장애를 재현한 것은 아님
- 실제 화면 캡처: `RecoverySlot.png`, `RecoveryWarning.png`
- 전체 EditMode 회귀 검사 178개 통과, 강제 종료 후 복원 검사 통과
