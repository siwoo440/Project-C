# 261일차 지팡이 카드 확장 · 저주 표식부터 마력 방출까지

카드 시트 169~176행의 원화와 효과를 실제 전투, 보물 보상, 도감과 회차 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 저주 표식 | 지정 적이 받는 마법 피해를 두 적 턴 동안 15% 늘린다. |
| 바람 칼날 | 적 하나에게 마법 피해 6을 준다. 명중한 생존 적의 회피율을 두 적 턴 동안 10%p 줄인다. |
| 마나 회수 | 손패의 다른 지팡이 카드 한 장을 선택해 버리고 현재 행동력을 1 회복한다. |
| 화염 쇄도 | 지정한 서로 다른 생존 적에게 각각 마법 피해 9를 준다. 명중한 생존 적에게 각각 35% 확률로 화상 2를 두 턴 동안 부여한다. |
| 서리 감옥 | 적 하나에게 마법 피해 8을 준다. 명중한 생존 적은 40% 확률로 다음 행동 한 번을 잃는다. |
| 연쇄 번개 | 살아 있는 적을 타격마다 무작위로 골라 마법 피해 6을 최대 세 번 준다. |
| 중력 압박 | 생존 적 전체의 회피율을 두 적 턴 동안 15%p 줄인다. |
| 마력 방출 | 생존 적 전체에게 마법 피해 9를 준다. |

서리 감옥의 시트는 행동력 1 감소를 명시한다. 게임에서 적마다 적 턴에 행동을 하나씩 예고하므로 기존 행동 1회 취소를 사용했다. 화염 쇄도는 대상이 한 명이면 한 번 타격한다. 회피 감소는 현재 회피율을 최소 0%까지 낮춘다.

Unity 검사 33건이 통과했다. 상점 검사 2건을 포함했고 실패와 건너뜀은 각각 0건이었다. Windows Direct3D 11의 두 적 검사 조우에서 저주 표식으로 마법 취약 15%와 남은 적 턴 2를 확인했다. 이어 마력 방출 한 번으로 표식 대상과 다른 적에게 방어 계산 전 마법 피해가 각각 10과 9 적용됐고, 두 카드에 행동력이 총 3 사용됐다. [저주 표식](CurseMarkApplied.png) · [마력 방출](ManaDischargeMagicVulnerability.png)
