# 몬스터 체력 조정

전투와 소환에 등장하는 적의 시작 체력과 최대 체력을 기존 최종 수치의 절반으로 조정했습니다. 층·조우 등급·지역 레벨을 먼저 적용하고, 홀수는 올림해 최소 1을 유지합니다. 기본 공격력 배율과 시작 정신력 보정은 기존 방식으로 계산합니다.

---

## 검증

- Unity 검사 18건 통과. 상점 검사 2건을 포함했으며 실패와 건너뜀은 0건입니다.
- 보스의 체력에 따른 페이즈 전환과 소환 적의 체력 조정도 확인했습니다.
