# 256일차 유물 확장 · 검은 별가루부터 침식 방울목걸이까지

유물 시트 138~145행의 원화와 실제 획득, 장착 효과, 상점 및 회차 저장을 연결한다.

| 유물 | 효과 |
| --- | --- |
| 검은 별가루 | 아군의 마법 피해로 생존 적의 체력이 줄면 20% 확률로 그 적의 정신력을 2 낮춘다. |
| 어긋난 심장파편 | 현재 체력이 절반 이하인 생존 아군이 적에게 주는 피해를 15% 높인다. |
| 어비스 밀랍인장 | 아군이 적에게 행동 불가 상태를 실제로 적용하면 카드 한 장을 뽑는다. |
| 침묵 결정종 | 공포가 걸린 적의 공격력을 1 낮춘다. |
| 붉은 균열섬유 | 적이 출혈로 받는 턴 종료 피해를 1 높인다. |
| 검게 물든 청진기 | 전투 시작에 현재 체력이 가장 높은 생존 적 하나를 실제 아군 턴 두 번 동안 표식으로 지정한다. |
| 공허의 잔뿌리 | 적에게 적용되거나 중첩된 약화가 다섯 번 늘어날 때마다 생존 아군 각각을 체력 3만큼 회복한다. |
| 침식 방울목걸이 | 아군 턴에 아군이 적의 정신력을 실제로 낮추면 25% 확률로 현재 행동력을 1 회복한다. |

출처가 있는 실제 아군 피해에 심장파편의 비율을 한 번 적용하며 소수점은 내린다. 청진기는 현재 체력이 같을 때 적 배치 순서가 앞선 생존 적을 고른다. 선택한 적의 기존 약화 면역을 적용하며 별도의 대체 대상은 조회하지 않는다. 약화를 받지 않았거나 이미 행동력이 상한인 상황에는 방울목걸이의 확률 판정을 하지 않는다.

## 검증

- Unity 검사 34건 전부 통과. 실패와 건너뜀 각 0건. 상점 실동작 검사 2건 포함.
- Windows Direct3D 11 실행에서 유물 8종 저장과 불러오기를 확인했다.
