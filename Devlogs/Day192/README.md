# 192일차 탐사 재화 아이콘 UI

탐사 화면 오른쪽 위 네 칸에 골드, 나사, 철판, 전선을 순서대로 표시한다. 아이콘 오른쪽의 수량은 재화를 얻거나 소비하는 즉시 갱신된다. 층과 캐릭터 경험치는 패널 아래에서 확인할 수 있다.

상점 방에 들어가면 해당 방의 재고를 연다. 화면이 이미 열려 있으면 두 번째 방의 방문 기록과 재고를 보존한다. 탐사 중 항상 보이던 상점 버튼, 호감도, 클리어 조우 문구를 제거했다.

Unity 6000.3.21f1의 별도 검증 프로젝트에서 재화 표시, 상점 방문, 공용 카드 구매와 소유자 복원, 보상 전용 카드 구분, 유물 할인·판매, 탐사 자동 저장을 포함한 기능 검사 6개와 화면 촬영 검사 1개가 통과했다.

![골드 123, 나사 45, 철판 67, 전선 89를 표시한 탐사 화면](ExplorationResources.png)
