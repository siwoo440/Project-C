# 106일차: 새 게임 초기화와 저장 범위

---
## 작업 내용

- 새로하기 시 기존 자원, 설비, 성장, 호감도, 파티 상태와 탐사 상태를 초기화했다.
- 이전 전투 결과, 상점, 휴식, 회차 덱, 파티 편성, 유물과 소모품을 정리한다.
- 세계 해금은 유지하며, 기존 사용자 설정을 삭제하지 않는다.
- 현재 상태 보관 위치와 후속 저장 범위를 `저장과초기화기준.md`에 정리했다.

---
## 검증과 남은 작업

- 새로하기의 자원·성장·탐사, 유물·소모품, 파티·덱, 전투 결과·상점·휴식 초기화와 세계 해금 유지 테스트를 추가했다.
- 별도 프로젝트 복사본에서 전체 EditMode 테스트 145개 통과.
- 거점 상태의 파일 저장·복원과 이어하기는 구현되지 않았다. 107일차부터 진행한다.
- 실제 사용자 화면에서의 시각 확인과 독립 실행 빌드는 수행하지 않았다.
