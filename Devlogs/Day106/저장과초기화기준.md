# 106일차 저장과 초기화 기준

---
## 범위

- 새로하기는 이전 게임의 거점 성장과 진행 중 탐사를 초기 상태로 되돌린다.
- 세계 해금 기록과 설정은 유지한다. 현재 설정 화면에는 저장된 옵션이 아직 없다.
- 이 기준은 시제품용 제안이며, 저장 파일 구현과 이어하기는 후속 일차에서 진행한다.

---
## 현재 상태와 초기화 대상

| 구분 | 현재 보관 위치 | 새로하기 처리 |
| --- | --- | --- |
| 골드·나사·철판·전선 | `PlayerResourceManager` | 초기화 |
| 설비 단계 | `FacilityUpgradeManager` | 초기화 |
| 성장 경험치·레벨 | `CharacterProgressionManager` | 초기화 |
| 호감도 | `CharacterAffinityManager` | 초기화 |
| 아군 체력·정신력·사망 및 회복 | `BattleResultManager`, `CharacterRecoveryManager` | 초기화 |
| 탐사 층·조우·이벤트·보상 상태 | `ExplorationSessionManager` | 초기화 |
| 파티·회차 덱·상점·유물·소모품·휴식 | 관련 런타임 관리자 | 이전 회차 상태 제거 |
| 세계 해금 | `CharacterUnlockProgress`, `PlayerPrefs` | 유지 |
| 게임 설정 | 현재 저장 구현 없음 | 향후 설정 저장 시 유지 |

---
## 후속 구현 순서

- 106일차: 새로하기에서 기존 런타임 상태를 초기화하고, 실제 메뉴 흐름으로 검증한다.
- 107일차: 거점 상태의 저장·복원 데이터와 안정적인 기록 경로를 구현한다.
- 108일차: 유효한 저장 데이터가 있을 때 이어하기를 활성화한다.
- 109일차 이후: 탐사 데이터와 자동 저장 지점, 손상 데이터 처리를 추가한다.

저장 파일이 도입된 뒤에는 새로하기에서 기존 저장을 어떻게 교체할지도 함께 검증해야 한다.
