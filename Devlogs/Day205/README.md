## 조작과 성능

탐사 안내 다섯 페이지는 실제 Windows 플레이어 화면을 사용한다. 지도에서 이동한 뒤 이벤트·보물·휴식·상점 안내를 읽을 수 있다. 실제 선택 화면에서는 비용을 치르는 파티원과 획득한 카드를 받을 파티원을 구분한다. [탐사 튜토리얼](../Day200/README.md) · [캐릭터 선택 화면](../Day201/AshstormActor.png)

194일차의 Windows 에디터 측정에서 거점과 탐사를 세 번 왕복했다. 탐사 진입은 287.7~500.2ms, 거점 복귀는 272.0~288.2ms였다. 장시간 메모리 추이와 다른 기기의 프레임 속도는 별도 측정 대상이다. [측정 조건과 원시 수치](../Day194/README.md)

204일차 기능을 포함한 Unity 6000.3.21f1 회귀 검사 383개가 모두 통과했다. 이벤트 선택, 비용 차감, 획득한 카드·유물의 소유와 저장 복원, 캐릭터 사망·회복을 포함한다. 위 표의 실제 플레이 시간과 밸런스 항목은 이 검사로 측정할 수 없다.
