# 탐사 상단 HUD 개편

왼쪽 소모품과 유물 버튼, 탐사 도움말, 우측 자원 표시를 첨부한 배치에 맞춰 확대했다. 중앙 상태판은 흰색 굵은 `F1` 형식으로 현재 층을 표시하고 아래 줄에 캐릭터 레벨과 경험치를 배치한다. 경험치가 바뀌면 현재 탐사 화면에서 즉시 갱신한다.

회색 금속 상태판은 ImageGen으로 제작하고 투명 여백을 정리한 768×256 스프라이트로 적용했다.

## 검증 결과

- Unity 검사 10건 통과. 상점 재고·구매 확인 2건을 모두 실행했다.
- 실제 Windows 플레이어의 두 해상도에서 두 소모품 줄, 유물, 도움말, 층 표시, 네 자원이 겹치지 않음을 확인했다. [1600×900](ExplorationHeader1600x900.png) · [1280×800](ExplorationHeader1280x800.png)
- 도움말 X 닫기, 유물 창 열기·닫기, F로 이벤트 열기, 경험치 증가 즉시 표시를 확인했다.
