# 158일차 : 전투 시작 방어 유물 추가

- 봉쇄문 인증키는 전투 시작 시 생존 아군 전체에게 방어도 6을 부여합니다.
- 상점과 보물 후보, 저장 복원 목록에 유물을 연결했습니다. 구매 후 저장·복원과 실제 전투 적용을 확인했습니다.
- 상점 가격은 시트의 228~264 범위에서 임시로 246골드를 적용했습니다. 범위 가격 결정과 판매 기능은 후속 작업입니다.
- `GateKeyShop.png`는 실제 상점 상품 목록을 촬영한 화면입니다.
- 유물 그림은 기존 유물 이미지를 참고해 이미지 생성 도구로 제작했습니다. 요청 내용은 청록색 빛과 황동 장식을 가진 방패 모양의 기계식 성문 열쇠입니다.
- Unity 편집 모드 검사 318개를 모두 통과했습니다.
