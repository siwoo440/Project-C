# 255일차 성배 카드 확장 · 생명의 계약부터 빛의 대심판까지

카드 시트 143~149행의 일곱 장을 원화, 보물 보상, 소유자 저장 및 실제 전투에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 생명의 계약 | 시전자 정신력 5를 먼저 차감하고 지정 아군의 체력을 25 회복한다. |
| 대천사의 축복 | 살아 있는 아군 각각의 제거 가능한 디버프를 모두 정화하고 체력 25를 회복한다. |
| 순교자의 빛 | 시전자 체력을 1로 낮춘 뒤 시전자를 포함한 생존 아군 각각의 체력을 30 회복한다. |
| 부활 성가 | 현재 전투에서 쓰러진 출전 아군 한 명을 최대 체력의 50%로 부활시킨다. 소수점은 올린다. |
| 불멸의 잔 | 생존 아군마다 첫 치명 피해에서 체력 1로 버티는 보호 1회와 방어도 10을 준다. |
| 성배의 기적 | 현재 행동력을 모두 써서 1당 각 생존 아군 체력을 8 회복한다. 4 이상 지불하면 대상마다 약화 하나를 제거한다. |
| 빛의 대심판 | 생존 적 전체에 마법 피해 25를 주고 생존 아군 각자 체력 15를 회복한다. |

성배의 기적은 행동력이 0이면 사용할 수 없으며 회복 후 첫 제거 가능한 디버프를 정화한다. 순교자의 빛은 체력 비용과 피해를 구분한다.

## 실제 검증

Unity 단독 재검사에서 상점 2건을 포함한 32건이 통과했다. 실패와 건너뜀은 각각 0건이다. 실제 치명 피해로 쓰러진 최대 체력 87의 아군을 부활 성가로 체력 44에 되살렸다. Windows 실행판에서는 성배의 기적이 행동력 6을 모두 지불하고 아군 체력을 29에서 77로 회복했다. 약화 두 개 중 먼저 적용한 중독 한 개가 제거됐다.
