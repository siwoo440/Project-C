# 196일차 던전 타일 외곽선

탐사 바닥과 벽 타일 이미지의 네 변에 검은 외곽선을 추가했다. 같은 재질의 타일이 이어지는 곳에서도 이동 단위인 한 칸을 구별할 수 있다.

기존 석재 무늬와 색을 기준으로 두 이미지를 각각 편집했다. 두 스프라이트 모두 기존 크기인 1254×1254픽셀을 유지했고, 네 변이 만나는 모서리까지 검은 선이 이어지는지 확인했다.
