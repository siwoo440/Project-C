# 65일차 개발일지

---
## 작업 내용

- 선택한 파티를 원본 에셋과 분리된 런타임 파티·덱·전투 편성으로 생성한다.
- 역할별 임시 카드를 선택 인원에게 배분해 12장 시작 덱을 만든다.
- 빈 파티, 출전 불가 상태, 역할 카드 누락 시 편성 생성을 차단한다.

---
## 검증

- 런타임 편성의 카드 소유자, 파티 복사 및 누락 데이터 차단을 확인했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 60개 통과.

---
## 남은 작업

- 역할별 임시 카드 에셋과 거점 출발 버튼을 실제 탐사·전투에 연결해야 한다.
- 임시 카드는 캐릭터별 전용 카드나 패시브를 대체하지 않는다.
