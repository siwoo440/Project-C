# 263일차 지팡이 카드 확장 · 비전 보호부터 운명 동결까지

카드 시트 177~184행의 원화와 효과를 실제 전투, 보물 획득, 도감과 회차 저장에 연결한다.

| 카드 | 효과 |
| --- | --- |
| 비전 보호 | 생존 아군 전체가 적의 직접 마법 피해에 대한 저항 15%를 두 적 턴 동안 얻는다. |
| 정신 충격 | 지정 적에게 마법 피해 10을 준다. 명중한 생존 적의 정신력을 5 낮춘다. |
| 냉기 폭발 | 생존 적 전체에 마법 피해 7을 준다. 명중한 생존 적의 행동 속도를 한 적 턴 동안 1 낮춘다. |
| 화상 증폭 | 화상이 걸린 모든 생존 적의 활성 화상을 한 적 턴 연장한다. |
| 감전 전이 | 감전 대상에 마법 피해 12를 준다. 명중 후 다른 생존 적 하나에게 감전 1을 두 적 턴 동안 부여한다. |
| 마법 반향 | 이번 아군 턴에 같은 사용자의 다음 지팡이 마법 공격을 한 번 복제한다. 복제는 기본 피해의 50%를 내림해 정상 명중과 방어를 거친다. |
| 룬 폭발 | 지정 적에게 마법 피해 11을 주며, 활성 청진기·공개·전차 표식이 있는 대상에는 6을 추가한다. |
| 운명 동결 | 지정 적에게 한 적 턴 동안 기절을 부여하고, 두 적 턴 동안 마법 저항력을 10 낮춘다. |

마법 반향은 복제 피해에만 적용하며 카드 사용과 비용, 정신력 및 다른 상태 부여는 원본에서 한 번 정산한다. 감전 전이는 원래 적의 감전을 유지한다. 운명 동결은 기존 약화의 저항력 수치 체계를 사용한다.

최종 Unity 검사 34건이 통과했다. 상점 검사 2건을 포함했고 실패와 건너뜀은 각각 0건이었다. 운명 동결 검사는 전투 전에 적의 마법 저항 20을 설정해, 약화 중 저항 10과 종료 후 저항 20의 복원을 확인했다. Windows Direct3D 11에서는 같은 적에게 원본 마법 피해 10과 반향 피해 5가 적용됐다. 행동력은 반향 준비와 공격 카드에 각각 2씩만 사용됐다. [반향 준비 화면](MagicEchoReady.png) · [반향 적용 화면](MagicEchoReplay.png)
