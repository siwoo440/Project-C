## 작업 내용

- 내장 이미지 생성 도구로 임시 시작 카드용 일러스트를 제작했다.
- 공격·방어·지원·전략 임시 카드 4종의 일러스트에 공용 스프라이트를 연결했다.

## 이미지 생성 기준

- 어두운 폐허의 청록색 마력 결정과 타로 문양, 손으로 그린 판타지 게임 일러스트.
- 카드 일러스트 영역에 사용할 수 있도록 글자·테두리·인물 제외.
- 파일: `Assets/_ProjectC/Resources/UI/StarterCardArt.png`.

## 검증

- 네 역할 카드 모두 Unity 스프라이트를 정상 참조하는지 테스트했다.
- 별도 프로젝트 복사본에서 Unity 6000.3.21f1 EditMode 테스트 63개 통과.
- 실제 전투 화면에서의 시각적 배치는 아직 확인하지 않았다.
