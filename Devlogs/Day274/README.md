# 274일차 유물 확장 · 소금가죽 파편부터 카라반 비밀장부까지

유물 시트 211~218행의 효과와 투명 원화를 전투, 상점 및 회차 저장에 연결한다.

| 유물 | 효과 |
| --- | --- |
| 소금가죽 파편 | 아군이 받는 출혈 지속 피해를 1 낮추고 화상 지속 피해를 1 높인다. |
| 흑사막 추적자의 표식핀 | 개막에 살아 있는 적 중 현재 체력이 가장 낮은 대상에게 3적 턴 표식을 부여한다. 같은 체력은 조우의 배치 순서로 고른다. |
| 모래여왕의 알껍질 | 매 세 번째 실제 아군 턴에 30% 확률로 생존 적 하나의 공격력을 한 적 턴 동안 2 낮춘다. |
| 유리사막 반사판 | 적이 생존 아군에게 실명을 실제로 부여하면 50% 확률로 무작위 생존 적 하나에게 한 적 턴 동안 실명을 부여한다. |
| 검은 태양의 재 | 살아 있고 화상 중인 적이 받는 전투 피해를 8% 높인다. |
| 마른 오아시스 심장 | 전투를 시작할 때 생존 아군 모두에게 체력 회복 6과 독립 정신력 감소 2를 적용한다. |
| 모래폭풍 병 | 생존 아군에게 처음 두 적 턴 회피율 +10%p와 첫 아군 턴 명중률 −5%p를 각각 적용한다. |
| 카라반 비밀장부 | 실제 승리 보상의 골드·나사·철판·전선을 15% 높이고 정예 전투에서 아군이 받는 피해를 5% 높인다. |

카라반 비밀장부의 재료 보너스는 각 기본 보상에 적용한 뒤 기존 설비 효과를 한 번 적용한다. 마른 오아시스 심장의 체력 회복은 실제로 회복했을 때의 기본 정신력 보너스와 함께 작동한다.
