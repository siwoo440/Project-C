# 121일차 도감 분류와 목록 화면 제작

---
## 작업 내용

- 로비에서 도감의 일곱 분류와 6열 목록을 열고 이전 화면으로 복귀
- 실제 이벤트·포션·적·유물·상태 효과의 이름과 보유 설명을 표시
- 항목 이름 정렬, 상세 정보 확인, 긴 목록의 세로 스크롤 지원
- 아직 원본 데이터가 없는 기록과 상호작용 오브젝트 분류에 빈 목록 안내 표시
- 실제 실행 화면 캡처: `Categories.png`, `Entries.png`
- 검증: 전체 EditMode 테스트 168개 통과, 최종 왼쪽 정렬 적용 후 도감·화면 검사 3개 통과
