# 167일차 : 회복·마법 공용 카드 보상 추가

- 목표: 카드 시트의 작은 치유, 불덩이, 마력탄을 원본 이미지와 수치로 실제 보물 보상에 연결합니다.
- 작은 치유는 AP 1, 아군 한 명 체력 6 회복입니다.
- 불덩이는 AP 1, 적 한 명 마법 피해 9입니다.
- 마력탄은 AP 1, 적 한 명 마법 피해 7입니다.
- 시트에 가격이 없어 세 카드는 보물에서만 얻고 상점 표시와 직접 구매를 막습니다.
- 보물에서는 파티 소유자를 직접 선택하고 저장과 복원에서도 카드와 소유자를 유지합니다.
- 기존 상점 상품과 보상 카드의 구입·획득 경로를 유지합니다.
- 실제 카드 에셋, 전투 효과, 보물 후보, 상점 차단과 저장 복원을 검사합니다.
