# 108일차 이어하기 구현 계획

**목표:** 유효한 거점 저장이 있을 때 이어하기를 활성화하고 저장 상태로 거점에 진입한다.

**구성:** 저장 서비스에서 읽기 전용 유효성 검사를 제공한다. 메인 메뉴는 이 결과로 버튼을 연결하고 클릭 시 파일을 다시 검증·복원한 뒤 거점으로 이동한다. 실패 시 현재 씬과 진행 상태를 유지한다.

**검증:** 임시 저장 경로로 파일 없음, 잘못된 파일, 정상 저장, 클릭 전 파일 변경을 검사한다. 정상 흐름에서 복원된 자원과 거점 진입을 확인하고 전체 EditMode 테스트를 실행한다.

**범위:** 거점 저장만 사용한다. 탐사 중 재개는 109일차 이후에 구현한다.
