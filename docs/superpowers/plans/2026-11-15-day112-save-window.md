# 112일차 저장·불러오기 창 계획

**목표:** 참조 이미지에 맞는 저장 목록과 독립된 저장·불러오기·삭제 버튼을 Unity UI로 구성한다.

**구성:** 생성한 종이 배경과 금속 버튼 이미지 3종을 별도 리소스로 사용한다. 자동 저장 한 칸과 수동 저장 네 칸을 표시하고, 각 칸의 저장 상태·시각과 세 버튼을 독립적으로 갱신할 수 있게 한다.

**검증:** 다섯 슬롯의 이미지·문구, 빈 슬롯 상태, 각 버튼에 전달되는 슬롯 번호와 닫기 동작을 검사한다. 전체 EditMode 테스트를 실행한다.

**범위:** 이 일차는 이미지와 화면 구성이다. 실제 저장 파일 연결과 메뉴 진입은 113일차에 구현한다.
