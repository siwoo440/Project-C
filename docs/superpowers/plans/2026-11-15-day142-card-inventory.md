# 142일차 카드 목록과 임시 수치 정리 계획

- 기획서의 윈터폴 시제품 목표 30~40종과 원본 카드 시트의 현재 행을 구분해 기록한다.
- 실제 프로젝트의 캐릭터 전용 시작 카드, 역할 공용 시작 카드, 테스트·디버그 카드를 각각 집계한다.
- 시트와 프로젝트는 공통 카드 ID가 없으므로 이름의 정확한 일치만 기계적으로 표시하고, 의미가 비슷한 카드를 자동으로 같은 카드라고 판단하지 않는다.
- 카드 시트의 이름·속성·희귀도·비용·설명·대상을 스냅샷으로 남기고 작성되지 않은 항목을 표시한다.
- 22명의 전용 카드가 해당 캐릭터의 시작 덱과 저장 원본에 연결되는지 자동 검사한다.
- 시제품 목표에는 사용자가 확인한 4명의 전용 카드와 공용 카드만 포함한다. 시작 덱에 연결된 임시 8종과 상점 후보 3종의 검증 상태를 분리한다.
