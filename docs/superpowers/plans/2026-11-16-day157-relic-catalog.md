# 157일차 : 유물 데이터 기반 구축

- 유물 시트의 제목을 제외한 298종을 이름과 설명, 구매·판매 가격 및 편차로 보관합니다.
- 빠진 세 유물의 판매 가격은 사용자가 허용한 임시값을 사용하며, 기존 판매 편차 칸에 적힌 범위를 판매 가격으로 정리합니다.
- 자료 목록은 실제로 작동하는 유물의 획득 목록과 분리합니다. 개별 효과를 구현하기 전에는 동작하지 않는 유물이 나타나지 않습니다.
- 각 효과의 임시 수치는 실제 구현과 함께 시트 설명에 기록합니다.
- 전체 유물 효과·이미지·상점과 판매 기능은 이후 일차에서 순차적으로 제작합니다.
