# 153일차 전투 밸런스 점검 계획

- 실제 22명 캐릭터, 시작 카드, 윈터폴 적 원본의 수치와 비용을 집계한다.
- 공용 AP와 피해 계산, 정신력 기준을 기획서와 비교하고 재현 가능한 단순 피해 예시를 검증한다.
- 일반전 3~5턴, 정예전 5~7턴, 보스전 8~12턴은 플레이 관찰 목표로 기록한다.
- 단순 계산을 실제 플레이 결과나 밸런스 통과로 취급하지 않으며, 관측 근거가 없는 값은 임의로 확정하지 않는다.
- 확인한 문제는 회귀 검사와 함께 수정하고, 미확정·미검증 항목은 기획서에 남긴다.
- 검증 중 확인한 탐사·상점 입력 관리자의 장면 간 중복 생성도 함께 수정하고 실제 복귀 흐름에서 검증한다.
- 기획서와 달랐던 정예 전투의 도주 차단을 일반·정예 허용 및 보스 금지 규칙으로 수정한다.
