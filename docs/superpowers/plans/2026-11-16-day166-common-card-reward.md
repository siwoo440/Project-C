# 166일차 : 공용 카드 보상 소유자 선택

- 보물 카드 후보에 공용 카드를 포함하고 실제 당첨 시 파티 소유자 선택을 표시합니다.
- 파티원 선택 전에는 카드 지급과 보물 사용 처리를 보류합니다.
- 취소하면 보물이 남고 같은 보상으로 다시 선택할 수 있습니다.
- 카드 지급 성공 후에만 보물 사용과 자동 저장을 처리합니다.
- 저장 복원과 화면 파괴 시 대기 창 및 일시 정지를 안전하게 해제합니다.
- 고정 소유자와 다른 보상은 기존 지급 방식으로 유지합니다.
- 실제 탐사 흐름에서 취소, 재선택, 지급, 복원과 중복 방지를 검증합니다.
