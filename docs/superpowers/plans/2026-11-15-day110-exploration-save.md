# 110일차 탐사 상태 저장 계획

**목표:** 탐사 시점의 거점 진행과 탐사 상태를 하나의 저장 파일에 기록한다.

**구성:** 거점 저장 데이터를 메모리에서 수집하고, 층·시드·위치·처리한 조우와 이벤트, 파티, 원본 덱과 현재 회차 덱, 카드 강화, 유물·소모품과 위험 상태를 함께 저장한다. 식별자는 원본 데이터의 고유 ID를 사용한다.

**검증:** 고유 임시 파일에 실제 런타임 상태를 저장하고 파일에 담긴 값과 순서를 검증한다. 불완전한 탐사는 저장하지 않으며, 기존 파일 교체 시 실패하면 이전 파일을 보존한다. 전체 EditMode 테스트를 실행한다.

**범위:** 이 일차는 저장 데이터 생성과 기록이다. 실제 탐사 재개와 저장 지점 연결은 111~112일차에 진행한다.
