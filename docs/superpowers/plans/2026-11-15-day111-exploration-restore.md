# 111일차 탐사 상태 복원 계획

**목표:** 저장된 탐사 상태를 검증한 뒤 같은 파티·덱·층·위치와 진행 상태로 복원한다.

**구성:** 저장 파일의 캐릭터·카드·유물·소모품 식별자를 런타임 카탈로그에서 검증한다. 전체 검증 후 거점 상태, 회차 편성·덱, 조우·이벤트·상점·휴식·위험 상태를 복원한다. 이어하기는 유효한 최근 저장을 선택하며, 새 게임은 이전 탐사 저장을 더 이상 사용하지 않는다.

**검증:** 임시 경로에서 탐사 저장 후 런타임을 변경하고 복원한다. 잘못된 식별자와 손상 데이터는 기존 상태를 변경하지 않아야 한다. 실제 탐사 씬 진입 시 시드·위치와 파티를 확인하고 전체 EditMode 테스트를 실행한다.

**범위:** 저장 슬롯 화면과 버튼은 112~113일차, 자동 저장 지점과 전투 전후 체크포인트는 114일차에 연결한다. 기존 사용자 저장과 테스트 파일은 분리한다.
