# 147일차 상태 이상과 방 생성 점검 계획

**목표:** 기획서와 실제 구현의 상태 이상·방 생성 차이를 점검하고, 확인된 공통 지속 규칙과 중독 수치 감소를 검증 가능한 범위에서 반영한다.

**구성:** `BattleStatusEffectInstance`, `BattleStatusEffectProcessor`, `BattleStatusEffectController`에서 상태 강도와 진영별 지속 턴을 분리한다. 탐사 맵의 기존 시드 생성 방식은 유지하고 도달 가능성과 방 역할 제한을 검증한다.

**환경:** Unity 6000.3.21f1, C#, EditMode와 실제 전투 흐름 검사.

---
## 작업과 검증

- [ ] 기획표 1~161일차의 완료·예정 상태와 커밋 제목을 대조하고 초기 구현의 후속 작업을 기록한다.
- [ ] 중독 총 수치가 턴 시작마다 1 줄어드는 검사와 자신의 턴에 적용한 상태의 지속 턴을 첫 종료에 유지하는 검사를 먼저 작성해 실패를 확인한다.
- [ ] 중첩·정화·면역·전이와 소환 적에도 동일 규칙이 적용되도록 처리한다. 별 예약 회복 등 발동 후 제거하는 전용 효과와 사용자 확인 화상 피해 2→1은 보존한다.
- [ ] 여러 시드와 층의 모든 방·계단 도달 가능성, 양방향 연결, 층별 관문·특수 방 제한을 확인한다.
- [ ] 구역 진행도 기반 보스 예약과 구간 배치 등 기존 층 기반 맵에 없는 규칙은 확인된 미구현으로 기록한다.
- [ ] 변경 테스트와 전체 Unity 테스트를 실행하고 기획서의 완료 표시·임시 규칙을 갱신한다.
