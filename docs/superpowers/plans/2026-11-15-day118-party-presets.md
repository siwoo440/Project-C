# 118일차 편성 1~4 저장과 전환 계획

---
## 구현 순서

1. 네 편성의 독립 선택과 전환, 저장·복원 및 기존 저장 호환 테스트를 작성한다.
2. 편성별 캐릭터 식별자와 현재 선택 번호를 저장 데이터에 포함한다.
3. 편성 화면의 네 버튼을 연결하고 편성 변경을 거점 자동 저장에 반영한다.
4. 사망·회복·해금 상태가 달라진 캐릭터는 편성에서 확인하고 해제할 수 있으나 출발은 막는다.
5. 새 게임 초기화, 수동 저장, 탐사 저장, 기존 저장 파일과 실제 출발 흐름을 회귀 검증한다.

---
## 데이터 보존 기준

- 과거 버전 1 저장에 편성 정보가 없으면 빈 편성 네 개로 복원한다.
- 잘못된 캐릭터 식별자, 중복, 인원 초과는 복원 전에 차단한다.
- 사용할 수 없게 된 캐릭터를 저장된 편성에서 임의로 삭제하지 않는다.
- 편성 슬롯 전환은 다른 슬롯의 선택을 덮어쓰지 않는다.
