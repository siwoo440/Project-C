# 145일차 윈터폴 보스 초기 구현 계획

- 별도 적 문서와 주요 기획서에서 윈터폴 보스의 확정 정보를 확인하고, 이름이 미정인 밸런스 시트의 보스 기본 체력 350·공격 18·방어와 저항 12를 임시 기준으로 연결한다.
- 사용자가 확인한 대로 기존 보스 체력 2.5배와 공격 1.35배를 추가 적용하고, 1층 계산 및 기존 저장 조우 목록 호환성을 검증한다.
- 정신력과 시야에 대응 가능한 압박을 주는 임시 행동을 예고와 함께 구현한다. 패턴과 페이즈 수치·조건은 확정 기획이 아닌 개발 임시값으로 기획서에 기록한다.
- 페이즈 전환은 기획서에 따라 미처리 행동을 취소하고 기존 턴 종료 정리를 한 번만 실행한다. 카드 연속 공격, 턴 종료 효과, 승패와 다음 턴 진입을 검증한다.
- 실제 보스 조우와 전투 화면을 확인하고 처치, 보상, 기존 탐사 저장과 회귀 테스트를 검증한다.
