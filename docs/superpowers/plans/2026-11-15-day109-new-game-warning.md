# 109일차 새로하기 경고 계획

**목표:** 새로하기 전에 진행 및 저장 데이터가 초기화되는 사실을 알리고 확인을 받는다.

**구성:** 메뉴 위에 경고 패널을 표시한다. 취소하면 메뉴와 데이터를 유지하고, 확인하면 기존 새 게임 초기화 흐름을 실행한다. 패널이 열린 동안 다른 메뉴 입력을 막고 취소 버튼에 키보드 초점을 둔다.

**검증:** 실제 메뉴에서 경고 문구와 취소 시 진행 상태 유지를 확인한다. 확인 후 기존 새 게임 초기화와 거점 진입을 검증하고 전체 EditMode 테스트를 실행한다.

**후속:** 진행 중인 탐사 저장 작업은 110일차부터 계속한다.
