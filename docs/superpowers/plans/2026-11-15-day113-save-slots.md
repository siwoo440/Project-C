# 113일차 저장 슬롯 연결 계획

---
## 구현 순서

1. 자동 저장 경로와 수동 슬롯의 유효성 검사, 저장, 불러오기, 삭제를 독립 경로 테스트로 검증한다.
2. 저장 화면에 슬롯별 데이터와 오류 메시지를 표시하고 삭제 확인을 연결한다.
3. 메인 메뉴와 거점·탐사 화면에서 저장 화면을 열고 각 기능을 연결한다.
4. 새로하기와 슬롯 확인창에 공통 배경·버튼 이미지를 제작해 적용한다.
5. 기존 이어하기와 저장 상태 복원, 빈 슬롯 및 손상 파일을 회귀 검증한다.

---
## 기준

- 자동 슬롯은 기존 거점·탐사 자동 저장 중 최근 유효 파일을 사용한다.
- 수동 슬롯 네 개는 서로 다른 파일로 관리하며 새 게임 시작 시 유지한다.
- 저장할 게임이 없는 메인 메뉴에서는 저장 버튼을 비활성화한다.
- 덮어쓰기와 삭제는 확인 후 실행하며 실패 시 기존 상태와 오류 안내를 유지한다.
- 플레이어 진행 파일을 건드리지 않도록 테스트 경로를 분리한다.
