# 148일차 전투 튜토리얼 개발 계획

- 기획서 11.4와 실제 전투 UI를 기준으로 손패·카드 사용·AP·정신력·적 행동 예고·턴 진행을 단계별로 안내한다.
- 카드 사용과 적 턴 종료는 실제 전투 이벤트를 감지한다. 안내와 건너뛰기는 게임 진행을 막지 않으며 전투 화면에서 다시 열 수 있게 한다.
- 설정의 튜토리얼/힌트 항목을 실제 설정 저장소에 연결한다. 최초 완료 여부는 기기별로 보관하고 다시 보기는 별도로 제공한다.
- 화면을 어둡게 하고 관련 영역을 금색 테두리로 강조한다. 배치가 변경되거나 대상이 없어도 전투 입력과 게임 진행이 막히지 않게 한다.
- 상태 전이·건너뛰기·재시작·설정과 실제 전투 이벤트를 테스트하고, 실제 화면 확인 후 전체 EditMode 검사를 실행한다.
- 각성·붕괴의 실제 발동 유도와 전투 후 보상 안내, 로비·탐사 튜토리얼은 별도 단계와 후속 일정에서 검토한다.
