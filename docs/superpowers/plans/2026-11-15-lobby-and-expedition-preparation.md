# 로비와 탐사 준비 화면 개발 계획

---
## 요청 사항

- 로비에 오른쪽 캐릭터·편성·탐사 버튼, 위쪽 골드·도움말·설정, 아래쪽 도감·자원·설비 강화 배치
- 로비에 자동으로 표시되던 기존 파티 편성 창과 거점 디버그 패널 제거
- 탐사 버튼에서 맵을 선택한 뒤 새 편성 화면으로 이동
- 새 편성 화면은 왼쪽 캐릭터 목록, 가운데 네 개의 캐릭터 편성 칸, 축소한 오른쪽 상세 패널 배치
- 아래쪽에 편성 1~4 선택 영역 배치
- 화면 완성 후 실제 실행 화면을 캡처해 채팅에 표시

---
## 개발 일차

1. 114일차: 로비 레이아웃과 기존 자동 편성 화면 제거, 기존 진입 기능 유지
2. 115일차: 탐사 맵 선택과 새 편성 화면 연결, 현재 게임에 존재하는 맵만 선택 가능하도록 구성
3. 116일차: 네 개의 편성 칸과 편성 선택 동작, 캐릭터 상태 및 탐사 출발 연결
4. 화면 실행 캡처와 전체 흐름 검증을 완료 일차에 수행

---
## 기준

- 기존 저장 데이터와 전투·탐사에서 사용하는 파티 데이터는 보존한다.
- 아직 구현되지 않은 콘텐츠는 실행 가능한 것처럼 표시하지 않는다.
- 기존 편성 화면을 자동으로 생성하거나 새 편성 버튼에서 다시 열지 않는다.
- 저장 화면과 설정, 실제 로비 자원 표시가 새 배치에서 계속 동작한다.
