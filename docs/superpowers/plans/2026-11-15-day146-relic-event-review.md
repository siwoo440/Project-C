# 146일차 이벤트·유물 점검과 초기 보완 계획

- 주요 기획서의 시제품 목표와 별도 이벤트 기획·유물 시트를 현재 게임 데이터, 획득 경로 및 실제 효과와 대조한다.
- 테스트용 이벤트 3종과 유물 2종은 시제품 완성 수량과 구분하고, 현재 지원하지 않는 선택 결과와 유물 효과를 후속 작업으로 기록한다.
- 사용자가 승인한 잿빛 인장과 유물 시트에서 대상·효과가 명확한 항목부터 상점·보물 획득, 저장 복원, 전투 효과를 연결한다.
- 잿빛 인장은 전투 시작 시 생존 아군에게 방어도 총 6을 순서대로 배분한다. 깨진 멜로디 박스는 아군 전체 정신력 +1, 청동 향로는 아군 전체 마법 저항력 +1을 1턴, 부유석 조각은 무작위 생존 아군 1명에게 방어도 8을 적용한다.
- 실제 전투 시작 효과, 중복 획득, 상점·보물 후보와 저장 복원을 검증한다. 나머지 유물과 이벤트는 수량만 맞추기 위해 미구현 효과를 완료로 표시하지 않는다.
