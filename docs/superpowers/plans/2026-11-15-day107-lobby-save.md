# 107일차 거점 저장 구현 계획

**목표:** 거점의 자원, 설비, 성장, 호감도, 캐릭터 상태와 회복 정보를 파일로 저장하고 복원한다.

**기준:** `Devlogs/Day106/저장과초기화기준.md`. 세계 해금은 기존 별도 기록을 유지한다.

**구성:** 저장 서비스가 각 관리자의 상태를 식별 가능한 값으로 수집하고 버전이 있는 데이터로 기록한다. 복원 전 데이터 유효성을 확인하고, 각 관리자가 자신이 소유한 상태를 복원한다. 테스트에는 고유한 임시 파일 경로를 사용한다.

**순서:** 실제 관리자 상태를 바꾸고 저장·초기화·복원하는 실패 테스트를 작성한다. 자원·설비·성장·호감도와 사망·회복 상태를 구현한 다음 저장 파일의 누락 및 오류 처리를 검증한다. 거점에서 호출할 저장 지점은 기존 탐사 종료·거점 흐름을 확인한 뒤 연결한다.

**제외:** 탐사 도중 저장과 이어하기 버튼은 이후 일차 범위다. 기존 아틀라스 변경은 포함하지 않는다.
