# 132일차 연인·전차 및 손패 UI 보완

- 연인 전용 카드로 생존한 다른 아군을 파트너로 지정하고 변경할 때 기존 턴 기록을 초기화한다.
- 파트너의 카드 사용을 추적하고 사망과 턴 전환 시 연계 상태를 정리한다.
- 전차의 전용 카드와 같은 적에 대한 두 번째 공격으로 턴 내 돌파 표식을 얻는다.
- 목표 변경과 턴 종료 시 기존 표식을 정리하고 임의의 추가 피해 수치는 적용하지 않는다.
- 추가 피해량과 마무리 카드, 정신 상태별 효과는 기획 확정 후 연결한다.
- 손패가 화면 밖으로 넘어가지 않도록 카드 간격을 줄이고, 마우스 진입 시 카드를 위쪽과 최상단에 표시한다.
