# 117일차 맵 선택과 새 편성 화면 계획

---
## 동작 흐름

1. 로비의 탐사 버튼에서 현재 구현된 기본 탐사 맵을 선택한다.
2. 맵을 선택하면 이전에 자동 표시되던 창과 별도의 새 편성 화면으로 이동한다.
3. 왼쪽에서 출전 가능한 캐릭터를 고르면 가운데 네 개의 편성 칸에 순서대로 표시한다.
4. 오른쪽의 축소된 정보 영역에서 선택 캐릭터의 실제 데이터를 확인한다.
5. 유효한 파티를 선택한 경우 기존 탐사·전투 데이터와 시작 덱을 준비하고 출발한다.

---
## 검증 기준

- 로비 진입 시 기존 편성 창이 자동으로 표시되지 않는다.
- 맵 선택 전에는 편성 화면이 표시되지 않고 뒤로 돌아갈 수 있다.
- 선택 인원 제한, 중복, 미해금, 사망, 회복 상태를 기존 출전 규칙으로 검증한다.
- 편성 후 실제 탐사에 진입하고 선택 캐릭터가 유지된다.
- 실행 화면을 캡처해 실제 배치를 확인한다.
- 네 개의 편성 저장 선택지는 118일차에 연결한다.
