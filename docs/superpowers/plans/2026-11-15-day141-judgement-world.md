# 141일차 심판·세계 임시 전용 카드 계획

- 심판은 선택한 생존 아군을 즉시 8 회복하고, 회복 전 체력이 최대 체력의 50% 이하면 4를 추가 회복한다.
- 세계는 선택한 생존 아군에게 방어도 3을 준다. 이번 턴 세계 이외 서로 다른 두 캐릭터의 전용 카드가 사용됐으면, 다른 생존 아군 중 체력 비율이 가장 낮은 대상에게도 방어도 3을 준다.
- 각 전용 카드를 실제 편성과 저장 목록에 연결한다. 전용 카드의 식별은 해당 소유자의 전용 카드에 한정하고 턴마다 사용 기록을 초기화한다.
- 세계의 기존 최종 탐사 승리 해금 및 저장·재시작 후 유지 여부를 회귀 검증한다.
- 위기 경계, 다른 소유자와 전용 카드 판정, 같은 소유자 반복, 턴 변경, 추가 대상 부재, 최대 체력과 방어도 처리를 검사한다.
- 각 패시브와 정신 상태별 효과는 구체적 기획이 미정이므로 후속 항목으로 유지한다.
