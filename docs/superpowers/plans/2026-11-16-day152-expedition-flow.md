# 152일차 거점부터 보스까지 흐름 검증 계획

- 실제 거점의 탐사·지역 선택·파티 편성 버튼으로 출발하고 일반 조우 접촉, 전투 결과 확인과 탐사 복귀를 검증한다.
- 반복 이동과 전투는 테스트에서 단축하여 최종 보스 층으로 진행하며, 실제 보스 전투·결과 확인·보상·성공 정산·거점 복귀를 확인한다.
- 보상의 중복 지급 방지, 저장 상태와 귀환 뒤 재출발 가능 여부를 검사하고 발견된 진행 차단 문제를 수정한다.
- 해당 검사는 전체 맵을 수동으로 이동하는 플레이 검사를 대체하지 않으며, 자동 검사의 단축 구간과 한계를 기록한다.
