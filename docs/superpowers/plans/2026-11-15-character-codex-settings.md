# 캐릭터·도감·설정 화면 개발 계획

---
## 캐릭터 화면

- 로비의 캐릭터 버튼에서 실제 캐릭터 일러스트와 이름을 여섯 열로 표시
- 목록이 화면을 넘으면 스크롤하고 뒤로 돌아가는 경로 제공
- 기존 캐릭터 해금과 출전 상태를 임의로 변경하지 않음

---
## 도감 화면

- 상호작용, 포션, 적, 유물, 상태이상, 씻겨진 기록, 상호작용 오브젝트의 일곱 분류 표시
- 분류 선택 후 참고 이미지의 격자 목록과 스크롤 배치 적용
- 프로젝트에 실제 존재하는 데이터를 연결하고 미구현 분류는 빈 상태를 표시

---
## 설정 화면

- 기획서 `10. 설정`의 그래픽·사운드·게임플레이·조작·언어 항목과 기본값을 원본 기준으로 대조
- 참고 이미지처럼 상단 분류 탭과 스크롤 가능한 설정 항목 배치
- 변경한 값의 실제 적용과 저장·복원을 검증하고 지원하지 않는 기능은 동작하는 것처럼 표시하지 않음
- 실제 실행 화면과 기존 설정 진입·복귀 흐름 검증
