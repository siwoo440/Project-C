# 150일차 전투 표시 설정 연결 계획

- 기획서의 피해 숫자 표시와 카드·상태 이상 상세 툴팁 설정을 실제 전투 화면에 연결하고 기기 설정으로 저장한다.
- 상세 툴팁의 키 누름 모드는 임시로 왼쪽 또는 오른쪽 Alt를 사용한다. 마우스를 올린 상태에서 키를 눌렀다 떼는 변화도 반영한다.
- 피해 숫자를 꺼도 피격 강조, 방어도 흡수, 회복과 상태 문구는 유지한다.
- 상태 상세 툴팁이 화면 밖으로 잘리지 않도록 현재 캔버스 범위를 기준으로 위치를 조정한다.
- 현재 프로젝트에 실제 음원과 사운드 재생 경로가 없는 점을 기록하고, 소리 설정이 적용된 것처럼 표시하지 않는다.
- 설정 저장·복원, 표시와 비표시, 키 상태 변화, 화면 경계와 실제 전투 연결을 검사한다.
