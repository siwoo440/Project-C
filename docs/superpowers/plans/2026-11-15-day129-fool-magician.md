# 129일차 바보·마법사 전용 능력 보완

---
## 개발 방향

- 기획서 2.14와 두 캐릭터의 검토용 설계안을 기준으로 기존 선택 드로우와 버린 카드 회수·패시브를 점검한다.
- 사망한 소유자의 전용 카드는 덱에서 보존하되 일반 드로우와 바보 선택 후보에서 제외한다.
- 살아 있는 카드가 버린 더미에만 남아 있으면 재구성하고, 사망 카드만 남은 경우 반복 없이 종료한다.
- 소유자 부활 후 기존 카드가 다시 드로우 후보가 되도록 한다.
- 사망 카드가 덱 위에 있어도 바보의 선택하지 않은 유효 카드 처리와 마법사 회수 기능이 유지되는지 검증한다.
- 추가 전용 카드의 수치와 동작은 검토용 설계이며 확정된 내용으로 표시하지 않는다.
