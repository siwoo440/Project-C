# 149일차 탐사·거점 튜토리얼 개발 계획

- 실제 로비 화면의 캐릭터, 구역 선택 후 파티 편성, 회복 대기, 설비 강화와 탐사 출발 흐름을 순서대로 설명한다.
- 탐사 화면에서는 WASD와 방향키 이동을 실제 위치 변경으로 확인하고, 현재 구현된 접촉 방식의 전투·이벤트·보물·휴식·상점을 안내한다.
- 각 안내는 건너뛰기와 다시 보기를 지원하고 기존 튜토리얼/힌트 설정을 따른다. 완료 기록은 각 안내별 기기 설정에 저장한다.
- 안내 배경이 게임 입력을 막지 않도록 구성하고, 캐릭터 회복 대기를 전투 턴이 아닌 인정된 탐사 횟수로 설명한다.
- F키 상호작용, 구역 진행도 기반 보스 예약, 거점 덱 관리 등 현재 구현과 다른 기획은 완성된 것처럼 안내하지 않고 후속 작업으로 남긴다.
- 이동 감지·단계 진행·설정·다시 보기 및 실제 로비와 탐사 씬 연결을 검사하고 화면을 촬영한다.
