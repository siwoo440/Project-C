# 106일차 새 게임 초기화 구현 계획

**목표:** 새로하기에서 이전 게임의 런타임 진행 상태를 초기화한다.

**기준:** `Devlogs/Day106/저장과초기화기준.md`. 세계 해금과 사용자 설정은 유지한다.

**구성:** `MainMenuController`에서 초기화를 호출하고 기존 관리자들의 초기화 기능을 활용한다. 초기화 기능이 없는 회차 상태는 각 소유 관리자에서 정리한다. 저장 파일은 107일차 이후에 다룬다.

**검증:** 실제 메뉴 버튼 흐름에서 이전 자원·성장·탐사 상태가 초기화되는지 먼저 실패 테스트로 확인한다. 이어서 회복, 파티, 덱, 유물, 소모품, 상점 상태와 해금 유지도 검증하고 전체 EditMode 테스트를 실행한다.

**주의:** 원본 프로젝트의 기존 아틀라스 변경은 수정하거나 커밋하지 않는다. Unity 테스트는 별도 프로젝트 복사본에서 실행한다.
