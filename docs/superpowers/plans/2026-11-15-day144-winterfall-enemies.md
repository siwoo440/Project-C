# 144일차 윈터폴 일반 적·정예 초기 구현 계획

- 별도 적 문서에서 일반 적 5종과 정예 2종의 쉬움 체력·물리 방어력·저항 수치 및 명시된 기본 공격을 확인한다.
- 사용자가 승인한 임시 기준대로 저항 퍼센트 숫자를 현재 저항 수치로 사용하고 계산 방식 차이를 기록한다.
- 턴 종료 화상 2→1과 한 턴 실명의 공격 명중률 25%p 감소를 적용하고, 중독·정화·사망 처리와 함께 검증한다.
- 적 행동의 공격 적중 후 상태 이상 확률을 데이터로 지정하고, 행동 예고와 실제 적용 결과를 확인한다.
- 일반·정예 조우에 새 적을 연결하고, 해당 적의 기본 공격·화상·실명 외 미지원 패시브와 복합 패턴은 완료로 표시하지 않고 후속 항목에 기록한다.
- 이미지와 실제 전투 화면을 확인하고 적 생성·턴 처리·저장과 기존 조우 회귀를 검증한다.
