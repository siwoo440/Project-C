# 151일차 전투 화면 UI 이미지 적용 계획

- 요청한 전투 화면을 기존 로비의 어두운 청록색과 금색 디자인에 맞춰 이미지 기반 UI로 개선한다.
- 새로 생성한 손패 배경과 카드 프레임을 적용하고, 기존 제작 이미지를 활용해 전투 버튼·행동력·턴 정보와 상태 표시를 정리한다.
- 카드 일러스트와 글자 가독성, 호버·선택·사용 불가 표시, 드래그 대상과 버튼 입력 영역을 유지한다.
- 화면 크기와 손패 장수 변화에 따른 배치, 실제 전투 입력과 기존 튜토리얼·툴팁 표시를 검증한다.
- 실제 전투 화면을 촬영하고 전체 검사 후 커밋·푸시와 기획서 완료 링크를 기록한다.
- 상태 효과 15종을 정사각형 아이콘으로 구분하고 왼쪽 아래에 남은 턴, 오른쪽 아래에 효과 수치를 표시한다.
