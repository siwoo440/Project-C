# 165일차 : 공용 카드 상점 소유자 선택

- 공용 카드 상품을 누르면 현재 탐사 파티의 캐릭터 목록을 표시하고 플레이어가 소유자를 선택합니다.
- 소유자 선택 전에는 골드를 차감하거나 카드를 지급하지 않으며, 파티원이 아닌 캐릭터는 선택할 수 없습니다.
- 선택한 캐릭터에게 기존 카드가 없어도 현재 파티원이라면 카드를 받을 수 있습니다.
- 강타, 검풍, 정화를 실제 상점에 연결하고 구매 후 덱과 저장 복원을 확인합니다.
- 사용자가 확인한 임시 상점 가격은 강타 80골드, 검풍 120골드, 정화 100골드입니다.
- 보물 보상에서의 공용 카드 소유자 선택은 별도 후속 작업입니다. 구현 전까지 보물에서 공용 카드를 임의로 지급하지 않습니다.
