# 170일차 : 정신력 게이지 색상 개선

- 사용자가 확인한 기존 정신력 범위 0~100과 중립 50을 유지합니다.
- 정신력이 0에 가까울수록 빨강, 50에서는 중립색, 100에 가까울수록 파랑이 되도록 연속적으로 보간합니다.
- 각성·붕괴 중에도 고정 색상이 아니라 실제 정신력 수치에 맞게 색상을 바꿉니다.
- 정신력이 0일 때도 빨간색을 확인할 수 있도록 게이지 안쪽 바탕색을 함께 표시합니다.
- 상태 이름, 지속 턴, 정신력 수치와 기존 효과는 유지하며 배경 대비에 맞춰 글자를 읽기 쉽게 표시합니다.
- 실제 유닛의 수치·상태 변화, 사망·재연결, 색상과 클릭 차단 여부를 검사하고 화면을 촬영합니다.
